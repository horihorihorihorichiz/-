麻雀 守りGTO 通常ルール

通常麻雀（フリテンあり）版。リーチした相手の河から「当たらない牌」を読む練習。現物・スジを小学生にも分かる言葉で解説。スマホ向け。

韓麻（パラダイスシティ）のルール要点

  • 役なし：4面子1雀頭ならアガれる（七対子・国士のみ特殊役）
  • フリテンなし：現物でも当たる（安全牌の概念が違う）
  • チーなし／ポン・カンあり・5は全部赤ドラ
  • 点数：ロン6・ツモ2ずつ・リーチ+2・ドラ各+1・国士20
