# 競馬予想 Ver.99.27 実行スキル

## 役割
渡されたレースデータに対して `keiba/template-v99.27.md` の Ver.99.27 ロジックを
STEP0→STEP10 まで忠実に適用し、台帳と買い目を出力する。

## 手順
1. **必ず最初に `keiba/template-v99.27.md` を Read する**（暗記で回さない。配点・補正表・展開マトリクスは毎回ファイル参照）。
2. ユーザーのデータ（テキスト貼付 or スクショ画像）から必須事前情報を抽出：
   - レース: 場・距離・回り・馬場状態・馬場指数・クラス(Tier)・頭数・斤量条件
   - 各馬: 今回馬体重・性齢・斤量・新聞脚質表記・騎手・過去9走・タイム指数表
   - 指定: ブースト①②／馬体重「未定」／展開手動上書き
3. テンプレ通りに計算：
   - STEP0 母数判定 → STEP1 脚質5段階(新聞表記を必ず先に転記) → STEP2 展開
   - STEP3 LTS → STEP4 TSI → STEP5 FSI → STEP6 Bonus → STEP7 各成分
   - STEP8 WAvg → STEP9 Power/Final_PWin(30%cap) → STEP10 ランク/Case判定
4. 出力：①前提・データ欠損の明示 ②脚質表 ③展開根拠 ④成分台帳 ⑤Final_PWin順位 ⑥Case+買い目

## データ取得についての制約（重要）
- この実行環境からは netkeiba 等の競馬サイトに**自動アクセス不可**（ボット遮断403＋会員ログイン不可）。
- よってデータは**ユーザーがテキスト貼付またはスクショ画像で渡す**前提。URLを渡されても取得できない。

## 欠損データの扱い（毎回明示する）
- **タイム指数表が無い** → TSI(配点30)は全馬0で除外し「暫定値・要再計算」と明示。タイム指数タブがあれば再計算を促す。
- **馬場指数が無い** → B補正=0(中立帯-15〜-19相当)で全馬一律として処理し明示。
- **4角空欄** → 基本除外して残りで平均。頻度が多ければ最後尾算入も検討。処理は常に報告。

## 注意点
- VG(コース特性) と G1-G3(レースグレード/Tier) を混同しない。
- 展開補正(最新版): 稍重→ミドルハイ / 重・不良→ミドルまで(差し馬不利のため)。枠順系補正はダート不適用。
- 計算は段階ごとに根拠を表示し、ダブルチェック(上がり・距離・指数・体重・4角・年数)する。
