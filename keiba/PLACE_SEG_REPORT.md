## 結論（先頭）

**「3着内 × セグメント別」も不成立。事前登録の二次基準を通ったセグメントは 36 中 0。**

| 判定 | 基準 | 実測 | 判定 |
|---|---|---|---|
| **一次** Δα>0 が VALIDATE 3fold連続 | — | **3 / 36 セグメント**（S-B ダ短・芝短・ダ中長） | 偶然期待 **4.5** を**下回る** |
| **二次** 複勝flat VAL ROI≥95% かつ CONF ROI≥95% | — | **0 / 36 セグメント** | **全滅** |
| 三次（参考） ワイド・三連複 EV | — | EV≥1.2 三連複 ROI **24.8%(VAL) / 32.5%(CONF)** | 参考・不合格 |

決定打は次の3つ:

1. **Δα の符号は全体でコインフリップ以下**。推定可能な全フォールドで Δα>0 だったのは
   S-A **49.3%**(35/71) / S-B **47.7%**(62/130) / S-C **25.6%**(21/82)。
   「専用の方が市場への付加情報が多い」という傾向は**存在しない**。
2. **out-of-sample 対数損失の改善は実質ゼロ**。VALIDATE+CONFIRM の1頭あたり改善（汎用−専用）は
   S-A **+0.000014** / S-B **+0.000069** / S-C **+0.000001** nats。
   比較対象: PLACE_SYSTEM で汎用モデルが市場に足した分が **+0.00014**、
   「単勝オッズの読み替えを柔軟にするだけ」の分が **+0.00057**。
   **セグメント別学習の寄与は、汎用モデルの寄与の 1/2〜1/100。**
3. **複勝ROIは市場ベンチマークを超えない**。スキーム全体プール（VALIDATE 874R / CONFIRM 675R）:

   | スキーム | VALIDATE 専/汎/市場1-3人気 | CONFIRM 専/汎/市場1-3人気 |
   |---|---|---|
   | S-A 場 | 84.4 / 80.6 / **85.0** | 82.9 / 77.9 / 81.2 |
   | S-B 馬場×距離 | 83.2 / 80.6 / **85.1** | 80.3 / 77.9 / 80.9 |
   | S-C 場×馬場 | 86.3 / 80.7 / **85.1** | 79.2 / 77.9 / 81.0 |

   専用は汎用より 2〜6pt 高いが、**市場1-3番人気ベタ買いとほぼ同着で、95%には遠い**。
   3着内的中率でも専用が汎用に勝つのは S-B の VALIDATE だけ（60.9% vs 59.7%）で、
   S-A・S-C は負け（58.9 vs 59.7 / 59.0 vs 59.7）。

**SPECIALIST実験の結論は覆らなかった。「1着当てという土俵が悪かっただけ」という仮説は棄却する。
3着内に変えても、セグメント別に学習データを絞る操作そのものが情報を増やしていない。**

## 1. 一次判定 — Δα の推移

### 1-1. 構造的な欠陥（実行中に判明・正直に記録）

**S-A と S-C は事前登録の一次基準を定義上満たせない。**
JRA の開催カレンダー上、1つの場が VALIDATE 窓（202603/04/05）で走る月は**最大2ヶ月**しかない:

| 窓 | 各場の該当fold月 |
|---|---|
| VALIDATE | 東京 04-05 / 中山 03-04 / 京都 04-05 / 阪神 03-04 / 福島 04 / 新潟 05 / 中京 03 / 小倉 03 / **札幌・函館 なし** |
| CONFIRM | 札幌 07-08 / 函館 06-07 / 福島 06-07 / 新潟 07-08 / 中京 07-08 / 小倉 06-07 / 東京 06 / 阪神 06 / **中山・京都 なし** |

したがって「VALIDATE 3フォールド連続」を評価できるのは **S-B の6セグメントだけ**。
S-A/S-C の30セグメントは機械的に不通過（=一次通過3件はすべてS-B）。
**事前登録は変更しない**が、この欠陥は結論の読み方に影響するので §1-3 に代替の読み方を参考値として併記する。

### 1-2. S-B（馬場×距離帯・6セグメント。唯一 3fold が揃う）

α_spec = 専用モデルの α_place / α_gen = 汎用 v8place の α_place（**同一レース集合・同一市場側・q_model の列だけ差し替え**）。

| **ダ短** | 946 | **+0.0522** | **+0.0592** | **+0.0576** | ○ | +0.0646 / +0.0668 / +0.0648 |
| **芝短** | 655 | **+0.0365** | **+0.0318** | **+0.0348** | ○ | +0.0362 / +0.0472 / +0.0518 |
| **ダ中長** | 1394 | +0.0041 | +0.0040 | +0.0006 | ○ | −0.0004 / −0.0012 / +0.0020 |
| ダﾏｲﾙ | 1227 | −0.0323 | −0.0278 | −0.0232 | × | −0.0175 / −0.0138 / −0.0101 |
| 芝中長 | 1741 | −0.0138 | −0.0174 | −0.0122 | × | −0.0134 / −0.0175 / −0.0156 |
| 芝ﾏｲﾙ | 928 | −0.0487 | −0.0486 | −0.0421 | × | −0.0372 / −0.0349 / −0.0366 |

α の水準そのもの（fold 202608・専用/汎用）:
ダ短 **+0.0685 / +0.0037**（SE 0.0397）・芝短 −0.0049 / −0.0567（SE 0.0519）・
ダ中長 +0.1145 / +0.1125（SE 0.0335）・ダﾏｲﾙ +0.0449 / +0.0550・芝中長 +0.0133 / +0.0289・芝ﾏｲﾙ +0.0204 / +0.0569。

- **ダ短が唯一の質的な差**: 汎用の α は **0.000 付近（=ダート短距離では汎用モデルの付加情報はゼロ）**
  なのに、専用は **+0.065** を出す。6フォールド全部で Δα>0。
  SPECIALIST実験（1着の土俵）で唯一通過したのも「ダ短」であり、**2実験で同じ区分が浮いた**。
- ただし **α の SE は 0.040** で、+0.065 は z≈+1.7。**単独では有意ですらない**。
- **符号が3fold連続で揃うことに情報はほとんど無い**: α は「その月より前の全データ」の累積で推定するため、
  隣接foldの学習集合は9割以上重複する。**「3fold連続」は実質1観測**である
  （PLACE_SYSTEM §1-4 でも「α>0 の連続は実力ゼロのヌルでも通る」と実証済み）。

### 1-3. 参考（事前登録外・合否に使わない）: 推定可能な全VALIDATEフォールドで Δα>0

S-A/S-C の構造的欠陥を補うための**参考読み**。セグメントごとに推定できた VALIDATE fold（1〜3個）が
全部 Δα>0 かで数える。偶然期待は Σ 0.5^(fold数)。

- **通過 11 セグメント（α推定可能な27セグメント中）/ 偶然期待 8.25** → **偶然と区別できない**。
- 内訳: S-A 中山(+0.0190,+0.0184) 小倉(+0.0415) 福島(+0.0127) 阪神(+0.0282,+0.0340) /
  S-B ダ短・芝短・ダ中長 / S-C 京都ダ(+0.0128,+0.0137) 小倉芝(+0.1063) 新潟ダ(+0.0524) 阪神芝(+0.0858,+0.0624)
- α 推定可能な VALIDATE fold を1つも持たないセグメント: S-A 2（札幌・函館）/ S-C 7。

さらに **fold の入れ子（=実質1観測）を認めた場合の正しい期待値**は「セグメントごとに符号がコイン投げ」であり、
偶然期待は **27 × 0.5 = 13.5**（α推定可能な27セグメント）。観測 11 は**それすら下回る**。

## 5. 何が分かったか（次に効く形で）

1. **セグメント別学習は、目的変数を3着内に変えても効かない**。
   Δα の符号は全体でコインフリップ（47〜49%）、S-C に至っては 25.6% と**明確に悪化**する。
   S-C（場×馬場20分割）は学習データが1セグメント平均345R しかなく、
   MINE の複勝ROIが専用80.5% < 汎用81.7%・的中率54.4% < 58.0% と**データ減の害が素直に出た**。
   SPECIALIST報告の「データ減の害が特徴重み差の益を上回る」は3着内でもそのまま成立する。
2. **唯一の非自明な残り火は「ダ短（ダート<1400m）」**。
   汎用の α_place が **0.000**（＝汎用モデルはダート短距離で市場に何も足していない）のに対し
   専用は **+0.065** を6fold連続で出す。SPECIALIST（1着の土俵）でも通過した唯一の区分と一致する。
   ただし **z≈+1.7 で有意でなく・複勝CONFIRM 70.2%・OOS対数損失の改善も最大 +0.001 nats/頭**。
   **買える材料ではない**。追うなら「ダ短だけ n を増やして（例: 過去年次の追加ハーベスト）
   独立窓で再測定する」以外に道はなく、現データでの再分析は後知恵になる。
3. **場（venue）で切る設計は検証窓と相性が悪い**。JRA は場ごとに開催が季節で偏るため、
   3ヶ月窓では1つの場に最大2fold しか立たず、CONFIRM に至っては中山・京都が消える。
   **今後「場別」を検証するなら、窓は月次3分割ではなく「開催回」単位か、
   同一場の同季節を年跨ぎで揃える設計にしないと測れない**（本報告の最大の設計上の学び）。

## 6. 限界（事前登録の§既知の限界 + 実行後に判明した分）

1. **市場側は単勝オッズの Harville 近似**であり事前複勝オッズではない（PLACE_SYSTEM と同じ限界）。
   複勝ROIは実払戻ベースなので正しいが、α_place の市場側は近似である。
2. **α の fold は入れ子**（累積学習）。「3fold連続」は独立3試行ではなく実質1観測。
   本報告はこれを §1-2/§4 で明示的に割り引いて判定した。
3. **n が小さい**。S-C は VALIDATE 平均44R・CONFIRM 平均34R。
   **n<30 のセル（S-C CONFIRM の東京芝23R・阪神芝30R 等）はすべて参考値**。
   複勝ROIの標準誤差は n=40 で ±20pt 程度あり、95%基準は運の要素が大きい。
4. **S-A/S-C は一次基準を構造的に満たせない**（§1-1）。事前登録は変更していないが、
   このため「一次通過3件」は S-B 由来に限られる。
5. **ヌル検査は本実験では未実施**。PLACE_SYSTEM §1-4 で「α>0 連続はヌルでも通る」ことが
   既に実証されており、本実験は**その基準で誰も二次を通っていない**ため、
   偽陽性率の再測定をしても結論（不成立）は動かないと判断した。
   逆に言えば **§5-2 のダ短を追うなら、ヌル検査（`rule_audit.py --null-sweep` 相当）が必須**。
6. 三連複・ワイドは推定オッズ依存で構造的に壊れる（§3）。参考値としてのみ記載。
