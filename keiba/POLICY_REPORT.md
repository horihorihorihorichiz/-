## 3. ヌル統制（MINEラベルシャッフル×100、同一手続きで学習→実VAL/CONFで評価）

- 100回中 **82回はヌルでも「常時見送り」を学習**（賭けなし）。賭けた18回の成績:
  - VAL ROI: p5=31.5% / p50=67.9% / **p95=78.3%**（利益 p5=-8,230円 / p50=0 / p95=0）
  - CONF ROI: p5=31.1% / p50=70.5% / **p95=95.4%**（利益 p5=-5,620円 / p50=0 / p95=0）
- 解釈: この学習機構が偶然に「賭ける方策」を出した場合、実VALでは中央値68%・95%点でも78%と
  **確実に負ける**。実データで学習した「常時見送り」は、機構が正しく働いた結果（利益0 ≥ ヌルp95利益0、
  ヌルの負け分布を回避）であり、かつ「賭けて勝つ方策」はヌルと区別できる形では存在しなかった。

- 一次基準「実方策のVAL/CONF ROI > ヌル95%点」: **判定不能側で不成立**。実方策は賭けないため
  ROIが定義されず、「賭けて100%超」を示す証拠はゼロ。
- 実弾水準「VAL/CONF両方ROI>100% かつ n_bet>=80」: **n_bet=0で未達**。

  「レースごとに最適な戦い方」を1本の木にすると、その答えは「全レース見送り」になる。
