## 3. 試行数の申告（Bonferroni）

**総試行 = 7**（スクリーニング6特徴 + B-sd22最終判定1本）。
最終判定の一次基準のz閾値は片側 p ≤ 0.05/7 = 0.00714 → **z ≥ 2.45** をBonferroni込みの合格線とする。

## 4. スクリーニング（MINEのみ・6試行）

各特徴 f ∈ {pos_var, pace_lv, pace_gap, fwd_fin, grind, unlucky} について:

- モデル = **Plackett-Luce条件付きロジット（1→2→3着、V99Wと同一の尤度）**。
  効用 u_i = **log pm_i（オフセット・係数1固定）** + b·s16_i + γ·f_i
  （s16 = 凍結B-sd16スコア。b, γ は tr80 で最尤推定、正則化なし）
- ベースライン = u_i = log pm_i + b·s16_i（bをtr80で推定）
- **増分ΔLL = va20 での合計対数尤度の差**（ホールドアウト。in-sampleのΔLLは常に≥0なので使わない）
- **選択規則: va20 ΔLL > 0 の特徴だけを B-sd22 に載せる。**
- 診断（選択には使わない・報告のみ）: 全MINEでの γ 推定値と数値ヘッセ行列によるSE・Wald z、
  in-sample ΔLL、芝ダ×距離帯6群ごとの va20 ΔLL 分解と群別γ（全MINE・群内推定）。
  unlucky と grind は任務指定の重点確認として群別表を必ず載せる。

選択数 k が 0 なら B-sd22 は作らず、その旨を報告して終了する（VAL/CONF未接触のまま）。

## 5. B-sd22（最終1試行）

- Z22 = Z16（12成分z + corner4z） + 選択k特徴のレース内z（k<6でも名称はB-sd22とする）。
- 構造・学習はV99W2腕2のB-sd16と完全同型:
  全体1本 wg22（リッジλ_g22、w0=0）→ 6群（芝ダ×距離帯）の ws22（リッジでwg22へ縮小、λ_sd22）。
- λ選択（MINE内部 tr80→va20 NLL/R、グリッドはV99W2と同一・変更禁止）:
  λ_g22 ∈ {0.0003, 0.001, 0.003, 0.01, 0.03}、λ_sd22 ∈ {0.01, 0.03, 0.1, 0.3, 1, 3}。
- 確定学習 = MINE全体（選んだλで wg22 → ws22）。

## 6. 最終判定（VAL/CONF各1回・変更禁止）

**一次基準 P1（市場オフセット条件付きロジットの真のOOS増分）**
- 全MINEで2モデルを推定して係数を凍結:
  A: u = log pm + a·s16 ／ B: u = log pm + a'·s16 + c·s22（PL 1→2→3、正則化なし）
- VAL・CONFで（係数固定のまま）ΔLL_P = LL(B) − LL(A) を算出。
- **合格 = ΔLL_P > 0 が VAL と CONF の両方、かつ VAL+CONF プールの
  レース単位ペア差 z = mean(d)/(std(d)/√n) ≥ 2.45（Bonferroni 7試行）。**

**二次基準 P2（PL枠組みでの置換価値）**
- B-sd22スコア（ws22群別）とB-sd16スコア（凍結）の PL ΔLL/R を3期で比較。
- 合格 = VAL と CONF の両方で B-sd22 > B-sd16。

**総合合格 = P1 と P2 の両方**。片方のみは「部分通過」と正直に書く。未達は未達と数字で書く。

**併記（判定に使わない）**
- 4券種（単勝1/複勝1/複勝2/三連複1、100円均等、タイブレーク=現行WAvg→馬番小 = V.bet_metrics）の
  的中率/ROIを3期ともB-sd16と並記。ROIは既定規律どおり **VAL/CONF両方100%超 + n≥80** 以外は主張しない。
- 直接対決OOS: u = log pm + c·s22 vs u = log pm + a·s16（全MINE推定→凍結→各期LL）。
- 群別（6群）のΔLL_P分解。

## 8. 事前に分かっている限界（先に書く）

1. pace_lv / pace_gap はレース全体のラップで馬個体のラップではない（CORNER登録済みの限界）。
2. unlucky|top3 は CORNER単独検定で MINE z=−3.90 → VAL z=−0.28 と減衰した実績がある。
   今回は「市場+s16を条件にした残差」という別の問いだが、同じ方向に減衰する可能性はある。
3. grind は単独ではMINEすら通っていない（|z|=1.6）。群別で拾えなければ載らないのが自然な帰結。
4. s16 と新6特徴は同じ過去走レコード由来なので相関があり、増分は単独効果より小さく出るのが普通。
5. va20は約1,291Rで、1本あたりの増分検出力は限られる。選択漏れ（偽陰性）は起こりうる。
