## Ver.100.1: 得点システムの重み学習（同日追加・ユーザー指示「得点システムを工夫してもいい」）
- **何をしたか**: s2=11要素の等重み合算だった得点を、`fit_score.py` が **Plackett-Luce（3着内の並び）の尤度で重み学習**（L2=0.05で等重みに正則化、ホールドアウトで改善した時だけ採用）。
- **学習された構造（1.0=従来）**: 上がり3F LTS **1.08↑**・距離適性DSI **1.09↑**／枠順FSI **0.75↓**・クラスNSI **0.82↓**・展開 **0.79↓**・斤量馬体重HCS **0.92↓**
  → 監査の指摘（NSI二重計上・展開レバー過大・FSI手調整）とデータの答えが一致。
- **結果**: 3着内並びNLL test 2.2160→2.2135、place連鎖 6.1536→**6.1496**、ROI test 168%→**181.9%**（scale0.9）。
  改善は本物（ホールドアウト）だが小幅。**大幅な伸びしろは「データ量→正則化を緩める」「芝/ダート別・JRA/NAR別の重み」「tsi有りデータでの学習」**にある。
- 再学習手順: `python fit_score.py --l2 0.05 --write && python fit.py --test <直近週末> --write`（収穫が増えるたびに回す）。

## Ver.101 第1弾: 1年収穫+自前スピード指数（7/14）
- **収穫完走**: 2025/7/13〜2026/7/12の全JRA平地 **3,390レース**（結果・全券種最終オッズ盤込み）。
- **自前スピード指数**: 結果ページ再取得(enrich.py)→基準タイム推定(speedidx.py)で**46,404走に指数付与**。
  netkeiba純正タイム指数と**R²=0.63**＝プレミアム依存を公開データで概ね再現。馬柱の直近1年走をカバー。
- **1年データ+指数での再学習結果**（train 3,017R / test 127R）:
  - 勝者α=0は大標本で確定（単勝の当て合いでは市場に勝てない）。α_place=0.03は両セットで市場超え維持。
  - **乖離バケット（モデル1位が4番人気以下=929R）の単勝フラットROIが85%→99%に改善**＝
    モデルの独自主張が市場効率の境界線に到達。指数の効果はここに一番出た。
  - エッジ購入ROI: train 3,246R **88.9%**(85.8%から+3pt) / test 144R **134.5%**。**壁(100%)はまだ**。
- **結論**: 指数は効いたが単独では壁を越えない。次弾=騎手ファクター(データ取得済み)と
  Ver.2モデル(生特徴量・指数の実差を使う)で情報をさらに積む。

## Ver.101 第2弾: 騎手ファクター+Ver.2モデル（7/14「今日全部やれよ」実施分）

  **ROIの壁(train約85%)は不変**。= 結論:「**公開情報は最終オッズに全部織り込まれている**」を
  3,000レースで確認。モデルの出来ではなく市場効率の問題。
- **自前指数のライブ配線**: fetch_raceがspeedidx.json(92,808キー)を自動参照。七夕賞の再取得で
  タイム指数16走→**91走**に。手貼り不要化が完成（貼りは上書きとして残る）。
- **残された+EVへの道（次の主戦場）**:

     効率化する前。モデルが最終オッズと同等の精度なら、朝の甘い価格に対してはプラスになり得る。
     → paper.pyが実行時オッズを記録開始（今週末から）。**紙上運用が「本当の実験」**。
  2. NAR（薄い市場）の別フィット。

## Ver.102: エージェント実験による統合チャンピオン U2（7/14「もっと高められる/エージェント駆使して」）
- **やり方**: KPI=「3着内馬をモデル5位以内に」。共通ハーネス(exp_harness.py)+共通ゲート
  (train>67.3/test>66.6)で6つの特徴量ファミリーをエージェント並列実験→**全ファミリーがゲート突破**→統合。
- **勝ち特徴12個**（features2.py）: コース適性B（今日の条件一致成績・距離帯ベスト・ピッタリ距離複勝率・
  芝ダ替わり・道悪適性）＋上がり文脈（距離補正残差・差し脚の質）＋フォーム（2走前ベスト・休養×前走）＋
  クラス（昇級×前走内容・頭数変化）。
- **統合チャンピオンU2の成績**（27特徴・L2=0.10・市場情報不使用）:
  | | 旧WAvg | R3 | **U2** | 市場天井 |
  |---|---|---|---|---|
  | 3着内馬が5位以内(train) | 61.8% | 67.3% | **68.7%** | 73.8% |
  | 同(test) | 66.3% | 66.6% | **70.6%** | 72.6% |
  | 3頭全員5位以内(train) | 22.0% | 28.6% | **30.5%** | 38.7% |
- **ライブ実証**（test期間のレース・学習に不使用）: 七夕賞(11→6→9)=⑪1位・⑥3位で2/3捕捉／
  彦星賞(15→1→10)=⑮2位・①3位で2/3捕捉（旧システムはこの2頭を軸から外して全滅していたレース）。
- 本採用済み: params_v2.jsonのweights_win=U2、predictの得点表示・ランキングはこれで出る（--no-v2で旧に戻せる）。
- R5 血統: 父11,367頭を収穫し種牡馬as-of特徴×3変種を実験→**ゲート棄却**（test 68.5-69.0 < 70.6）。
  馬自身の実績に既に織り込まれている（血統が効く新馬戦はモデル対象外）ため。sire_map.jsonは資産として保持。
