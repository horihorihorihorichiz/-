# PLUSエンジン — 「プラスの根拠があるときだけ撃つ」への作り変え（2026-08-22）

指示: 「システムを全部プラス生み出せるように作り変えて」

## 設計思想（ここが作り変えの本体）

確定オッズの情報だけでは全レースをプラスにできない（控除率20〜25ptに対し
モデルの上乗せは2〜4pt。8/21〜22の全数測定で確定）。だから**逆にする**:

> **「全レースを買ってプラス」ではなく「プラスの根拠がある発火だけ買う」。**
> 発火しないレースの損益はゼロ。発火したものは全部プラス（を狙う）。
> 大半のレースが見送り＝正常動作（Ver.100体制の思想を継承し、発火条件を今日の実測で総入替）。

## エンジン構成

```
順位付け: hori52（49分割2層・検証済み・selfcheck監視下）
              ↓
発火判定: 凍結された発火表（下記）に該当するか
              ↓
該当なし → 見送り（損失ゼロ）
該当あり → 指定の型・指定の額で買い目を出す（購入は人間）
```
