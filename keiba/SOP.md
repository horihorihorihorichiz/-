# 競馬予想 標準作業手順書（SOP）── どのAI/人でも同じ品質で回すための完全手順

**対象**: このリポジトリを引き継ぐ全てのAI（モデル不問）・人間。
**原則**: 判断はこのSOPと `RULES.md` に従う。計算は全て `calc.py`/`predict.py` がやる。**自分の直感で上書きしない**。

---

## 全体フロー（毎レース同じ）

```
STEP1 データ受領   ユーザーから馬柱(9走)+タイム指数+オッズ+馬場+馬体重 を受け取る
STEP2 race_json化  下の「変換規則」で build_<レース名>.py を書く → race_<名>.json 生成
STEP3 実行         python predict.py race_<名>.json --race-id <id> [--budget N]
STEP4 出力         RULES.md §1 の形式で提示（全頭ランキング=得点列必須/買い目/点数/i-PAT）
STEP5 直前更新     馬体重・馬場・最終オッズが変わったら build を直して再実行
STEP6 記録         結果確定後 results.jsonl に追記 → python stats.py で通算を報告
```

race_id の作り方は `RULES.md` §5。GO/NO-GO・買い目構造は predict.py が自動判断する。

## STEP2 変換規則（馬柱テキスト → build_*.py）★この文書の核心

雛形は既存の `build_kasamatsu.py` / `build_sparking.py` をコピーして数字を差し替える。

### レースヘッダ（race dict）
| キー | 決め方 |
|---|---|
| name | 「レース名(格) 場所R ダ/芝 距離」 |
| venue | 場名（JRA10場は `predict.py` が JRA判定。それ以外はNAR） |
| surface | "芝" or "ダ" |
| distance | m |
| field | 頭数 |
| baba | **必ずユーザーに確認**（良/稍/重/不）。当日変わったら差し替え再実行 |
| today_vg | 既定 **2**（変更指示があるときのみ） |
| dist_cat | 距離カテゴリ: **≤1400=S / 1500〜1700=M / ≥1800=L** |
| today_tier | 下のTier表でそのレースの格 |
| nsi_haiten | 既定 **20** |
| dsi_haiten | 既定 **5** |
| race_id | 分かれば入れる（無ければ --race-id で渡す） |

### Tier表（クラス→数値。小さいほど格上）
```
Jpn1/G1=1   Jpn2/Jpn3/G2/G3/地方重賞=2   OP/L(リステッド)=3
JRA3勝/A級(A2)=4   A2B1/JRA2勝=5   B1/B1B2=6   B2B3/B3=7
C1=8   C2/3歳条件戦=9   C3/未勝利/新馬=10
```

### 各馬 Hh(num, name, style, csi, races, kin, wt, ch, off, last_days, boost)
| 引数 | 決め方 |
|---|---|
| num / name | 馬番・馬名 |
| style | 新聞の脚質欄そのまま（逃/先/差/追）。迷ったら直近3走の4角位置: 1-2番手→逃or先 / 中団→差 / 後方→追 |
| csi | コース・距離実績: 当該コース同距離で **3勝以上or圧倒的=5 / 1-2勝or連対複数=2.5 / 実績なし=0** |
| races | 直近9走（新しい順）を R() で（下記） |
| kin | 今回の斤量 |
| wt / ch | 今回の馬体重 / 増減（**未発表なら前走馬体重・ch=0** とし、発表後に差し替え） |
| off | **道悪（稍/重/不）レースでの着順リスト**（新しい順）。TAS(道悪適性)に使う |
| last_days | 前走からの日数（races[0].days と同じなら省略可） |
| boost | ユーザーがブースト指定した時のみ 1 or 2（既定0） |

### 各走 R(dist, fin, field, umaban, c4, agari, vg, tier, days, pace, bi, tsi, surface)
| 引数 | 決め方 |
|---|---|
| dist / fin / field / umaban | 距離 / 着順 / 頭数 / 馬番 |
| c4 | 4角通過順位（通過欄の最後の数字。「1-1-1-1」なら1） |
| agari | 上がり3F（「後 40.4」の数値） |
| vg | 既定 **2** |
| tier | そのレースの格（上のTier表） |
| days | **レース日から今回までの日数**（日付から計算。中X週なら X*7+4 目安） |
| pace | ペース欄: H / M / S（無ければ None） |
| bi | 馬場指数（タイム指数表の括弧内。無ければ None） |
| tsi | **タイム指数**（タイム指数表の数値。無ければ None） |
| surface | 芝走だけ "芝" を明示（既定"ダ"） |

**注意**: 取消/除外走は除いて9走に満たなくてよい。地方→JRA転入などでタイム指数が無い走は tsi=None。

## 禁止事項（どのAIでも）
- 購入/投票確定ボタンを押す・認証情報(INET-ID/暗証番号/P-ARS)を読む/保存する/送る
- SランクをEV妙味で軸から外す／人気本命(≤3.5倍)を買い目から消す／短オッズ安全網を勝手に切る
- 得点列・点数・i-PAT形式の省略／100円単位以外の金額
- ユーザー指示の拡大解釈（迷ったら聞く。7/9笠松の誤読を繰り返さない）
