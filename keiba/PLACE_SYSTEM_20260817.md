# 3着内(複勝圏)特化システム 検証報告（2026-08-17）

V8検証で唯一プラスだった材料（NDCG@3 +0.0054・V+C 1550R・P(改善>0)=0.95＝「勝ち馬当てはダメだが
3着内の並びは僅かに良い」）を受けて、**目的変数そのものを3着内に変えた**モデルを作り、
複勝・ワイド・三連複という「3着内の並びが効く券種」で市場に勝てるかを測った。

---

## 結論（先頭）

**α_place は事前登録の基準を満たした（史上初めて α が正になった）。しかし付加情報の大きさは
実用に対して2〜3桁足りず、券種の検証は全て不合格。買える結論は1つも出ていない。**

| 事前登録の判定 | 基準 | 実測 | 判定 |
|---|---|---|---|
| ① α_place>0 が3フォールド連続 | 3連続 | **24フォールド連続**（v3place / v8place とも。27foldで26回正） | **合格** |
| ② 三連複 EV≥1.2 @VALIDATE | n≥40 & ROI≥110% | n=153,618 / **ROI 19.6%**（v8place: n=148,133 / 24.0%） | **不合格** |
| ② ワイド EV≥1.2 @VALIDATE | n≥40 & ROI≥110% | n=29,181 / **ROI 39.5%**（v8place: n=28,089 / 40.2%） | **不合格** |
| ③ 三連複 EV≥1.2 @CONFIRM | n≥25 & ROI≥105% | n=94,085 / **ROI 34.8%**（v8place: 29.5%） | **不合格** |
| ③ ワイド EV≥1.2 @CONFIRM | n≥25 & ROI≥105% | n=18,790 / **ROI 55.0%**（v8place: 50.3%） | **不合格** |
| ④ 複勝単体（モデル3着内確率1位のflat） | ベンチマーク=市場1-3番人気 | **VALIDATE 80.7% < 84.9%（市場）** / CONFIRM 77.9% < 80.9% | **ベンチマーク割れ** |

**①が合格しても②③④が全滅する理由**（本報告の核心）:

1. **α_place は正だが小さすぎる**。out-of-sample の対数損失改善は **1頭あたり +0.00014**
   （VALIDATE・v8place）。同じデータで「単勝オッズの柔軟な変換だけ」（3次多項式＋勝率＋頭数）を
   足すと **+0.00057** 改善する。**モデルが足す情報は、単勝オッズの読み替え方を変えるだけで
   得られる分の 1/4 しかない。**
2. **ヌル検査で基準の弱さが露呈**。モデルの3着内確率をレース内でシャッフル（情報ゼロ）しても
   α は 8種中5種で正、最大 +0.0216（z=+2.75）。**「α>0が3フォールド連続」はノイズでも通る基準**である。
   実データの α=+0.0424 はヌル8本すべてを上回る（0/8）ので「本物だが小さい」が正しい読み。
3. **3着内の並びの質は市場に負けたまま**。モデル単体は捕捉3で **−3.4pt**、NDCG@3で **−0.042**
   （V+C 1549R・P(改善>0)=0.000）。α_placeブレンド後でようやく市場と**同着**
   （ΔNDCG +0.0004・95%CI −0.0011〜+0.0021）。**追い抜いてはいない。**
4. **券種EVは推定の構造上、勝者の呪いで壊れる**（§2）。EV≥1.2で選んだ組合せの
   モデル確率は実測ヒット率の **約3倍**、推定オッズは実払戻の **約3倍**。両者が同方向に効いて
   EV 3.5 に対し実ROI 0.2〜0.5 になる。ブレンド確率で同じことをやると **EVが1を一度も超えない**
   （VALIDATE/CONFIRM の全組合せ中の最大EV = 0.95 / 0.98）。

**土俵を「勝ち馬」から「3着内」へ変えると α の符号は反転した（V7/V8の −0.13 → +0.04）。
これは4連敗の後で初めての質的変化であり、記録に値する。だが控除率20〜25%の壁に対して
+0.04 の α が生む上積みは1%未満で、買い目に落ちるものは何も無い。**

### α_place の定義（事前登録）

事前の**複勝オッズは台帳に無い**ため、市場側は単勝オッズから作る:

```
p_win  = (1/単勝オッズ) をレース内で和1に正規化   （控除率補正）
q_market = Harville近似（Plackett-Luce）で p_win から作った P(3着内)  … 和=3
q_model  = 二値モデルの生出力をロジットの平行移動でレース内和3に正規化
主指標   P(3着内_i) = σ( α·logit q_model_i + β·logit q_market_i + c )     ← α_place
副指標   u_i = α·log w_model_i + β·log p_win_i を1着→2着→3着の逐次選択尤度で（V7と同じ形）
```

係数は月次WF（fold月 m の係数は m より前の月だけで最尤推定）。SEはレース単位のクラスタ頑健。

### 1-4. 頑健性②: ヌル検査（RULES §偽陽性率）

モデルの3着内確率を**レース内でシャッフル**して情報を完全に破壊し、同じ手順で α を推定した
（fold=202608・学習6,704R・8シード）。

| | 実データ | ヌル8本 |
|---|---|---|
| v8place α | **+0.0424** (z +2.67) | 平均 +0.0082 / 最大 **+0.0216**（z最大 **+2.75**） / 実データ以上 **0/8** |
| v3place α | **+0.0358** (z +2.25) | 平均 +0.0120 / 最大 **+0.0320**（z最大 +2.55） / 実データ以上 **0/8** |

**手順そのものが α に約 +0.01 の正のバイアスを持つ**（シャッフル後の logit q_model が

- **「α>0が3フォールド連続」という事前登録の合格基準は、実力ゼロのモデルでも通る**

- 実データの α はヌル8本すべてを上回る（0/8）。ヌルの分布（平均+0.008・SD≈0.009）に対して
  約3.8σ。**「本物だが小さい」**が正しい読み方。

## 2. 券種別EV（二次判定）— 三連複・ワイド

### 2-1. 手順と、その手順が抱える問題

台帳に**組合せの事前オッズが無い**（あるのは的中組の払戻だけ）ため、EVの計算には市場オッズの
推定が要る。手順:

```
モデル3着内確率 q_model(和3) → PL強度 w = harville⁻¹(q_model) → 三連複の理論確率（全C(n,3)通り）
市場 p_win → 同じ機械で市場側の三連複確率
組合せオッズ: log(実払戻/100) = a + b·log(1/p_market_combo) を「前月までの的中組」で回帰しWF推定
EV = p_model_combo × odds_est   （閾値1.2は事前登録・事後変更なし）
的中時の払戻は **実払戻** を使用
```

**素の版は EV推定が壊れた**: 平均EV 4.0 に対し実ROI 39%。原因は §5 の Harville較正表の歪みが
「3着内確率→PL強度」の逆変換で裏返り、3乗されて効くこと。そこで **やり直し1回**として、
model側・market側の組合せ確率それぞれにレース内温度較正 `p_cal ∝ p^γ`（γ は前月までの的中組で最尤推定・
月次WF）を掛けた版を作り、再実行した（`place_combo.py`）。**判定基準は一切変更していない。**

推定された γ（最終fold）: **γ_model = 1.01、γ_market = 0.85**。
→ **モデル側の組合せ確率は温度の意味では既に較正済み**で、歪んでいるのは市場側のHarvilleの方だった。
そのため較正しても結果はほとんど動かなかった。

### 2-3. なぜ壊れるか（勝者の呪いの定量）

選ばれた組合せについて「モデル確率」と「実測ヒット率」を突き合わせた:

| 分割 | 券種 | 平均モデル確率 | 実測ヒット率 | **倍率** | 平均EV | 実ROI |
|---|---|---|---|---|---|---|
| VALIDATE | 三連複 | 0.00235 | 0.000749 | **3.14×** | 3.59 | 19.6% |
| VALIDATE | ワイド | 0.02896 | 0.011857 | **2.44×** | 2.44 | 39.5% |
| CONFIRM | 三連複 | 0.00298 | 0.001020 | **2.92×** | 3.35 | 34.8% |

  EV 3.5 が実ROI 0.2 になる。
- 三連複はレース平均176点/約400点が発火した。**閾値が閾値として機能していない**＝
  この機械でEVを計算すること自体が誤り。
- **ブレンド確率（α_place を効かせた実運用形）では EV が一度も1を超えない。** α=+0.04 の
  上積みは控除率25%の壁の前で完全に無力。

- **全ての枠で100%未満**（三連複の払戻率75%・ワイド77.5%の壁を一度も超えない）。
- **モデル単体は市場に負ける**（VALIDATE 三連複top5 で 72.2% vs 80.3%）。
- ブレンドは市場と互角（CONFIRMで一部上回るがn=675Rでの±数ptは誤差範囲）。
- v8place では CONFIRM の model top1 三連複が **95.1%（55R的中）** と全表で最高になるが、
  **同じ v8place の VALIDATE では 81.6% で market の 89.4% に負けている**。
  v3place も CONFIRM 85.8% / VALIDATE 89.8%(market 91.5%) と分割をまたいで一貫しない。
  675R・的中47〜55Rの数字であり、**部分集合の高い数字は拾わない**（RULES §後知恵禁止）。

**→ 二次判定: 三連複・ワイドとも VALIDATE / CONFIRM 全て不合格。**

## 3. 複勝単体（三次判定）

モデルの3着内確率1位の馬を複勝flat 100円。ベンチマークは市場1-3番人気の複勝flat。

| 分割 | R数 | モデル1位 的中 / **ROI** | ブレンド1位 **ROI** | 市場1-3番人気 的中 / **ROI** | 市場1番人気 **ROI** |
|---|---|---|---|---|---|
| MINE | 5,014 | 57.7% / **81.5%** | **84.8%** | 52.6% / **82.6%** | 84.7% |
| **VALIDATE** | 874 | 59.7% / **80.7%** | **86.6%** | 54.2% / **84.9%** | 86.0% |
| **CONFIRM** | 675 | 57.0% / **77.9%** | **83.2%** | 51.5% / **80.9%** | 83.0% |

（v8place。v3place: モデル1位 VALIDATE 78.0% / CONFIRM 79.0%、ブレンド1位 85.8% / 83.2%）

- **モデル1位は的中率で市場1-3番人気を上回る**（VALIDATE 59.7% vs 54.2%）が、
  **ROIでは負ける**（80.7% vs 84.9%）。当てているのは「人気馬の中でさらに堅い馬」であり、
  的中率の上積みが配当の低下に食われている。**複勝は的中率を上げても回収率は上がらない券種**である。
- **ブレンド1位が最良のライン**（VALIDATE 86.6%・CONFIRM 83.2%）だが、
  市場1番人気（86.0% / 83.0%）に対し **+0.6pt / +0.2pt** に過ぎない。
  **控除率20%の壁（=80%）は超えるが、100%には14pt足りない。**
- 市場ベンチマークの数字が variant 間で0.1pt動くのは、同オッズ馬のargsortのタイブレークが
  台帳の並び（＝モデルのスコア順）に依存するため。実質同一。

## 4. 3着内の並びの質（V8のNDCG@3と同じ土俵）

## 5. Harville近似の限界（本検証の最大の弱点・必ず読むこと）

**事前の複勝オッズを1件も持っていない。** 市場側の3着内確率は全て「単勝オッズ→Harville」の
近似であり、その近似は実測で明確に歪んでいる。

### 5-1. Harville 3着内確率の較正（全馬・全fold月・91,210頭）

| Harville q | 0.039 | 0.146 | 0.247 | 0.348 | 0.448 | 0.548 | 0.648 | 0.747 | 0.847 | 0.937 |
|---|---|---|---|---|---|---|---|---|---|---|
| **実際の3着内率** | **0.052** | **0.178** | **0.268** | 0.339 | 0.411 | 0.487 | 0.573 | 0.673 | 0.752 | **0.877** |
| 頭数 | 41,856 | 15,026 | 8,887 | 6,983 | 5,542 | 4,508 | 3,365 | 2,422 | 1,748 | 873 |

**ロングショットを過小評価（0.039→0.052、相対+33%）、本命を過大評価（0.937→0.877）。**
教科書どおりのHarvilleバイアスが、この台帳でもそのまま出ている。

### 5-2. 実際の複勝払戻との突き合わせ（3着内馬 19,557件）

| 実払戻の平均 | Harville含みオッズ(0.8/q)の平均 | 比 |
|---|---|---|
| **3.350倍** | **4.208倍** | **0.796** |

Harville から作った「複勝の含みオッズ」は実際の複勝払戻より **平均25%高い**。
つまり Harville は3着内馬の確率を系統的に低く見積もっている。

### 5-3. これが結論に与える影響（正直に）

1. **α_place>0 のうち約半分は、この歪みの形直しである**（§1-3 の flex で α が半減）。
   残り半分は「単勝オッズのどんな変換でも作れない情報」だが、
   **本物の複勝プールが既にその情報を織り込んでいる可能性は、この台帳では検証不能**。
   複勝は単勝と別プールで、複勝オッズは単勝オッズの関数ではない。
   **「複勝市場に勝った」とは一切主張できない。主張できるのは「単勝オッズを条件にしたとき
   3着内予測に僅かな残差情報がある」まで。**
2. **券種EVの失敗のうち、オッズ推定側の3倍過大評価は近似の責任**である。
   本物の三連複・ワイドのオッズがあれば、この誤差は消える。ただし**確率側の3倍過大評価は
   モデルの責任として残る**ので、実オッズがあっても EV≥1.2 が ROI 110% を満たす見込みは薄い
   （§2-4 のオッズ推定不要な top-k flat も全て100%未満）。
3. **次にやるなら、まず事前の複勝・ワイドオッズを収穫すること。**
   それ無しにこの路線を数字で進めることはできない。

## 6. その他の限界・注意

1. **確定オッズ前提**。実運用で使えるのは直前オッズなので、本結果は実運用より**甘い条件**。
2. **コーパスは実効7,699R（202307〜202608）で2023-2024が歯抜け**。αは学習量に対して単調増加中で、
   収穫が進めば α がもう少し伸びる可能性は残る（ただし OOS対数損失の改善は 0.0001 のままで
   増える兆候が無い）。
3. **v8place の V8特徴は3着内の土俵では一貫して効いた**が、gain比では `cs_fin` 2.48% /
   `cs_top3` 1.75% など F4（同コース実績）系のみで、F1（当日トラックバイアス）・F2（前走不利）は
   V8報告と同じく下位。特徴上位は cond_perf 19.4% / wavg 12.5% / fin_frac 11.0% / field 6.4%。
4. **γ較正のMLEは直近1,500レースの窓**で行っている（全期間だと1推定に数分かかるため）。
   γ は 0.97〜1.05（model）/ 0.78〜0.88（market）の狭い範囲で安定しており、窓長の影響は小さい。
5. **組合せの点数に上限を設けていない**（事前登録どおり EV≥1.2 を全て買う）。
   点数を絞る後知恵の探索は行っていない。
6. **オッズ較正の回帰は的中組だけを標本にしている**（外れ組の払戻は存在しないため）。
   的中組は真の確率に比例して抽出されるため、推定オッズは実際より低めに出る＝
   **EVを過小に見積もる方向のバイアス**であり、不合格の結論を弱めない。
7. **PL逆変換の収束バグを1件修正した**（`pl_from_place` が n=4 の一極集中ケースで残差1.2e-3のまま
   返っていた。停止条件を「wの変化量」から「残差 max|harville(w)−q|」に変更）。
   実データ（n≥5）では平均85反復で残差1e-9に到達。selftest 通過を確認済み。

## 8. 所見（次に何をするか）

1. **土俵を変えたことで α の符号は初めて反転した**（勝ち馬 −0.13 → 3着内 +0.04）。
   「モデルは順位そのものではなく、3着内に入るかどうかの二値にだけ残差情報を持つ」
   という切り分けが得られたのは収穫。**ただし +0.04 は控除率の壁に対して無力。**
2. **この路線を数字で進める前提条件は「事前の複勝・ワイド・三連複オッズの収穫」**。
   それ無しでは市場側が全てHarville近似となり、αの半分が近似の形直しに食われ、
   券種EVはオッズ推定誤差で壊れる。**収穫が先、モデルは後。**
3. **事前登録の合格基準「α>0 が3フォールド連続」は弱すぎた**（ヌルでも通る）。
   今後の登録は最低でも「ヌル分布の95%点を超える」「OOS対数損失の改善が
   1頭あたり X nats 以上」といった**大きさの基準**を含めること。今回の実測値を基準設定の材料にできる:
   ヌルα の平均+0.008・最大+0.032、OOS対数損失の改善で意味を持つ水準は 0.001/頭 のオーダー。
4. **V8の22特徴は「3着内の二値」でだけ一貫して効く**（α で +0.007、flex下でも23fold連続で正）。
   使い道があるとすれば買い目の並び（複勝・ワイドの相手選び）であって、勝ち馬予測ではない。
   ただし**市場を超えないので、実弾のルールには入れられない**。
5. **実運用への反映: なし。** Ver.100のエッジ購入・紙上運用の設計は変更しない。
