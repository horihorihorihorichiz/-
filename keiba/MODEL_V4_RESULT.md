## 2. V4で変えた3点と、その理論的根拠

### (1) today_vg のバグ修正 — `hist_fix_vg.py`
6,701件を `course.course_vg(venue, surface, dist)` で再計算。5,212件が書き換わり、
VG1=1000 / VG2=1489 / VG3=1423 / VG4=2789 に分散した。

### (2) 枠番・今日の馬場を特徴に追加 — なぜ必要か
> **理論**: モデルの得点が勝率の十分統計量なら、**観測可能などんな変数でも順位を入れ替えられないはず**。
> ところが実際は「枠」という観測可能な変数で順位が逆転していた（外枠2位 27.2% > 1位 24.4%）。
> これは欠落変数バイアスの証明であり、枠が持つ情報がモデルに入っていないことを意味する。

追加した特徴（`fit_v2.RAW_FEATS` / `CTX_FEATS`。**レース内z標準化を通さない生値**）:

| 特徴 | 理由 |
|---|---|
| `waku` / `waku_rel` / `umaban_rel` | 同じ馬番8でも18頭なら内、9頭なら外。頭数で正規化しないと意味が変わる |
| `waku_x_dirt` | 枠の有利不利は芝とダで逆向き（ダは砂被り回避で外が楽） |
| `baba_today` | 「今日が不良か」そのもの |
| `wet_x_baba` | 道悪の日にだけ、その馬の道悪実績が効く（交互作用。良の日は0で自動的に無効化） |
| `today_vg` / `is_dirt` / `field` | レース文脈 |

※z標準化を通すと、枠番は「馬番の順序」に潰れて絶対的な内外の意味が消え、
　レース単位の値（今日の馬場など）は全頭同値なので**全部0になって消える**。だから生値で渡す。

**結果**: 外枠2位の逆転は**消滅**した（V4: 1位26.2% > 外枠2位21.9%）。狙い通り。
ただし**特徴単体の重要度は低い**（waku=#32/36, baba_today=#34）。
＝汎用的に効いたのではなく、**特定のバイアスをピンポイントで潰した**という性質の貢献。

### (3) 目的関数を LambdaRank → 二値(1着か否か) — ここが効いた本体
> **理論**: LambdaRank(NDCG@5, label_gain=[0,1,3,7]) は**3着内の並び全体**を最適化する。
> 2着・3着にも利得が付くので、1位の枠は「勝ち切る馬」ではなく
> **「安定して3着内に来る馬」**で埋まる。しかもNDCGの割引は対数なので、
> 勝ち馬を1位に置くか2位に置くかの差は目的関数上ほとんど罰されない。
> これが観測された症状そのもの＝**モデル1位の勝率24.8%に対し市場1番人気は32.8%**。
>
> 二値(logloss)は**賭ける対象そのもの**（勝つか否か）を推定する proper scoring rule なので、
> スコアの最大値＝推定勝率の最大値になる。順位の意味がブレない。

さらに **種違い5本の平均**（レース内zで合議）。1本だと学習のブレがそのまま順位に出るため。

| 変種 | 捕捉5 | 1位勝率 | **市場との差** | 1位単勝ROI | 三連複1-2-3位ROI | 外枠2位の逆転 |
|---|---|---|---|---|---|---|

| V3特徴＋VG修正 | 67.8% | 24.8% | −2.8pt | 75.7% | – | あり |

### 合格ゲート判定（MODEL_V4_PLAN.md）
| ゲート | 目標 | 実測 | 判定 |
|---|---|---|---|
| ①1位勝率 − 市場implied | ≥ 0pt | −2.2pt（V3の−3.0から改善） | **✕未達** |
| ②1位単勝ROI | ≥ 85% | 76.5%（V3の74.4から改善） | **✕未達** |

| ④外枠2位の逆転が消える | 消える | 消えた | ○ |

### ①②が未達である理由（理論）
パリミュチュエル方式で控除率を超えるには、原理的に2つしかない:
- **(a) 胴元プール（＝全参加者の集合知）より正確に推定する**
- **(b) プールの価格が、プール自身の推定からズレている所を突く**

①②は (a) を測る指標であり、**測った結果モデルは市場より下**だった。
モデルが持っていない情報（調教の動き、当日の気配、乗り替わりの含意、厩舎の勝負度合い）を
市場は持っているので、これは驚くべきことではない。
**したがって残る道は (b) だけであり、(b) は定義上オッズを見なければ実行できない。**
「オッズで判断をやめる」は好みの問題ではなく、**測定の結果として現時点では不可能**。

## 4. 「オッズを使わない買い方」の探索 — 見つからなかった

`oddsfree_mine.py` で、オッズを一切使わない条件（馬場・芝ダ・距離・頭数・クラス・場・
開催日目・VG・モデル得点差・モデル1位の枠）を 2,780セル総当りした。
一見きれいな階段が出た:

```
三連複 モデル1-2-3位（1点/レース・オッズ不使用）
  全レース                          n=2200  ROI  76.5%
  1勝クラス                         n= 650  ROI 111.2%
   ＋2日目以降                      n= 568  ROI 123.5%
   ＋良馬場                         n= 416  ROI 148.1%
   ＋メイン4場                      n= 246  ROI 164.8%  dev155.5/conf183.8/最大除外126.4%
  （除外側: ローカル75.9% / 初日25.9% / 道悪51.4%）
```

同じ246レースでV3は85.2% → V4bin2s 164.8% なので「V4にしたから出た」ことは確か。
対照実験も、モデルだけが勝っていた:

| 同じ246Rで買い方だけ変える | ROI | 的中率 | 平均配当 |
|---|---|---|---|
| モデル1-2-3位 | 164.8% | 7.3% | 2,252円 |
| 市場1-2-3番人気 | 66.4% | 10.2% | 654円 |
| ランダム3頭 | 42.6% | 1.2% | 3,497円 |

### ✕ しかし多重検定で落ちた
モデルの並びを**レース内でシャッフルした「実力ゼロの偽データ」**で、同じ2,780セルの
総当りを20回やり直した:

```
偽世界の合格数:   平均 14.8件 / 中央値 8件 / 最大 67件
偽世界の最高ROI:  中央値 236.2% / 最大 924.5%
実測:             合格 14件 / 最高ROI 209.9%（本命ルールは164.8%）
```

**実力ゼロのデータからでも平均14.8件、最高ROI中央値236%が出る。**
実測の14件・209.9%はこの分布の中に完全に埋もれている。
＝**この採掘手続きは三連複では信号と雑音を区別できていない**。164.8%は採用しない。

（原因は三連複の配当分布の裾の重さ。5的中・最大配当除外の門番では、
　1本の万馬券で作られた偽の合格を止めきれない。）

### そして選択バイアスを完全に外すと、こうなる
全2,200Rでの三連複1点（条件による選抜を一切しない）:

| | ROI | 的中率 | 平均配当 |
|---|---|---|---|
| モデル1-2-3位（V3） | 72.5% | 7.1% | 1,016円 |
| **モデル1-2-3位（V4）** | **76.5%** | 6.8% | 1,121円 |
| 市場1-2-3番人気 | 77.8% | 9.7% | 803円 |
| ランダム3頭 | 2.8% | 0.1% | 2,017円 |

- モデルに**実力はある**（的中率6.8% vs ランダム0.1%）
- V4はV3を**+4.0pt 改善**した
- しかし**まだ市場（77.8%）に届かず**、どちらも控除率を超えない

これが選択バイアスゼロの真実であり、§3の結論と完全に一致する。

### ★重要な用語修正
JRAの tier は実際には **{3,4,5,6,10} の5種類しかない**（実データで確認）。
- tier3 = OP/重賞 / tier4 = 3勝 / tier5 = 2勝 / **tier6 = 1勝** / tier10 = 未勝利・新馬

したがって patterns.py の `6 <= tier <= 9` は「上級」ではなく **1勝クラスちょうど**である。
数字（412.2%等）は正しいが、**ラベルが間違っていた**。以後「1勝クラス」と呼ぶ。

## 7. この件から確定した運用原則

1. **馬場チェックは飾りではない**。三連複の同じルールで 良148.1% / 道悪51.4%。
   道悪では「各馬の今日の水分量への適性」という未観測変数が結果を支配し、
   過去走ベースの序列が崩れる。ユーザー指摘の通り、毎回必ず見る。
2. **開催初日は買わない**。初日は馬場バイアスが誰にも（市場にもモデルにも）読めない。
   三連複25.9%、乖離単勝も抑止側。
3. **採掘したパターンは、必ず「実力ゼロの偽データ」で同じ採掘をやり直して偽陽性率を測る**
   （`rule_audit.py --null-sweep`）。今回これをやらなければ 164.8% を実弾に載せていた。
4. **オッズ抜きで市場に勝てるという主張は、選択バイアスを外した全レース比較で示す**。
   部分集合のROIは、いくらでも良く見せられる。
