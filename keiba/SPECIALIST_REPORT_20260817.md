# 条件専用モデル実験 報告書（2026-08-17・SPECIALIST_PROTOCOL_20260817.md の実行結果）

## 結論（先頭に明記）

**ユーザー仮説「条件専用に学習したモデルは汎用モデルを凌駕する」は、実質的に不成立。**

- 11セグメント中 **10セグメントで不成立**。全体傾向は明確に「専用が劣る」:
  3スキーム総合（各5,990R）でMINE窓のΔROIは −2.3〜−3.3pt、モデル1位勝率も
  全スキームで専用が下（例: S2全体 24.7% vs 汎用26.4%）。NDCG@3もほぼ全セルで専用が下。
  事前登録書「既知の限界」に書いた通り、**データ減の害が特徴重み差の益を上回った**。
- 唯一 **S1「ダ短」（ダート<1400m）だけが事前登録基準1を機械的に通過**
  （VALIDATE ΔROI+33.6pt・勝率28.1%≥24.0% / CONFIRM ΔROI+24.4pt）。
  ただし後述の診断により**偶然の疑いが濃い**（MINE窓では逆符号Δ−11.9pt・
  全期間807R合算ではΔ−1.4pt・11セグメント同時検定の多重性未補正・
  VALの優位の1/3が1発の14.4倍的中由来）。
- 基準1通過を受けて実施した**基準2＝専用スコアでの採掘再実行は完全不合格**:
  VALIDATE通過 **0セル**（3倍ルール即死）。前回キャンペーンと合算しても
  総試行117,380・VAL通過12 < 3×偶然期待29.7 → **合算でも不合格**。
- 事前登録書の文言に従い「ダ短」のみ形式上 RULEBOOK_V2候補（最終関門=ライブ直前判定）と
  記録するが、**上記の診断から実弾・紙上の優先度は最低ランクを推奨**。採掘セルの採用はゼロ。

## 実行概要

- 実装: `specialist_wf.py`（本報告と同時作成）。**実行1回で完走・バグ修正/基準変更/再実行なし**。
  WF実行1回 → 比較1回 → 採掘再実行1回、の計3コマンドのみ。
- ベースライン: `wf_preds_v3ext2.jsonl`（汎用V3のWF 5,990R・202409〜202608・24フォールド）。
- **公平性の事前検証**: 現行コードで汎用V3をfold 202409で再学習 → ベースラインと
  **206/206レースで order 完全一致・score差0.0**。専用との差は「学習データの絞り」だけに帰着する。
- 専用モデル: 汎用V3と**同一**の28特徴・LambdaRank・同一ハイパラ・同一train/val分割手順
  （`wf_compare.train_fold` / `VARIANTS["v3"]` をそのまま呼ぶ。コード分岐なし）。
- セグメント定義（事前登録・距離帯境界はMINING_PROTOCOL凍結バンドを踏襲）:
  - S1: 馬場×距離帯6分割 = 芝/ダ × (短<1400 / ﾏｲﾙ1400-1799 / 中長1800+)
  - S2: クラス帯3分割 = tier≥10 / tier6-9 / tier≤5
  - S3: 頭数帯2分割 = ≤12頭 / 13頭+
- 学習: 24フォールド×11セグメント=264枠のうち**262回学習**。800頭未満の「専用なし=汎用流用」は
  **2件**（fold 202409のダ中長734頭・芝ﾏｲﾙ704頭）。分割不能ガード発動0件。
- 出力: `wf_preds_spec_s1.jsonl` / `s2` / `s3`（ベースライン同形式 + segment / spec_used /
  train_races / train_horses）。
- 分割（変更なし）: MINE=202409-202602 / VALIDATE=202603-202605 / CONFIRM=202606-202608。
- 指標: モデル1位勝率 / 単勝flat ROI（払戻ベース・100円/R全レース） / NDCG@3
  （利得2^rel−1, rel=3/2/1）。同一レース集合で専用vs汎用を対比。

### 「ダ短」通過の診断（基準は変更しない・報告のみ）

1. **MINE窓では逆符号**: Δ−11.9pt（604R・sign-flip p=0.91＝専用が良い証拠ゼロ）。
   全期間807R合算では **Δ−1.4pt ≒ 差なし**。優位はVAL/CONF窓（計203R）だけの現象。
2. **月別Δは−135〜+58ptで乱高下**: MINE18ヶ月中12ヶ月がマイナス。VAL/CONF6ヶ月中5ヶ月が
   プラスに揃ったのは分割の偶然と整合的。
3. **1発依存**: VALのΔ+33.6ptのうち **+11.9pt が1レースの14.4倍的中**
   （202604 の1位不一致レース）由来。VAL+CONFで1位が不一致の62Rのうち
   専用のみ的中16 / 汎用のみ的中7 / 両外れ39。
4. **多重性未補正**: 基準1は11セグメントに同時適用しており、セグメント単位の
   sign-flip p（VAL 0.036 / CONF 0.049）はBonferroni補正(×11)すると有意でない。
5. 表の他セルにも同規模の逆方向の飛び値がある（芝ﾏｲﾙ CONF −35.2pt・ダ中長 CONF +25.5pt等）
   ＝この程度の±20〜35ptは窓n=60〜200では普通に出る。

## 限界

1. **セグメント判定の多重性**: 基準1に多重比較条項が無く、11セグメント×基準1で
   偶然通過が1個程度出ることは排除できない（上記診断の通り「ダ短」はその典型挙動）。
   基準は事前登録どおり緩和も強化もせず、機械判定と診断を併記した。
2. **スピード指数較正定数の全期間フィット（軽微リーク）**は両群共通＝比較の公平性は保たれるが、
   絶対ROIはライブ比で楽観側。
3. 専用モデルの学習手順は汎用と完全同一（train末尾10%をearly stopping検証に使用）。
   小セグメントでは検証部の比率が高く学習が浅くなるが、これは「同一手順」の帰結であり
   専用化のコストの一部として測定に含めた。
4. VALIDATE 874R / CONFIRM 676R（セグメント単位では60〜658R）と窓が小さく、
   単勝ROIのΔ±20〜35ptは1〜2発の的中で動く。
5. fold 202409 の2セグメント（ダ中長・芝ﾏｲﾙ）は800頭未満で汎用流用（事前登録の規定どおり記録）。

## 今後（提案・本実験の主張ではない）

- 全体としては**専用化よりデータ量**。凡そ全セグメントでNDCGも勝率も専用が下という結果は、
  「汎用モデル＋条件フィルタ」の現行路線を支持する。
- 「ダ短」を追うなら賭け金ゼロのライブ紙上ウォッチのみ（形式上のRULEBOOK_V2候補・優先度最低）。
  本データでの再採掘・基準変更による復活は後知恵禁止ルール違反のため不可。
- 中間案（汎用モデルにセグメント交互作用特徴を足す / 汎用初期化からのファインチューニング）は
  本実験の登録範囲外。やるなら新しい事前登録書から。
