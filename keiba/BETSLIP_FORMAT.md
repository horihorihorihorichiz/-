# 買い目の書式（2026-08-22 ユーザー指示「毎回買い目もう少しきれいにまとめて」で確定）

**毎回この形で出す。** チャット返信でもmdファイルでも同じ書式。

## 全体構成

```
# 買い目 YYYY/MM/DD（曜）場1・場2・場3
**予算 10,000円 ／ 使用 N,N00円 ／ NN点**

--- レースカード（発走順） ---

### ⭐ 場R 発走時刻 レース名 距離 頭数【判定】
> 発火理由を1行 ／ 補足があれば1行

| 券種 | 買い目 | 点数 | 金額 | 払戻目安 |
|:--|:--|--:|--:|--:|
| 単勝 | **軸馬番** | 1 | XXX円 | X.X倍 → X,XXX円 |
| ワイド | a-b / a-c / a-d | 3 | XXX円 | |
| 三連複 | 軸 → 相手 流し/BOX | N | XXX円 | |
| | | **計N** | **X,XXX円** | |

軸 **N 馬名**（X.X倍・N人気）　相手 a（X.X倍）b（X.X倍）...

--- 合計表 ---

| 枠 | レース | 点数 | 金額 |
|:--|:--|--:|--:|
| ⭐本命（エッジあり） | ... | NN | X,XXX円 |
| 🔴当てにいく | ... | NN | X,XXX円 |
| — 予備 | 理由 | — | X,XXX円 |
| | **合計** | **NN** | **X,XXX円** |

⭐＝期待値プラス側の判定　🔴＝よく当たるが期待値マイナス　購入・投票は人間
```

## 規則

1. **レースは発走順に並べる**。直近のレースが上。発走が近いものには ＜あと N分＞ を見出しに付ける。
2. **記号で性格を区別する**
   - ⭐ = day_board/patterns がエッジ(ROI+)を認めた枠（S/A/B判定）
   - 🔴 = 的中率セル（8頭以下×1位2倍未満など）。よく当たるが期待値はマイナス。混ぜない。
3. **各レースの表は必ず合計行で締める**（点数と金額）。
4. **軸と相手は表の下に1行**で。馬番・馬名・オッズ・人気を書く。表の中に詰め込まない。
5. **払戻目安は単勝だけ数字を入れる**。複合は「万馬券圏」等の定性表現で可（オッズが動くため）。
6. **金額は100円単位**。予算10,000円が既定。使い切らず予備を残してよい（理由を書く）。
7. **見送りレースは書かない**。ただし全レース見送りなら理由を1行で書く。
8. 最後に必ず「購入・投票は人間」を入れる。

## 禁止

- 表の中に長い説明を書く（説明は表の外に）
- ⭐と🔴を同じ表に混ぜる
- オッズ無しで払戻を断言する
