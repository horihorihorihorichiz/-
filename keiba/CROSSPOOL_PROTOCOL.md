## 0. 仮説

我々のモデルは4回の実験で市場に負けた(α=-0.13)。本検証は**モデルを一切使わない**。
単勝プール(参加者最多・最も効率的)が正しいと仮定し、そこから導いた組合せ券の理論確率と、
実際の 馬連/ワイド/三連複 プールの価格が示す確率を比較する。
**一致しなければ、どちらかのプールが誤っている。** これはモデル精度に依存しない歪みである。

帰無仮説 H0: 「プール間に体系的な価格の食い違いは無い(あるのは近似誤差とノイズだけ)」。

## 1. データ

- `hist/{race_id}.json`(着順) と `hist_odds/{race_id}.json`(tan/fuku/umaren/wide/sanrenpuku/…) の
  両方が揃うレースのみ。券種ごとに当該オッズが欠けるレースはその券種の分析から除外。
- **限界(事前に明記)**: hist_odds は**最終(確定)オッズ**。実運用は締切前に賭けるため、
  ここで測る乖離は「締切時点で実際に取れた乖離」より楽観的でありうる。ワイドは**下限のみ**保存
  されているため、ワイドの払戻は保守側(実際の払戻は下限以上)、implied確率は過大側になる。
- 期間分割(変更禁止):
  - **MINE**: 202409–202602
  - **VALIDATE**: 202603–202605
  - **CONFIRM**: 202606–202608
  - 202409より前のレース(2023–202408)は**一切使わない**(パラメータ推定にも使わない)。

## 2. 単勝プールからの理論確率

1. 勝率 `p_i = (1/tan_i) / Σ_j (1/tan_j)`(控除率を正規化で除去)。
2. **Harville**: P(1着=a,2着=b,3着=c) = p_a · p_b/(1-p_a) · p_c/(1-p_a-p_b)。
3. **Stern/Henery 修正**: 2着・3着の条件付き確率を `f2_i = p_i^λ2`, `f3_i = p_i^λ3` で置換。
   - P(2着=b|1着=a) = f2_b / (Σ_m f2_m − f2_a)
   - P(3着=c|1着=a,2着=b) = f3_c / (Σ_m f3_m − f3_a − f3_b)
   - λ2=λ3=1 が Harville。λ2,λ3 は **MINE期の実着順のみ**で最尤推定(グリッド0.30–1.60刻み0.02)。
     VALIDATE/CONFIRM の着順は推定に一切使わない。
4. **経験較正(Harville近似誤差の吸収)**: MINE期のみで、券種別に
   `logit(q_cal) = a + b·logit(q_stern) + c·log(field) + d·logit(q_stern)²` をロジスティック回帰で当てはめ
   (目的変数=その組合せが実際に的中したか)、以後 **q_cal を理論確率**とする。
   係数は MINE で確定し凍結。これにより「近似の系統誤差」は理論側に吸収され、残った乖離は
   プール固有の価格ズレに近づく。
5. 券種別の理論値:
   - 馬連 = P(a,b が1-2着) / ワイド = P(a,b がともに3着以内) / 三連複 = P(a,b,c が3着以内)
   - 正規化の整合: レース内合計は 馬連1・三連複1・ワイド3(3着以内のペアは3組)。

## 3. 乖離の定義

- 市場implied: `m_k = (1/O_k) / Σ_j (1/O_j) × N`(N=馬連1・三連複1・ワイド3)。控除率は正規化で除去。
- **乖離比 D_k = q_cal,k / m_k**。D>1 = そのプールがその組合せを**過小評価**(理論より人気薄)。
- 分布(中央値・分位点・オッズ帯別)を MINE/VAL/CONF それぞれで報告する。

## 4. 戦略(事前確定・後出し追加禁止)

- 券種: **馬連 / ワイド / 三連複** の3つを独立に評価。
- **戦略A(過小評価を買う)**: `EV_k = q_cal,k × O_k` が閾値以上の点を1点100円で買う。
  閾値 **1.10 / 1.20 / 1.30** の3水準(この3つのみ。他の閾値を後から足さない)。
- **戦略B(過大評価を避ける)**: EVが下位X%の点を除外した残り全点を買う戦略は、
  全点買い(=控除率分だけ必ず負ける)の改善度合いとしてのみ報告し、**合否判定の対象外**(参考)。
  判定対象は戦略Aのみ。
- 賭け金は全て **flat 100円/点**。払戻はそのレースの確定オッズ×100円(ワイドは下限=保守側)。
- ROI = 回収 / 投下。

## 5. 判定基準(事前登録・変更禁止)

各券種×各EV閾値の組を1つの候補とする。

| 段階 | 条件 |
|---|---|
| MINE | 発火点数 n≥100 かつ ROI≥110% かつ 並べ替え検定 p<0.05 |
| VALIDATE | n≥50 かつ ROI≥105% |
| CONFIRM | n≥30 かつ ROI≥100% |

- 3段階すべてを通過した候補のみ「**合格**」。1つでも落ちたら**不合格**と書く。
- n<30 の集計は必ず「**参考(n<30)**」と表記し、合否判定に使わない。
- **控除率の壁**: 馬連22.5% / ワイド22.5% / 三連複25%。「乖離がある」だけでは不十分で、
  ROIが100%を超えて初めて実利がある。乖離の存在(統計的有意)と収益性(ROI)は分けて報告する。

### 並べ替え検定(MINE)
選択シグナル(乖離)が価格水準以外の情報を持たない、という帰無仮説を検定する。
各レース内で、**同一オッズ十分位バケット内**の組合せ間で乖離比 D をランダムに入れ替え、
同じ手順で選び直して ROI を計算する。1000回反復し `p = (#{ROI_null ≥ ROI_obs} + 1)/1001`。
オッズ分布を保存するため、「単に高オッズを買っただけ」で出る見かけの有意性を排除する。

## 6. Harville近似誤差と真の乖離の切り分け(必須診断)

近似誤差は「理論確率の推定誤差」であり、全プールに同じ向きで現れる(理論側が共通なので)。
真のプール間乖離は**プールごとに独立**に現れる。よって:

1. **診断1(プール間一貫性)**: あるペア(a,b)について、馬連プールの乖離 D_umaren と
   ワイドプールの乖離 D_wide を比較する。両者の相関が高ければ「理論側の誤差(共通要因)」が主因。
   相関が低く各プール固有のばらつきが大きければ、プール固有の価格ズレが存在する。
   → 相関係数と分散分解(共通成分 vs プール固有成分)を報告する。
2. **診断2(クロスチェック戦略)**: 三連複の候補について、その3頭の3ペアが
   **ワイドプールでも同方向に過小評価**(D_wide>1)であることを追加条件にした版を評価する。
   複数プールで一貫して乖離するものだけを「本物」とみなす。
   これは戦略Aの**サブ条件**であり、閾値は上記3水準と同じ(新閾値を足さない)。
3. **診断3(較正の確認)**: MINE で q_cal が実際の的中率と一致しているか(較正曲線)を確認し、
   VALIDATE/CONFIRM でも同じ較正が保たれるかを見る。ここで大きくズレるなら
   「乖離」は理論の誤差である可能性が高い、と結論する。
