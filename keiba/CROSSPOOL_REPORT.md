## 結論(先頭)

**プール間の「本物の歪み」は実質存在しない。全9候補(3券種×3閾値)が MINE 段階で不合格。合格ゼロ。**

1. 乖離比 D(=単勝から導いた理論確率 / 実オッズの示す確率)の**ばらつき自体は大きい**
   (三連複の5–95%点で 0.18–1.78)。しかし**そのばらつきは収益に一切変換できない**。
2. 戦略A(D>1=そのプールが過小評価している組合せを買う)の MINE ROI は
   **馬連34–51% / ワイド50–57% / 三連複48–52%**。判定基準 ROI≥110% に遠く及ばず、
   並べ替え検定も **p=0.23–0.96**(全滅)。
3. **選んだ方が悪い**。全点買い(=控除率をそのまま食う)の ROI は 馬連61.5%/ワイド59.3%/三連複53.0%
   なのに、「D が高い点だけ」を買うと 34–57% に**下がる**。乖離シグナルは負の情報。
4. 乖離Dは実質「超万馬券度」の代理変数(D と オッズ の log 相関 −0.33〜−0.39、
   D 最下位・最上位デシルとも中央オッズが跳ね上がる U 字)。ROI は D のデシルに対して**山型**で、
   両端(=極端に人気薄)が最悪。単勝プールの favourite–longshot バイアスと理論の推定誤差が
   同じ場所で最大化しているだけ。
5. 診断1: 同一ペアの 馬連プール乖離 と ワイドプール乖離 の log 相関は **0.898**
   (共分散0.177 / 分散0.207・0.189)。乖離の**86–94%は共通成分**=理論側の要因であり、
   プール固有の食い違いは残り 6–14% しかない。その残りを狙った診断2(三連複×ワイドで
   同方向に過小評価のものだけ)も **VAL 22–48% / CONF 42–58%** で改善しない。

> **「三連複プールは1点あたりの注目度が低いから歪んでいるはず」という仮説は、
> 少なくとも最終オッズのレベルでは支持されない。** 単勝と組合せ各プールの価格は、
> 理論の推定誤差の範囲内で整合しており、食い違う部分は買っても損が増えるだけだった。

## 4. Harville近似誤差と真の乖離の切り分け(必須診断)

### 診断1: プール間一貫性(共通成分 vs プール固有成分)
同一ペア(a,b) について、馬連プールの log D と ワイドプールの log D を比較(MINE、n=458,310)。

| 指標 | 値 |
|---|---|
| 相関 | **0.898** |
| 共分散(=共通成分の分散の推定) | 0.1773 |
| 分散(馬連 log D) | 0.2067 → 共通 **85.8%** / 馬連固有 14.2% |
| 分散(ワイド log D) | 0.1888 → 共通 **93.9%** / ワイド固有 6.1% |

**解釈**: 乖離のほぼ全てが「馬連とワイドで同じ向きに出る成分」＝両者に共通する要因。
共通要因は (i) 理論確率の誤差(両プールで同じ理論を使っている) と
(ii) 単勝プールと組合せプール全体の系統差 の合計であり、
**「馬連プールと三連複プールが互いに矛盾している」という当初の仮説が指す成分は最大でも6–14%**。
しかもその 6–14% は §3 の通り収益に結びつかない(戦略Aの発火はこの成分に支配されていない)。

### 診断2: クロスチェック戦略(複数プールで一貫して乖離するものだけ買う)
三連複の候補のうち、**3ペアすべてがワイドプールでも過小評価(D_wide>1)** のものに限定。

| EV閾値 | MINE n / ROI | VALIDATE n / ROI | CONFIRM n / ROI |
|---|---|---|---|
| 1.10 | 109,806 / **52.9%** | 27,186 / 47.5% | 14,147 / 58.2% |
| 1.20 | 87,121 / **54.2%** | 22,374 / 44.6% | 11,006 / 52.0% |
| 1.30 | 68,368 / **54.5%** | 18,095 / 22.3% | 8,456 / 41.7% |

無条件版(52.2/47.5/51.2%)から**ほぼ変化なし**。
「複数プールで一貫する乖離＝本物」という選別をかけても収益は生まれない。
＝ 一貫する乖離の正体は**共通の理論誤差**であって、プール固有の価格ズレではない。

### 診断3: 較正の維持
§1 の通り、MINE で当てた較正は VALIDATE / CONFIRM でも保たれている
(デシル別の予測/実測が3期間とも一致)。**理論は平均としては壊れていない**。
それでも D が大きく散らばり、その散らばりが収益ゼロ ⇒
散らばりの正体は**1レース単位の推定ノイズ(および市場の longshot バイアス)**である。

## 6. 限界(正直な明記)

1. **最終(確定)オッズを使用**。実運用は締切前に賭けるので、締切直前の実オッズでは乖離の姿が違いうる。
   ただし ANALYSIS_20260816 の実測(記帳→発走で単勝が平均0.73倍に短縮)からすると、
   締切前オッズはノイズが**多い**方向であり、乖離採掘が楽になる根拠にはならない。
   なお本検証は「乖離が最終時点でも残っているか」を見ており、そこですら無い、という結果。
2. **ワイドは下限オッズのみ**(`hist_odds/` の仕様)。したがってワイドの ROI は**過小**、
   implied確率は過大。真のワイドROIは表の値より高いが、
   全点買いとの相対比較(選んでも改善しない)は同じバイアスがかかるため結論は変わらない。
   確度を上げたい場合は上限オッズを再収穫して再実行すること(COMBO_ODDS_NOTES.md §4(C))。
3. **自分の賭けによるオッズ変動は無視**(パリミュチュエルなので大口では効く)。
   今回は「そもそも歪みが無い」結論なので影響しない。
4. 単勝オッズの正規化は単純な (1/o)/Σ(1/o)。favourite–longshot バイアスを単勝側で補正していない
   (補正はλと較正が3着以内確率の側で吸収する設計)。単勝プール自体のバイアス補正を入れた版は未実施。
5. 202409より前のデータ(2023–202408、約1,870R)は事前登録どおり**一切使っていない**。
6. 並べ替え検定は1000回・レース×オッズ十分位内での入れ替え。
   本検証は「有意でない」側の結論なので、検定の検出力不足はむしろ保守的に働く
   (＝有意でないものを有意と誤って主張していない)。

## 7. 示唆

- 「市場が市場自身と矛盾しているか」への答えは **No(少なくとも最終オッズでは)**。
  単勝プールと組合せプールは、モデルを使わない範囲で見る限り整合している。
  三連複プールは点数が多いにもかかわらず、単勝プールから導ける情報を織り込み済み。
- これで「オッズ抜きでは勝てない(MODEL_V4_RESULT)」に加え、
  **「オッズだけを使ったプール間裁定でも勝てない」** が確定した。
  残る道は「オッズ + オッズ以外の情報」の組合せ(=価格に織り込まれていない情報の発見)のみで、
  それは過去4回の実験でモデル側が負け続けている領域である。
- 次に試す価値があるとすれば、**最終オッズではなく時間断面**(朝→締切のオッズ変化、
  プール間で価格が寄る速度差)であり、静的な最終スナップショットではない。
  ただし ANALYSIS_20260816 の drift 実測は「朝の乖離は7割が消える」なので期待値は低い。
