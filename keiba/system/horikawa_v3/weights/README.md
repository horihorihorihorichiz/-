# 配点表について

- `reference_browser_fit.json` … 参考値。2026年8月にブラウザ上で
  10,551レースから学習したもの（学習5,015R / 未知検証1,707R）。
  **そのまま使うためのものではありません。** 成分の作り方は同じですが、
  ブラウザ版とPython版で細部の丸めが違うので、数字が完全には一致しません。
  自分で `python -m hk.cli harvest` → `python -m hk.cli fit` を回して
  `hori_w.json` を作ってください。参考値は「だいたいこのくらいの配点になる」
  という目安と、実装が壊れていないかの答え合わせに使います。

- `hori_w.json` … `fit` が書き出す本番の配点表。全体1本・6群・場・クラス・
  コース単位の全段と、内側検証が選んだ段階、形ごとの的中率が入ります。
