## 点数の出し方（5手順）

### 1. 16成分を1頭ずつ計算する

過去9走・今回条件・枠・斤量・馬場から算出する。定義は `horikawa_v3/hk/features.py`
（設計図が `calc.py` と呼んでいるもの）。
脚質確定と展開（ペース5段階）を先に決めてから、展開乗数が乗る。

**`score.js` にはこの手順が入っていない。** `score.js` は16成分が算出済みの状態を入力に取る。
Python 側は `horikawa_v3/` に取り込み済みで、そちらは成分づくりから予想まで一式そろっている。

### 2. レース内でZ正規化する

各成分を「そのレースの出走馬の中での偏差」に直す。結果が16次元ベクトル `Z16`。

レース間の水準差はここで消える。したがって **点数は同一レース内でしか比較できない**。
別のレースの点数と大小を比べることに意味は無い。

### 3. 配点ベクトルを2層で合成する

場の層とクラスの層を半分ずつ混ぜる。該当セルが無ければ順に粗い層へ落ちる。

```
w = 0.5 × w52[場+芝ダ+距離帯] + 0.5 × w30[芝ダ+距離帯+クラス]
    ↓ w52が無い → w30のみ ／ w30も無い → w6[芝ダ×距離帯] ／ それも無い → 全体1本
```

| 層 | キー | セル数 | 例 |
|---|---|--:|---|
| `w52` 場の層 | 場 + 芝ダ + 距離帯 | 49 | `中山芝M` |
| `w30` クラスの層 | 芝ダ + 距離帯 + `/` + クラス | 30 | `芝M/t6` |
| `w6` 6群（土台） | 芝ダ + 距離帯 | 6 | `芝M` |

- 距離帯 **S**≤1400m / **M**≤2000m / **L**>2000m（`hk/features.py:66`。後述の食い違いに注意）
- クラス **t3〜t6**（t6＝1勝クラス）・**t10**（新馬・未勝利）。
  JRAのクラス表記は `{3,4,5,6,10}` の5種類しか存在しない
- 層の名前は `w52` だが、正本に実在するセルは **49** である（52ではない）
- `w52` の各セルには学習に使ったレース数 `n` が付随する。最多は中山ダL 570R、
  最少は小倉ダL 64R。セルの信頼度はこの `n` で判断する

### 4. 内積をとる＝これが得点

```
得点 = Z16 · w
```

同点の並べ替えは `(−得点, −WAvg, 馬番)` の順。
得点表示は見やすさのため100前後に平行移動している。

### 5. PWinと形に変換する

- **PWin** ＝ 得点の softmax（上限30%でクリップ後に再正規化）
- **形** ＝ レース内SDで割った上位の段差
  `g12 = (1位−2位)/SD`、`g23`、`g34` → 1強／2強／3強／階段／混戦

## 16成分の意味

| 記号 | 名前 | 中身 |

## モデルの世代（16 → 26 → 50成分）

システムは3世代ある。設計図 Artifact が説明しているのは最初の世代。

| 世代 | 成分 | 形 | 配点表 | 状態 |
|---|--:|---|---|---|
| 16成分・線形 | 16 | レース内Z化 → 層別配点との内積 | `w6`/`w52`/`w30` | 設計図 Artifact / `score.js` |
| 26成分・線形 | 26 | 同上（配点は全体1本） | `linear26.global` | 調教込み。`hk.cli fit` |
| **50成分・木** | 50 | LightGBM。条件そのものを成分に渡す | 持たない | **本命**。`hk.cli gbdt` |

50成分・木では、セルを手で切るのをやめている。`horikawa_v3/README.md` に
「セルを手で切るのは効かないと測定で分かった（コース単位266セルは全体1本より悪い）」とあり、
かわりに 頭数 / 距離 / 芝ダ / 馬場 / クラス / 場 / 回り / 内外 / R / 月 を成分として渡し、
条件ごとの使い分けを学習器に見つけさせる。さらに馬ごとの生の値を14個（前走着順・前走着差・
通算勝率・同条件率・連続3着内・休養日数など）足して合計50成分。

### 実測（中央競馬10,551レース・2023年8月〜2026年8月、未知期間1,707レースで1回だけ測定）

| | 1位が1着 | 1位が3着内 | 上位6頭で3着独占 | 対数尤度 |
|---|--:|--:|--:|--:|
| 元の16成分・線形 | 23.43% | 54.66% | 37.96% | −2.2446 |
| 26成分・線形（調教込み） | 26.54% | 58.41% | 43.06% | −2.1338 |

16成分との差は対応のある検定で 1位が1着 +4.34pt(t=4.07) / 3着内 +4.98pt(t=4.00) /
6頭3着独占 +5.98pt(t=5.50)。3つとも規律R5の t>3.0 を越えている。

### 全セル共通の骨格

- **`DSI`（距離適性）と `NSI`（格）が二本柱**。どのセルでも最大級の重み（60〜100）
- **`mgn_abs`（着差）が唯一の大きな負**。−40〜−70。大敗の記憶を強く引く
- **`spd_res`（脚の残り）が第3の柱**。44〜60で全セル安定

### セルによる違い（設計上の意味）

- **`TSI`（タイム指数）はダートで効き、芝Lで効かない**: 6群では ダS 39.6 に対し 芝L 16.6、
  49セル単位では東京芝L 4.0 / 新潟芝L 4.3 とほぼ0。
  時計勝負のダートと、展開勝負の芝長距離の差
- **`TAS`（道悪適性）もダート寄り**: ダS 25.4 / ダM 23.9 に対し芝は一桁台のセルが多い
- **`FSI`（脚質×枠）はダートで倍**: ダS 36.0 / ダM 36.0 vs 芝S 21.0。砂被りの有無が効く
- **芝は展開・`CSI` 寄り、ダートは能力・時計寄り**という全体傾向がそのまま数字に出ている

## 使用上の警告

### できること

同一レース内で「どの馬が上位か」を並べる。
3着内率は VAL 56.5% / CONF 57.0%（現行6群比 +2.6pt、ただし1SE未満につき有望・未確定）。

### できないこと

市場（単勝オッズ）より正確な確率を出すこと。市場推定は全オッズ帯で誤差 ±0.7pt 以内であり、
この配点は市場に条件付けると情報を足さない。

**「点数が高い＝買い」ではない。** 買う根拠は別途、発火表（`plus_fires.json`）の
証明済みエッジだけ。

### PWinの取り扱い注意（2026-08-23の実測）

PWinは市場より一貫してフラットで、

- 単勝1〜3倍帯を **19.2%**（実測 **38.0%**）と大幅に**過小**
- 20〜50倍帯を **+2.8pt 過大**

条件付きロジットでは市場に対する上乗せがゼロ（β=−0.06, t=−2.42）。

**PWinは順位付けの副産物として読み、確率の絶対値や期待値計算には使わない。**
