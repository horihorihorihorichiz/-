## 点数の出し方（5手順）

### 1. 16成分を1頭ずつ計算する

過去9走・今回条件・枠・斤量・馬場から算出する。定義は `calc.py`。
脚質確定と展開（ペース5段階）を先に決めてから、展開乗数が乗る。

**この手順は本リポジトリに未移植。** `score.js` は16成分が算出済みの状態を入力に取る。

### 2. レース内でZ正規化する

各成分を「そのレースの出走馬の中での偏差」に直す。結果が16次元ベクトル `Z16`。

レース間の水準差はここで消える。したがって **点数は同一レース内でしか比較できない**。
別のレースの点数と大小を比べることに意味は無い。

### 3. 配点ベクトルを2層で合成する

場の層とクラスの層を半分ずつ混ぜる。該当セルが無ければ順に粗い層へ落ちる。

```
w = 0.5 × w52[場+芝ダ+距離帯] + 0.5 × w30[芝ダ+距離帯+クラス]
    ↓ w52が無い → w30のみ ／ w30も無い → w6[芝ダ×距離帯] ／ それも無い → 全体1本
```

| 層 | キー | セル数 | 例 |
|---|---|--:|---|
| `w52` 場の層 | 場 + 芝ダ + 距離帯 | 49 | `中山芝M` |
| `w30` クラスの層 | 芝ダ + 距離帯 + `/` + クラス | 30 | `芝M/t6` |
| `w6` 6群（土台） | 芝ダ + 距離帯 | 6 | `芝M` |

- 距離帯 **S**=短距離 / **M**=中距離 / **L**=長距離
- クラス **t3〜t6**（t6＝1勝クラス）・**t10**（新馬・未勝利）。
  JRAのクラス表記は `{3,4,5,6,10}` の5種類しか存在しない
- 層の名前は `w52` だが、正本に実在するセルは **49** である（52ではない）
- `w52` の各セルには学習に使ったレース数 `n` が付随する。最多は中山ダL 570R、
  最少は小倉ダL 64R。セルの信頼度はこの `n` で判断する

### 4. 内積をとる＝これが得点

```
得点 = Z16 · w
```

同点の並べ替えは `(−得点, −WAvg, 馬番)` の順。
得点表示は見やすさのため100前後に平行移動している。

### 5. PWinと形に変換する

- **PWin** ＝ 得点の softmax（上限30%でクリップ後に再正規化）
- **形** ＝ レース内SDで割った上位の段差
  `g12 = (1位−2位)/SD`、`g23`、`g34` → 1強／2強／3強／階段／混戦

## 16成分の意味

| 記号 | 名前 | 中身 |
|---|---|---|
| `TSI` | タイム指数 | 今回条件に近い過去走の最良タイム。距離換算・馬場差で補正 |
| `LTS` | 近走着順 | 最良着順スコア。中央競馬は繰上、条件一致でブースト |
| `FSI` | 脚質×枠 | 芝=内枠有利／ダ=砂被りロジック（差・追は外枠クリーンを高評価） |
| `Bonus` | 実績加点 | 該当実績の数で 0 / 8 / 10 点 |
| `DSI` | 距離適性 | 近3走±200mで掲示板=A → 1年以内 → ±400m の3段階 |
| `NSI` | 格 | クラス実績のグレード（勝ち上がりの水準） |
| `CSI` | コーナー | 通過順の統計。位置取りの安定度 |
| `WAS` | 斤量 | 出走馬プール内での相対斤量。最軽量判定を含む |
| `TAS` | 道悪適性 | 1年以内の稍/重/不の着順から A〜C |
| `HCS` | 条件調整 | 斤量・条件面の微調整 |
| `NRJA` | 間隔 | 前走からの休養日数（ローテ） |
| `展開乗数` | 展開 | ペース5段階（スロー〜ハイ）× 脚質の相性 |
| `spd_res` | 脚の残り | コーナー通過からの失速/持続。※4角系4成分の1つ |
| `mgn_abs` | 着差 | 着差の絶対量。負の重み＝大差負けを強く減点 |
| `wide4c` | 4角外回し | 4コーナーで外を回した距離ロス |
| `pos_gain` | 位置上昇 | 道中で押し上げた位置の量 |

下4つ（`spd_res` / `mgn_abs` / `wide4c` / `pos_gain`）は4コーナー通過データから作る後付けの4成分。
`mgn_abs` だけ符号が負＝「大差で負けた馬を強く減点する」働き。

**調教に相当する成分は存在しない。** エクスポートには調教データ
（`hori_train_YYYYMMDD.jsonl.gz` 約10,553件、各レース行の `"t":[調教インデックス]`）が
含まれるが、16成分のどれにも使われていない。データはあるが評価には入っていない。

### 「調教評価の重み 75.2」の正体

`README.md` に未確認事項として挙がっていた「調教評価の重み 75.2」は、**調教とは無関係**。

`75.2` は重みテーブル全体（w6 6 + w52 49 + w30 30 = 85ベクトル × 16成分 = 1,360個）の中で
**1箇所にしか出現しない**:

```
"中山芝M": [25.6, 52.9, 6.9, 25.6, 96.4, 58.3, 21.1, -19.8,
            16.8,  3.0, 6.9,  1.3, 61.2, -75.2, -8.7, -0.3]
                                         ↑ 14番目 = mgn_abs（着差）
```

すなわち **「中山・芝・中距離」セルにおける `mgn_abs`（着差）の重み `−75.2`**。
符号は**負**で、加点ではなく減点方向の係数である。

- **何に対する重みか**: 手順2でレース内Z正規化した**後**の値に掛かる係数
  （Z化 → 内積、の順）
- **どのスケールか**: 「平均絶対値を30に揃えた」正規化表示。層ごとに生の重みの絶対値が
  違うためそのままでは比較できず、設計図・`weights.json` ともにこの正規化表示を採用している。
  生の重みそのものではない

### 全セル共通の骨格

- **`DSI`（距離適性）と `NSI`（格）が二本柱**。どのセルでも最大級の重み（60〜100）
- **`mgn_abs`（着差）が唯一の大きな負**。−40〜−70。大敗の記憶を強く引く
- **`spd_res`（脚の残り）が第3の柱**。44〜60で全セル安定

### セルによる違い（設計上の意味）

- **`TSI`（タイム指数）はダートで効き、芝Lで効かない**: 6群では ダS 39.6 に対し 芝L 16.6、
  49セル単位では東京芝L 4.0 / 新潟芝L 4.3 とほぼ0。
  時計勝負のダートと、展開勝負の芝長距離の差
- **`TAS`（道悪適性）もダート寄り**: ダS 25.4 / ダM 23.9 に対し芝は一桁台のセルが多い
- **`FSI`（脚質×枠）はダートで倍**: ダS 36.0 / ダM 36.0 vs 芝S 21.0。砂被りの有無が効く
- **芝は展開・`CSI` 寄り、ダートは能力・時計寄り**という全体傾向がそのまま数字に出ている

## 使用上の警告

### できること

同一レース内で「どの馬が上位か」を並べる。
3着内率は VAL 56.5% / CONF 57.0%（現行6群比 +2.6pt、ただし1SE未満につき有望・未確定）。

### できないこと

市場（単勝オッズ）より正確な確率を出すこと。市場推定は全オッズ帯で誤差 ±0.7pt 以内であり、
この配点は市場に条件付けると情報を足さない。

**「点数が高い＝買い」ではない。** 買う根拠は別途、発火表（`plus_fires.json`）の
証明済みエッジだけ。

### PWinの取り扱い注意（2026-08-23の実測）

PWinは市場より一貫してフラットで、

- 単勝1〜3倍帯を **19.2%**（実測 **38.0%**）と大幅に**過小**
- 20〜50倍帯を **+2.8pt 過大**

条件付きロジットでは市場に対する上乗せがゼロ（β=−0.06, t=−2.42）。

**PWinは順位付けの副産物として読み、確率の絶対値や期待値計算には使わない。**

## 実装（score.js）

手順2〜5 を Node.js に移植したもの。依存パッケージなし。

```bash
node score.js --selftest     # 内蔵の検算（22項目）
node score.js race.json      # レースJSONを採点して表示
```

```js
const { scoreRace } = require('./score');

const r = scoreRace({
  place: '中山', surf: '芝', band: 'M', cls: 't6',   // band の代わりに dist: 1800 でも可
  horses: [
    { umaban: 1, name: 'ウマA', wavg: 0, comps: { TSI: 62, LTS: 5, /* …16成分すべて… */ } },
    // …
  ],
});

r.layer      // '0.5*w52[中山芝M] + 0.5*w30[芝M/t6]'
r.horses     // 得点降順。score / display / pwin / parts（成分別の寄与内訳）
r.shape      // '1強' | '2強' | '3強' | '階段' | '混戦'
r.g12        // 上位の段差
```

`parts` は成分ごとの `Z × w`。「どの成分が効いたか」の内訳がそのまま読める。

## 設計図に数値が無く、実装で暫定値を置いた箇所

`score.js` の `PROVISIONAL` に集約してある。**正本を確認したら差し替えること。**

| 項目 | 暫定値 | 状況 |
|---|---|---|
| 距離帯 S/M/L の境界 | S≤1400m / M≤2000m / L>2000m | 設計図は「短/中/長距離」としか書いていない |
| 得点表示の平行移動 | レース内平均を100に置く | 「見やすさのため100前後に平行移動」とのみ |
| PWin の softmax 温度 | 1.0 | 記載なし |
| 形の判定しきい値 | strong=1.0, step=0.5 | g12/g23/g34 の定義のみで、しきい値の記載なし |
| 「全体1本」のベクトル | w6 6セルの単純平均 | 正本に単独ベクトルが存在しない |
| `WAvg`（同点時の第2キー） | 入力で受け取る（既定0） | 16成分に含まれず、定義が設計図に無い |
| w52 はあるが w30 が無い場合 | w52 単独を使う | フォールバック記述がこのケースに触れていない |

PWin の上限30%クリップだけは設計図に明記があるため暫定ではない。
