# 得点構成のコース別再配合 — 実測 2026-08-19

指示: 「買い方じゃない、得点構成を変えてほしい」。
買い方は固定し、**得点の中身（成分の配合比率）をコースごとに学習し直した**。

## 設計
- 成分5つ: `V3得点` / `spd_res`(スピード余力) / `mgn_abs`(着差) / `wide4c`(4角外回し) / `pos_gain`(道中の位置取り)
  ※後ろ4つは通過順全区間の再収穫（2026-08-18）でCONFIRMを通過した特徴。
- Plackett-Luce（1着→2着→3着の順序尤度）で配合を学習。
- まず全体で1本 `w_g` を学習 → 42コース（MINE 40R以上）それぞれに個別配合 `w_c` を学習。
  `w_c` は `w_g` へL2で縮小し、縮小の強さλは **MINEの内部分割のみ**で決定。
- VALIDATE / CONFIRM は最後に1回だけ通した。データは5,690R（2022-01〜2026-08）。

## 途中で見つけた重大バグ（先に報告）
mktcond_ds.pkl の `top3` は馬番ではなく**0始まりのインデックス**だった。
馬番として扱うと学習が壊れ、「V3の重みがマイナス」という偽の結果が出る
（実際に一度出た。検算 `純V3のLL < ゼロ重みのLL` で検出し、修正後は正常）。
複勝払戻キーとの突合500レースで一致490/500を確認してから再実行した。

## 結論
- 指示どおり「得点構成をコースごとに変える」を、正しいラベル・正しい検証で実行した。
- **コースごとの最適配合は、全体の配合とほぼ同一だった。** これは「調べていない」のではなく、
  自由に変えさせたら内部検証が悪化する（λ=0.3で−0.0282）ことまで含めて測った上での結果。
- コースの個性が無いのではない。コースの個性（外枠不利・逃げ有利など）は
  **成分の中（4角外回し・位置取り等）に既に織り込まれていて**、配合比率の側には残っていない。
- 配合表そのものは course_weights_20260819.json に保存（42コース分）。
