## 2. 検定する特徴（全27本・実装前に確定／以後追加禁止）

すべて **as-of**（そのレースの発走時点で知り得る情報のみ）。
過去走レコード `h["races"]` は定義上すべて事前情報。斤量・馬体重の履歴だけは台帳を
**日付昇順に「読む→書く」の一方通行**で走査して作る（同日の他レースも参照しない＝厳密に前日以前）。

`ff = finish/field`（0=勝ち、1=最下位）。符号は「大きいほど良い」に揃える場合 `-ff` と書く。

### ペース適性（3本）
| 名前 | 定義 |
|---|---|
| `pace_h_fin` | `pace=="H"` の過去走の `-ff` 平均（該当なしNone） |
| `pace_s_fin` | `pace=="S"` の過去走の `-ff` 平均 |
| `pace_pref` | `pace_h_fin − pace_s_fin`（両方あるときのみ。正=ハイ向き） |

### 馬場指数適性（3本）
| `baba_slope` | 過去走の (`baba_idx`, `-ff`) の最小二乗傾き（正=道悪で良化）。baba_idxが2種以上必要 |
| `baba_match_fin` | 今日の `baba_idx` と**同じ**過去走の `-ff` 平均 |
| `baba_x_today` | `baba_slope × 今日のbaba_idx`（良の日は0で無効化） |

### 距離変化（4本）
| `dist_chg_signed` | `(今日dist − 前走dist)/前走dist`（**符号付き**。既存 dist_chg は絶対値） |
| `ext_fin` | 過去の**延長**戦（`races[i].dist > races[i+1].dist`）の `-ff` 平均 |
| `sht_fin` | 過去の**短縮**戦の `-ff` 平均 |
| `dist_chg_apt` | 今日が延長→`ext_fin` / 短縮→`sht_fin` / 同距離→同距離走の `-ff` 平均 |

### コース（馬場）替わり（1本）
| `switch_apt` | 今日が芝ダ替わりのときだけ「過去の芝ダ替わり戦の `-ff` 平均」、非替わりは0（中立） |

### 頭数適性（1本）
| `field_apt` | 今日の頭数±3 の過去走の `-ff` 平均 |

### 位置取りの安定性（2本）
| `pos_sd` | 直近5走の `corner4/field` の標準偏差（3走以上必要） |
| `pos_range` | 同 max − min |

### 上がりの安定性・傾き（2本）
※「同一レース内の他馬と比べた上がり順位」は過去走レコードに他馬情報が無いため**測定不可能**。
代替として as-of 標準上がりテーブル（`(馬場, 距離200括り, baba_idx)` の平均上がり、標本30未満は
`(馬場, 距離200括り)`→`(馬場)` にフォールバック、**前日以前のみ**で構築）との残差を使う。
| `agari_sd` | 直近5走の上がり残差の標準偏差（3走以上必要） |
| `agari_trend` | 上がり残差の最小二乗傾き（正=最近速くなっている） |

### 着順の傾き・ばらつき（2本）
| `fin_slope5` | 直近5走の `-ff` の傾き（正=良化中。3走以上必要） |
| `fin_sd` | 直近5走の `ff` の標準偏差（大きい=ムラ） |

### 斤量変化（1本）
| `kin_chg` | `今日kinryo − 前走kinryo`（前走の斤量は as-of 馬台帳から。無ければNone） |

### 馬体重の水準と変動（2本）
| `wt_dev` | `今日weight − 過去出走時weightの平均`（as-of 馬台帳・1走以上必要） |
| `wt_sd` | 過去出走時 weight の標準偏差（2走以上必要） |

### 間隔パターン（2本）
帯: `≤7`（連闘）/ `8-27`（中1-3週）/ `28-70`（中4-8週）/ `71+`（休養明け）
| `iv_match_fin` | 今回と同じ帯の過去走の `-ff` 平均 |
| `iv_best_match` | その馬の最良帯（n≥2 の帯のうち `-ff` 平均が最大）と今回帯が一致=1 / 不一致=0 |

### クラス経験（2本）
| `cls_exp_up` | `今日tier − 過去最小tier`（tierは小さいほど上級。正=上のクラス経験あり） |
| `cls_up_top3` | `tier < 今日tier` の過去走での3着内回数 |

### 復調シグナル（2本）
| `rebound_flag` | 前走 `ff ≥ 0.7` かつ 2-3走前に `ff ≤ 0.3` があれば1 / else 0 |
| `rebound_hist` | 過去の「`ff ≥ 0.7` の次走で3着内」率（大敗経験なしはNone） |

**合計 27本。これ以外を後から足さない。**

## 3. 検定手順（1本ずつ・単独）

### 3-1. データ
- 台帳 `hist/*.json`（8,639R）。`result.order` に着順・オッズがあるレースのみ。
- 各馬の市場確率 `pm = (1/odds)` をレース内で合計1に正規化（控除率補正）。
  オッズ欠損馬がいるレースは除外。

### 3-2. 分割（月次・以後変更禁止）
| 分割 | 期間 | 概算R数 |
|---|---|---|
| MINE | 〜202602 | 7,002 |
| VALIDATE | 202603〜202605 | 874 |
| CONFIRM | 202606〜202608 | 763 |

### 3-3. モデル（市場を条件にしたロジスティック回帰）
目的変数は2つ: `y_win`（1着=1）と `y_top3`（3着内=1）。**馬単位**の行。

- ベースライン共変量: `[1, log pm]`（`y_top3` のときは `[1, log pm, log(3/field)]`）
- 検定モデル: ベースライン + **候補特徴のレース内z**（Noneは0＝平均扱い）

各分割ごとに Newton-Raphson で最尤推定し、
- **増分の対数尤度** `ΔLL = LL(検定) − LL(ベースライン)`
- 候補特徴の係数の **z値**（`coef / SE`、SEは観測情報行列の逆行列の対角）

を記録する。

### 3-4. 判定（事前登録・変更禁止）
| 段 | 基準 |
|---|---|
| MINE 通過 | `|z| ≥ 2.5` |
| VALIDATE 通過 | MINE通過した特徴のみ・**VAL期間だけで再推定**し、**MINEと同符号** かつ `|z| ≥ 2.0` |
| CONFIRM 通過 | VAL通過した特徴のみ・**CONF期間だけで再推定**し、**MINEと同符号** かつ `|z| ≥ 2.0` |
| 特徴の合格 | MINE・VAL・CONF の3段すべて通過 |

VALIDATE / CONFIRM は各**1回だけ**実行する（再実行・条件変更は禁止）。
参考値として、MINE推定係数をそのまま当てた**アウトオブサンプル ΔLL** も併記する（判定には使わない）。

### 3-5. 多重比較
- 総試行数 = 27特徴 × 2目的 = **54**
- MINE の偶然期待 = 54 × P(|z|≥2.5) = 54 × 0.01242 = **0.67**
- VAL の偶然期待 = (MINE通過数) × P(同符号 かつ |z|≥2.0) = (MINE通過数) × 0.02275
- **バッチ判定**: VAL通過数 ≥ 3 × VAL偶然期待 なら「偶然では説明できない」と見なす。
  下回れば、個別に合格した特徴があっても**採掘の副産物**として扱う。

### 3-6. n の扱い
どの段でも評価に使ったレース数・馬数を必ず表に出す。**n<30 は参考表記**とし判定に使わない。

## 4. V9（合格特徴を V3 に足したモデル）

**作る条件（事前登録）**: 「MINE と VALIDATE の両方を通過した特徴が **1本以上**」のときだけ作る。
1本も無ければ V9 は作らず、その旨を報告に書く（ゼロならゼロと書く）。

### 4-1. 構成
- 一段目 V9 = 条件付きロジット（レース内 softmax・1着尤度）
  入力 = `fit_v2.build_row(..., v4=False)` の V3 行（28特徴 + field） **＋ 通過した過去走特徴（レース内z）**
- 比較対照 V3 = **同じ推定器・同じフォールド**で V3 行のみ
- 学習は月次ウォークフォワード（各評価月について、その月より**前**のレースのみで学習）

### 4-2. α の測り方（V7 二段構成と同じ）
評価月ごとに二段目
`u_i = α·log p_model_i + β·log p_market_i`
を条件付きロジットで推定する。**α>0 = モデルが市場に情報を足している**。

- フォールド = 評価6か月 `202603, 202604, 202605, 202606, 202607, 202608`
- **一次合格 = α>0 が 3フォールド連続**（V7・PLACE と同じ基準）
- あわせて `α(V9)` と `α(V3)` を並べ、**差**（新特徴が足した分）を必ず報告する。
  α(V9) > 0 でも α(V3) と同水準なら「新特徴の寄与はゼロ」と書く。

## 6. 事前に分かっている限界（先に書いておく）

1. 「同一レース内の他馬と比べた上がり順位」は保有データでは**作れない**（過去走レコードに他馬が無い）。
   as-of 標準上がりテーブルとの残差で代替する＝レース固有の展開差は残る。
2. 過去走レコードに **斤量・馬体重が無い**ため、その2項目は台帳の横断結合に頼る。
   台帳に無い期間（各馬の初出走・地方戦など）は None になり被覆が落ちる。
3. `vg`（馬場状態の別表現）は収穫初期の見落としで実測91%が2固定のため**使わない**。
4. 市場オッズは `result.order` の確定オッズ（＝発走直前の最終オッズ）。
   実運用の締切前オッズとは僅かにずれる。これは既存の全検証と同じ条件。
