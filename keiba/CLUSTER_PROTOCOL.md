## 3. ステップ1: レースの類型を「データに探させる」

### 3-1. レースベクトル（19次元・これ以外を後から足さない）

**全てレース発走前に知り得る量のみ。着順・払戻・的中は一切入れない。**

| # | 変数 | 定義 |
|---:|---|---|
| 1 | `field` | 頭数 = len(ns) |
| 2 | `dist` | 距離(m) |
| 3 | `is_dirt` | ダ=1 / 芝=0 |
| 4 | `baba_idx` | 良0 / 稍1 / 重2 / 不3 |
| 5 | `tier` | クラス（台帳の today_tier） |
| 6 | `day_no` | 開催日目 = race_id の 9-10桁目（`int(rid[8:10])`） |
| 7 | `log_fav1_odds` | log(1番人気の単勝オッズ) |
| 8 | `odds_sd` | log10(単勝オッズ) の標準偏差（母集団SD・全出走馬） |
| 9 | `top3_implied` | implied確率（1/odds を合計1に正規化）の上位3頭の和 |
| 10 | `entropy` | 混戦度 = −Σ p log p（同 implied 確率・自然対数） |
| 11 | `score_gap12` | 汎用モデル(PLACE)のOOSスコア 1位 − 2位 |
| 12 | `score_var_top5` | 同スコア上位5頭の分散（母集団分散・5頭未満は全頭） |
| 13 | `r_nige` | 脚質「逃」の割合（paper_style。未記入は分母から除く） |
| 14 | `r_senko` | 「先」の割合 |
| 15 | `r_sashi` | 「差」の割合 |
| 16 | `r_oikomi` | 「追」の割合 |
| 17 | `mean_career` | 出走馬の平均キャリア戦数（保存済み過去走数 len(races)。**上限9で打ち切られている**ことを明記） |
| 18 | `log_mean_rest` | log1p(平均 last_race_days) |
| 19 | `r_layoff` | last_race_days ≥ 90 の馬の割合（休み明け率） |

- 13〜16 は和がほぼ1（線形従属に近い）。k-means/GMM 上は許容し、報告に明記する。
- 標準化: **MINE の平均・SDでz標準化**（VAL/CONFにも MINE のパラメータを適用）。SD=0の列は0埋め。

### 3-2. クラスタリング手法（12構成・凍結）

| 手法 | k |
|---|---|
| **KM**  K-means (k-means++, n_init=20, seed=20260818) | 3, 5, 8, 12 |
| **WARD** 階層クラスタリング (Ward法・ユークリッド距離) | 3, 5, 8, 12 |
| **GMM** ガウス混合 (full covariance, reg_covar=1e-4, n_init=5, seed=20260818) | 3, 5, 8, 12 |

計 **12構成 / クラスタ総数 3×(3+5+8+12)=84**。

**割当規則（全窓共通・凍結）**
- KM / WARD: MINE で得たクラスタ中心（WARDは MINE ラベルの重心）への **最近傍中心**。
  MINE 自身も最近傍中心で割り当て直す（窓間で規則を揃えるため）。
- GMM: 学習済みモデルの `predict`（事後確率最大）。

**解釈の言語化**: 各手法・各kの全クラスタについて、19変数のz中心（MINE平均からの乖離）と
代表的な生値（頭数・距離・芝ダ比・tier分布・1番人気オッズ中央値等）を出力し、
「何が共通しているか」を必ず文章で書く。

## 4. ステップ2: 類型ごとの専用モデル

### 4-1. 学習スケジュール（凍結）

**四半期ウォークフォワード**。fold = 暦の四半期。fold q の学習データは
**q の開始日より前**のユニバース内レースのみ。予測対象は q に属するレース。

fold 一覧: 2024Q1(202403のみ) / 2024Q2 / Q3 / Q4 / 2025Q1〜Q4 / 2026Q1 / Q2 / Q3(202607-08) = **11 fold**。

（コース実験は月次30foldだったが、本実験は 84クラスタ×2目的あり計算量が10倍以上になるため
四半期に落とす。**この鈍化は専用モデルと汎用モデルの双方に等しく適用する**＝下記 GENQ。）

### 4-2. 比較する3本

| 記号 | 学習データ | 用途 |
|---|---|---|
| **SPEC** | fold q より前 かつ **同じクラスタ**のレース | 類型専用モデル |
| **GENQ** | fold q より前の **ユニバース全レース**（クラスタ無視） | ★一次判定の比較相手。SPECと**同一fold・同一特徴・同一ハイパラ**。違いは学習データの絞りだけ |
| **GEN** | `course_preds_gen.jsonl`（月次WF・202307からの全履歴） | 本番相当の汎用ベースライン。三次判定と診断に使う |

ハイパラは **全て `fit_place.BIN_PARAMS` + num_boost_round=800 / early_stopping=60**、
検証分割は「末尾10%・最低10レース」（course_system.train_generic と同一関数を使う）。
**SPEC専用のチューニングは一切しない**（差を学習データの絞りだけに帰着させるため）。

### 4-3. 小クラスタの扱い

- クラスタの **MINE レース数 < 300** → 「**専用なし=汎用流用**」と記録し、そのクラスタの
  SPEC 予測は GENQ をそのまま複製する（判定対象からも外す）。
- fold 単位で当該クラスタの学習レースが **30R未満** の場合も GENQ 流用（`spec_used=false` で記録）。

## 5. ステップ3: 判定（事前登録・変更禁止）

判定対象（judgeable）: **VALIDATE n≥50R かつ CONFIRM n≥50R かつ MINE≥300R** のクラスタ。

### 一次: α（市場に対する付加情報）

α は `place_eval` と同じ2段ロジット
`logit(y) = α·logit(q_model) + β·logit(q_market) + c`（レースクラスタ頑健SE）。
q_model は SPEC / GENQ それぞれのスコア、q_market は単勝オッズ由来。

- 各 (構成, クラスタ, 目的) について **VALIDATE の α_SPEC > α_GENQ** を成功とする。
- 成功数を、**偶然期待 = 判定対象試行数 × 0.5** と比較。
  二項検定（片側・p=0.5）で **p < 0.05** なら一次通過。

### 二次: 単勝flat ROI

SPECモデルの1位を各レース100円・全レース買い。
**VALIDATE ≥ 95% かつ CONFIRM ≥ 95%** を満たす (構成, クラスタ, 目的) を通過とする。
偶然期待は **モンテカルロ**（各レース一様ランダムに1頭を選ぶ試行を2,000回、
同一レース集合で VAL≥95% ∧ CONF≥95% を同時達成する確率）で算出し、
本プロジェクトの慣行に従い **通過数 ≥ 3 × 偶然期待 かつ 通過数 ≥ 1** を通過条件とする。

### 三次: 「特定のクラスタだけ買う」（モデルは汎用のまま・見送り戦略）

汎用モデル **GEN**（本番相当・月次WF）の1位をそのまま買う。変えるのは「どのレースを買うか」だけ。

- **選抜規則（MINE のみで決める・凍結）**: MINE で `n≥300` かつ **単勝flat ROI ≥ 100%** の
  クラスタを「買うクラスタ」に選ぶ。
- **判定**: 選抜クラスタ集合の合算で **VALIDATE ≥ 95% かつ CONFIRM ≥ 95%** なら通過。
- 券種は **単勝を主判定**、**複勝を副（同基準で併記）**。両方を試行数に数える。
- 偶然期待は「MINEでROI≥100%になるクラスタが偶然選ばれ、VAL/CONFでも95%を超える確率」を
  同じモンテカルロ枠組み（MINE選抜込み）で 2,000 回試行して算出する。

### 多重比較（必須記録）

- 試行数 = Σ(構成) 判定対象クラスタ数 × 2目的 × 2基準（一次・二次） ＋ 三次(12構成 × 2券種)。
- 実行前の見積り: 84クラスタ × 2目的 × 2基準 = 最大336 ＋ 三次24 = **最大360試行**。
- 全ての通過数を偶然期待と並べて報告する。**3倍ルールを満たさない通過は「不合格」と書く。**

## 6. 必ず報告する診断

1. **クラスタ別の汎用モデル成績**（GEN・MINE/VAL/CONF別に α・単勝ROI・複勝ROI・1位的中率）。
   クラスタ間で大きく違えば、それ自体が発見（「この類型では我々のモデルが効く/効かない」）。
2. **SPEC と GENQ の1位一致率**（クラスタ別・窓別）。一致率が高ければ「専用化は何もしていない」。
3. **クラスタの安定性**
   - 構成比の推移（MINE / VALIDATE / CONFIRM での各クラスタのシェア）
   - 中心ドリフト: MINE中心 と VAL割当メンバのz平均 のユークリッド距離
   - シルエット係数（MINE と VALIDATE）
4. クラスタ解釈の言語化（§3-2）。
5. 小クラスタ（<300R）で「専用なし=汎用流用」になった件数。

## 10. 追補（2026-08-18・**VAL/CONFを一度も見る前に記録**）

コーディネータからの優先度変更を受け、**三次（汎用モデル据え置き・クラスタは「どのレースを
買うか」の判定にだけ使う）を本命**に格上げする。一次（α比較）・二次は測るだけ測って報告する。

### 10-1. 固定ベースライン（コーディネータ提供・閾値はMINEのみで決定済み）

「例外レースを除き、残りをほぼ全部的中させる」ための除外条件:

| 記号 | 条件 |
|---|---|
| A | 市場1番人気の implied 確率 ≥ **0.341**（MINE 60%点） |
| B | implied分布のエントロピー ≤ **1.904**（MINE 40%点） |
| C | モデル1位−2位の得点差 ≥ **0.066**（MINE 40%点） |

**A∧B∧C = 「予想可能レース」**。それ以外は例外として除外。
提供値: 残存 MINE 906/4440 (20.4%) / VAL 194/874 / CONF 132/676。
複勝(市場上位2頭・各100円・2点) で MINE 94.4%/92.6%・VAL 95.9%/95.6%・CONF 92.4%/85.3%。

※本実験のユニバース(6,891R・レース数70/15/15)は提供値の分母(4440/874/676)と異なる。
**同一の閾値ルールを本実験のユニバースで実測し直した数字を併記**し、両方を報告する
（分母が違うものを混ぜて比較しない）。

### 10-2. 買い方（券種・凍結）

全て **市場（単勝オッズ）順**で選び、モデルは使わない。1点100円。

| 券種 | 買い目 | 点数 | 的中の定義 |
|---|---|---:|---|
| 複勝2点 | 市場上位2頭 各複勝 | 2 | 2頭の少なくとも1頭が3着内 |
| 複勝1点 | 市場1番人気の複勝 | 1 | その1頭が3着内 |
| ワイド3点 | 市場上位3頭のBOX | 3 | 3組の少なくとも1組が的中 |
| 三連複1点 | 市場上位3頭の1点 | 1 | その3頭が3着内独占 |

ROI = 払戻合計 /(100×点数×レース数)。

### 10-3. クラスタ由来の除外ルール（**選択は全てMINEのみ**）

**構成の選択**: 12構成のうち **MINEの複勝2点ROIが最大**になる1構成を選ぶ。
制約: 選抜後の MINE 残存 ≥ 300R かつ 残存率 ≥ 15%。**VAL/CONFは選択に一切使わない**。

**クラスタの選抜（2案・両方とも事前登録）**
- **T1（絶対基準）**: MINE の複勝2点ROI ≥ **100%** かつ MINE n ≥ 100 のクラスタ。該当なしなら「選抜ゼロ」と書く。
- **T2（相対基準）**: MINE の複勝2点ROI 降順に、累積 MINE n ≥ 300 になるまで採る。
- **T3（併用）**: ベースライン A∧B∧C **かつ** T2 の選抜クラスタ。

### 10-4. 合格基準（凍結）

**VALIDATE と CONFIRM の両方で 複勝ROI > 100% かつ 的中率 ≥ 85% かつ n ≥ 80R。**
1つでも欠けたら **未達**。99.9% でも「未達」と書く。

**多重比較**: 主判定の試行数 = T1/T2/T3 の **3**（構成はMINEで1つに決めるので1）。
Bonferroni の意味で、3試行のうち1つ通っただけでは弱い証拠であることを明記する。
12構成すべての VAL/CONF 数値は**診断として**全部載せるが、**主判定には使わない**
（使う場合は 12×3=36 試行として明記する）。
