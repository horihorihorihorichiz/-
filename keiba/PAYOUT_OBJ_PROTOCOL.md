## 0. 問い

今日までの全実験（V4/V5/V7/V8・アンサンブル・セグメント別・プール間裁定・コースバイアス）は
すべて **P(1着) を最大化**する学習だった。結果は10戦全敗、共通症状は「的中率は上がるが回収率は上がらない」。

**まだ一度もやっていないこと = 目的関数を「回収率（払戻）」そのものにする学習。**

- 従来: P(1着) 最大化 → 人気馬に寄る → 配当が安い → 回収率が上がらない
- 本実験: E[払戻] 最大化 → 「配当妙味のある馬」を高く評価する方向に学習が働くはず

これが効かないなら、「得点配分をどう変えても市場は超えられない」を配分側から閉じたことになる。

## 2. モデル（5本＋対照1本）

すべて LightGBM。ハイパラは V3（`wf_compare.train_fold`）と同一を基本とし、目的関数に伴う最小限の差のみ。
`learning_rate=0.02, num_leaves=31, min_data_in_leaf=30, feature_fraction=0.8,
bagging_fraction=0.8, bagging_freq=1, lambda_l2=5.0, num_boost_round=800, early_stopping=60`
検証分割は学習データの末尾10%（最低50R）— V3と同一。

| ID | 目的関数 | 説明 |
|---|---|---|
| **M1** | `lambdarank`（label 3/2/1・label_gain=[0,1,3,7]・ndcg@5） | **現行V3。比較対象（ベース）** |
| **M2** | `binary`（1着=1）+ **サンプル重み** | 勝ち馬の行の重み = **単勝払戻/100（=確定オッズ）**、負け馬 = 1.0。<br>重みの上限 **100.0**（1万円払戻相当）で打ち切り（1頭の300倍馬が学習を支配するのを防ぐ・事前登録） |
| **M2c** | `binary`（1着=1）重み全部1.0 | **対照**。M2の効果が「重み」由来か「binary化」由来かを切り分けるだけの診断用 |
| **M3** | `regression` 系。目的変数 = **単勝払戻 − 100**（勝ち馬 = 払戻−100、それ以外 = −100） | 「その馬を100円で買ったらいくら儲かったか」を直接予測。<br>3つの損失を全部走らせる: `M3-l2`(L2) / `M3-huber`(huber, alpha=100) / `M3-log`(目的変数を sign·log1p\|v\| に変換した L2)。<br>**主判定は `M3-huber`**（分散が極端に大きいため。事前登録） |
| **M4** | 同上を **複勝払戻 − 100** で | 該当馬に複勝払戻があれば 払戻−100、無ければ −100。<br>同じく `M4-l2` / `M4-huber` / `M4-log`。**主判定は `M4-huber`** |
| **M5** | 学習なし。**28特徴の線形結合の重みを直接探索** | 目的 = **MINE期の「モデル1位の単勝flat回収率」最大化**。<br>探索: 乱数シード20260818・N(0,1) から4,000本ランダム探索 → 上位1本を起点に座標降下3ラウンド（各次元 ±0.5/±0.25/±0.1 を試す）。<br>**探索は MINE 期のレースのみ**。VALIDATE/CONFIRM は一切見ない。得られた重みベクトルは**1本に凍結**して全期間に適用（fold毎の再学習はしない） |

### 2-1. 早期停止の指標（**実行前に確定・スモークテストで判明した仕様上の穴の手当て**）

スモークテスト（成績は一切見ていない・`best_iteration` だけを見た）で、次の2つが**学習不能**になることが判明した。

- **M2**: 重み付き binary_logloss を早期停止に使うと、ごく一部の高配当行が指標を支配し **1回で停止**（= 定数モデル）
- **M3-l2 / M4-l2**: 早期停止指標 `l2` は外れ値（高配当）が支配し **2回で停止**（= 定数モデル）

そこで**実行前に**次を確定する（成績を見た後の変更ではない）:

- **binary（M2/M2c）: 学習は重み付き、早期停止の判定は重み無し logloss**
- **regression（M3/M4 の全変種）: 早期停止の指標は常に `l1`（絶対誤差）**

学習の目的関数（重み・損失）そのものは §2 のまま変更しない。変えたのは「いつ止めるか」の指標だけ。
それでも `best_iteration` が極端に小さい（<20）モデルは「学習が起きなかった」として報告に明記する。

### 2-2. M1 の実体

M1（現行V3）は**既存のWF台帳 `wf_preds_v3ext2.jsonl` をそのまま使う**（再学習しない）。
この台帳は「汎用V3 LambdaRank 28特徴」の月次WF予測 **5,990R（202409〜202608）**で、
本実験のfold集合（`wf_ds_cache_v8.pkl` の 202409以降）と**rid が5,990件で完全一致**することを確認済み。
本実験は全モデルをこの **5,990R** に揃えて評価する。

M3/M4 の分散が極端（ほとんど −100、たまに +数千）で学習が不安定になりうる点は既知。
そのため **L2 / Huber / log変換の3本を必ず走らせ、どれを使ったか報告に明記**する。

## 3. 評価（全モデル・3分割別に必ず両方出す）

### 3-1. 基本成績（flat・全レース買い）
- **モデル1位馬の単勝**: n / 的中率 / **flat ROI** / 平均配当（的中時）
- **モデル1位馬の複勝**: n / 的中率 / **flat ROI**
- **モデル1位馬の平均人気**（人気馬に寄っているか穴に寄っているかの診断）
- 的中率 × 平均配当 の分解を必ず併記（回収率トレードオフの可視化）

### 3-2. α（市場を条件にした上積み）
二値ロジット `y ~ β0 + α·logit(q_model) + β·logit(q_market)` をクラスタ頑健SE（レース単位）で推定。
- `q_model` = モデルスコアのレース内softmax（温度τはMINE期の勝者尤度MLEで較正・モデルごと1本）
- `q_market` = 1/確定オッズ をレース内で和1に正規化
- 単勝（y=1着）と複勝（y=3着内）の2系統。分割ごとにプールして推定（in-split推定である旨を明記）

### 3-3. EV買い（実オッズ使用）
`EV = q_model × 実オッズ`。閾値 **EV ≥ 1.2**（事前登録）。単勝は `hist_odds.tan`、複勝は `hist_odds.fuku`（下限）。
分割別に n / 的中率 / ROI。精算は実払戻。

参考として M3/M4 は「予測値そのもの」による EV（`EV = (pred+100)/100`）も併記する（診断・判定には使わない）。

## 4. 追加の分析軸（2026-08-18 追記・**判定基準と分割は一切変更しない**）

「配分を変えても回収率＝的中率×平均配当の積は控除率付近に収束するのでは」という理論的整理に対する検証。
各モデルについて、以下の**見送り基準**別に「買ったレースだけ」の VALIDATE / CONFIRM 成績
（n・的中率・ROI・**見送り率**）を出す。閾値は**すべて MINE 期の分布から決める**（VAL/CONF は見ない）。

| 基準 | 内容 | 水準 |
|---|---|---|
| (a) スコア上位 | モデル1位の**レース内zスコア**が高いレースだけ買う | 上位 X% = **10 / 20 / 30 / 50**（閾値はMINE分位） |
| (b) 1位-2位差 | 1位と2位の**レース内zスコア差**が大きいレースだけ買う（確信度） | 上位 X% = **10 / 20 / 30 / 50**（同上） |
| (c) オッズ帯 | モデル1位の確定単勝オッズ帯で絞る | **<2 / 2-4 / 4-7 / 7-15 / 15-50 / ≥50** の6帯 |
| (d) EV回帰の予測値 | **M3/M4のみ**。予測値（=予想損益/100円）が閾値超えのレースだけ買う | **pred ≥ 0 / 20 / 50 / 100** |

### 4-1. 核心の診断（必須）
**「的中率 × 平均配当」がモデル間でほぼ一定か**を数表で確認する。
- ほぼ一定 → 「配分最適化は無効」の直接証拠
- 動く → 配分にまだ余地がある
