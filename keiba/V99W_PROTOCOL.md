## 3. 特徴とモデル
- 特徴12個: 11成分 + kankai := (展開乗数−1)×100。
- **レース内標準化**: z_k = (x_k − レース内平均) / レース内標準偏差。std<1e-9 → z=0。
- スコア: score(馬) = Σ_k w_k · z_k。温度は1固定（スケールはwが吸収）。
- 目的関数: **Plackett-Luce**（1着→2着→3着の順序尤度）を最尤化。
  対象レース条件: 採点馬（着順あり）≥5頭、かつ1・2・3着が全て採点馬に含まれる。
- 最適化: scipy L-BFGS-B（解析勾配）。

## 4. 腕
### 腕A（全体1本 w_g）
- 現行Ver.99.27配点（=生成分の等重み合算×乗数、score=WAvg）との比較。
  現行側の温度 T_base は MINE のみで1次元最適化して与える（現行に不利にならないため）。
- w_g の正則化: ridge λ_g·‖w‖²、グリッド {0.0003, 0.001, 0.003, 0.01, 0.03}、
  MINE内部分割の後方20%のNLLで選択。

### 腕B（条件別 w_c = w_g + δ_c、δはL2でw_gへ縮小）
条件軸は以下の4つ**だけ**。グループごとに mean-NLL + λ_B‖w_c−w_g‖² を最小化。
λ_B は軸ごとにグリッド {0.01, 0.03, 0.1, 0.3, 1, 3} を MINE内部分割で選択。
- ① コース: 場×芝ダ×距離。MINE 40R以上の64グループ（5,884R）のみ個別、他は w_g。
- ② VG: today_vg（データ実在値 1/2/3/4）。
- ③ 芝ダ×距離帯: surface × dist_cat（S/M/L）の6グループ。
- ④ クラス: today_tier 帯 {10}=未勝利 / {6}=1勝 / {5}=2勝 / {3,4}=3勝・OP重賞。

## 5. 評価（各期 × 各腕、決定は全てMINE、V/Cは最後に1回）
- (a) ΔLL/R: PL対数尤度（レース平均）の現行比。全対象レースで測定。
- (b) モデル1位の単勝: 的中率・ROI（1位に100円、払戻=result.payout単勝）。
- (c) 複勝: 1点（1位）と2点（1位+2位、各100円）の的中率・ROI。
- (d) 三連複1点: モデル上位3頭1点、的中率・ROI。
- スコア同点時の順位は 現行WAvg → 馬番の小さい方 で決定（決定的に固定）。
- 払戻対象は payout がある全レース（実質全レース）。
