## 0. 結論（先頭）

**一次（統計）と二次（安定性）は合格した。三次（三連複1点ROI 100%超）は不合格。総合＝不合格。**

| 段 | 基準 | 結果 | 判定 |
|---|---|---|---|
| 一次 | VALIDATE と CONFIRM の **真のOOS ΔLL > 0** | VAL **+0.529 nats**（834R）／ CONF **+12.876 nats**（641R） | **合格**（ただしVALは実質ゼロ・§3参照） |
| 二次 | **α > 0 が6フォールド全部** | **6/6 が正**（+0.076 〜 +1.955） | **合格** |
| 三次 | VAL/CONF 両方で **三連複ROI > 100%**・n≥80R | VAL **96.4%**（n=184）／ CONF **71.4%**（n=128） | **不合格** |
| 総合 | 3つすべて | — | **不合格** |

**要点（数字で書く）:**

1. **V3 を外した効果は本物だった。** `CORNER_REPORT.md` の V10（V3経由）は α が 6フォールド中1つしか
   正にならなかったが、**V3 を外して市場オフセット＋4特徴だけにすると α は 6/6 で正**になった。
   一次の OOS ΔLL も両期間で正。**「ボトルネックは新特徴ではなく V3」という前回の結論は支持された。**
2. **しかし効果量が桁違いに足りない。** MINE の期内 ΔLL は +58.2 nats / 6,168R = **+0.0094 nats/レース**。
   1レースあたりの市場自身の対数尤度は **−6.043** なので、上積みは **0.16%** にすぎない。
   λ の内部CVでも held-out LL/R は λ を10通り動かして **−6.04303 〜 −6.04535**（6桁目でしか動かない）。
3. **三連複1点は 100% に届かない。VAL 96.4% / CONF 71.4%。未達である。**
   必要とされた「的中率 +3.5pt（14.9%→18.4%）」に対し、実測は VAL 19.6% / CONF **8.6%**。
   CONFIRM で的中率が半減しており、+3.5pt どころか市場水準（7.8%）付近から動いていない。
4. **「モデルが市場に勝った分」は 18レースしかない。** VALIDATE+CONFIRM の 312レースのうち、
   モデルの上位3頭が市場の上位3頭と**違ったのは 18レース（5.8%）だけ**。
   その18レースでの的中は モデル3本 / 市場2本。**ROI差の全部が、この「1本多く当たった」から来ている。**
   これは統計的な証拠ではない。**ROIの上振れを実力として報告しない。**

## 1. モデルと実行条件

```
u_i = log(pm_i) + x_i·θ      市場は log-odds オフセット・係数1固定（学習させない）
q_i = softmax(u) over race   条件付きロジット（レース内正規化）
目的 = 3着内の並び（Plackett-Luce 3段展開）
θ=0 のとき q ≡ pm（＝素の市場）
```

| 項目 | 値 |
|---|---|
| 台帳 | `hist/*.json` → `corner_frozen_ids.json` と**完全一致**する **7,643R**（プログラムで照合・True） |
| 1-3着すべて特定 | 7,590R / 7,643R（残り53Rは同着等。該当段だけ尤度から外す） |
| 分割 | MINE 〜202602 **6,168R** ／ VALIDATE 202603-05 **834R** ／ CONFIRM 202606-08 **641R** |
| 説明変数 | **4本のみ**（`spd_res` / `mgn_abs` / `wide4c` / `pos_gain`）＝ CORNER で3段通過したもの。**追加ゼロ** |
| 正則化 | L2 のみ。**λ は MINE の内部5分割CV（レース単位・rid mod 5）だけで決定** → **λ = 0.03** |
| 市場確率 | `result.order` の確定オッズ。`1/odds` をレース内で合計1に正規化 |

## 2. θ と符号一致

| 特徴 | θ(MINE) | θ(VALIDATE単独) | θ(CONFIRM単独) | 符号一致 |
|---|---:|---:|---:|---|
| `spd_res` | +0.0061 | +0.0231 | +0.0444 | ○ / ○ |
| `mgn_abs` | **+0.1025** | +0.0407 | +0.1812 | ○ / ○ |
| `wide4c` | +0.0131 | +0.0221 | +0.0074 | ○ / ○ |

## 3. 一次判定 — 真のOOS ΔLL

`θ_MINE` をそのまま当てた `ΔLL = LL(θ_MINE) − LL(0)`。`LL(0)` は素の市場（学習パラメータゼロ）なので、
VALIDATE / CONFIRM の値は**正真正銘の期外値**である。

| 分割 | ΔLL | n(レース) | ΔLL / レース | 市場自身の LL/レース | 上積み比 |
|---|---:|---:|---:|---:|---:|
| MINE（期内・参考） | **+58.245** | 6,168 | +0.00944 | −6.043 | 0.16% |
| VALIDATE（真のOOS） | **+0.529** | 834 | **+0.00063** | −6.043 | **0.010%** |
| CONFIRM（真のOOS） | **+12.876** | 641 | **+0.02009** | −6.043 | 0.33% |

**一次＝合格（VAL>0 かつ CONF>0）。** ただし正直に書くと:

- **VALIDATE の +0.529 nats は 834レース分の合計**である。1レースあたり 0.00063 nats、
  市場の対数尤度の **1万分の1**。符号は正だが、**ゼロと区別できる水準ではない**。
  事前登録した基準は「> 0」なのでこれは合格だが、**この数字を根拠に実弾は動かせない**。
- CONFIRM の +12.876 nats は VALIDATE の24倍だが、期間が短い（641R）分だけ振れやすい。
  MINE→VAL→CONF で 0.0094 → 0.0006 → 0.0201 と**単調ではない**。

## 4. 二次判定 — α（追加項を1本のスコアにまとめた係数）

`s_i = x_i · θ_MINE` を1列にして、各フォールド月で `u_i = o_i + α·s_i` の α を推定した
（市場は係数1固定のまま。α はフォールド内推定なので、下の「期内ΔLL」は期外値ではない）。

| フォールド | n | **α** | 期内ΔLL |
|---|---:|---:|---:|
| 202603 | 277R | **+0.9321** | +2.034 |
| 202604 | 250R | **+0.0760** | +0.012 |
| 202605 | 307R | **+0.5565** | +0.737 |
| 202606 | 221R | **+1.7940** | +6.479 |
| 202607 | 246R | **+1.2098** | +3.185 |
| 202608 | 174R | **+1.9550** | +6.127 |

**二次＝合格（α>0 が 6/6）。**

- V10（V3経由）は α>0 が **1/6** だった。V3 を外しただけで **6/6** になった。
  **前回の結論「ボトルネックは V3」はこの数字で裏付けられた。**
- ただし 202604 の α=+0.076（期内ΔLL +0.012 nats / 250R）は**実質ゼロ**である。
  「6/6 で正」は基準を満たすが、6つのうち1つはゼロ同然だと明記しておく。
- α が1前後ということは「MINE で測った上積みを、そのままの重さで使ってよい」という意味であり、
  **上積みの向きは正しいが、上積みの量そのものが小さい**（§3）ことは変わらない。

## 5. 三次判定 — 例外除外レースでの三連複1点ROI（本命・**不合格**）

対象 = A(`fav_p≥0.341`) ∧ B(`ent≤1.904`) ∧ C(`sgap≥0.066`)。
`fav_p`/`ent`/`sgap` は `wf_preds_v3ext2.jsonl` から取得（`corner_frozen_ids` との共通 5,717R が母集団）。
買い目 = **本モデルの `P3`（Harville）上位3頭で三連複1点**。**買い方の探索はしていない（試行数 0）。**

| 分割 | n | **モデル 三連複ROI** | 的中率 | 平均配当 | 市場のみ(θ=0) ROI / 的中 |
|---|---:|---:|---:|---:|---|
| MINE | 865R | 82.4% | 15.1% | 544円 | 79.2% / 14.7% |
| **VALIDATE** | **184R** | **96.4%** | **19.6%** | 492円 | 96.0% / 19.6% |
| **CONFIRM** | **128R** | **71.4%** | **8.6%** | 831円 | 55.6% / 7.8% |
| （参考）VAL+CONF | 312R | 86.1% | 15.1% | — | 79.5% / 14.7% |

**三次＝不合格。VALIDATE 96.4% は 100% 未満。CONFIRM 71.4% は 100% に遠い。**
n は VAL 184R / CONF 128R で n≥80R の条件だけは満たしている。

### 5-1. 必要だった上積みと実測の差
コーディネータ提示の必要条件は「三連複1点で的中率 **+3.5pt**（14.9% → 18.4%）」だった。

| | 必要 | MINE 実測 | VALIDATE 実測 | CONFIRM 実測 |
|---|---|---|---|---|
| 的中率 | 18.4% | 15.1%（市場14.7%・**+0.4pt**） | 19.6%（市場19.6%・**±0.0pt**） | 8.6%（市場7.8%・**+0.8pt**） |

**モデルが市場に上積みした的中率は +0.0 〜 +0.8pt で、必要な +3.5pt の 4分の1以下。**
VALIDATE が 19.6% と必要水準を超えているのは**市場だけでも 19.6%** だからで、モデルの寄与ではない。

### 5-2. ROI の差はほぼ全部が18レースの偶然
VALIDATE+CONFIRM の **312レースのうち、モデルの上位3頭が市場の上位3頭と違ったのは 18レース（5.8%）だけ**。
残り 294レースはまったく同じ買い目である。

| その18レースだけ | 的中 | ROI |
|---|---|---|
| モデル上位3 | **3本 / 18** (16.7%) | 254.4% |
| 市場上位3 | 2本 / 18 (11.1%) | 138.9% |

**VAL+CONF の ROI 差（86.1% − 79.5% = +6.6pt）は、18レース中「1本多く当たった」ことだけで説明できる。**
的中1本の有無で ROI が数十pt動く水準であり、**統計的な根拠にはならない**。CONFIRM の
71.4% vs 55.6%（+15.8pt）も同じ性質で、**この上振れを実力として採用しない**。

### 5-3. 既存ベースラインとの照合（測定の健全性チェック）
`EXCLUSION_REPORT_20260818.md` の「三連複 市場上位3(1点)」と、本稿の「市場のみ(θ=0)」を比べる。

| | EXCLUSION（n=906/194/132） | 本稿 市場のみ（n=865/184/128） |
|---|---|---|
| MINE | 14.1% / 78.9% | 14.7% / 79.2% |
| VALIDATE | 19.6% / 98.9% | 19.6% / 96.0% |
| CONFIRM | 8.3% / 57.4% | 7.8% / 55.6% |

**ほぼ再現している**（差は母集団が 5,990R vs 5,717R と違うことによる）。測定系は健全である。
なお EXCLUSION の「三連複 モデル(V3)上位3(1点)」CONFIRM 90.1% は本稿の 71.4% より高いが、
それは n=132 で的中 13本 vs n=128 で的中 11本という差であり、**どちらも 100% 未満で結論は変わらない**。

## 6. 何が分かったか / 何が分からないままか

**分かったこと（数字で言えること）:**
1. **V3 を外すと α は 1/6 → 6/6 になる。** モデルの形を「市場オフセット＋少数特徴」にすれば、
   新4特徴の情報は**符号を保ったまま市場の上に乗る**。前回の診断は正しかった。
2. **その情報量は 1レースあたり 0.0006〜0.02 nats。** 市場自身（−6.043 nats/R）の 0.01〜0.33%。
   λ を4桁動かしても held-out LL が6桁目でしか動かないことが同じことを別角度で示している。
3. **その情報量では買い目がほとんど変わらない。** 上位3頭が市場と入れ替わるのは 312レース中 18レース（5.8%）。
   **買い目が変わらなければ ROI は変わらない**ので、ROI 100% 超は構造的に届かない。
   控除率25.1%の壁に対して、5.8%のレースでしか動かせない。

**分からないままのこと（今回測っていない）:**
- 特徴を増やせば買い目の変動率（5.8%）が上がるのかどうか。**本プロトコルは4本限定なので測っていない。**
  増やす場合は試行回数を記録して多重比較をやり直す必要がある。
- 三連複を1点ではなく複数点にした場合。**買い方の探索は事前登録で禁止したので測っていない（試行数0）。**
- 複勝・ワイドの発走前オッズを使った「価格に対する妙味」での購入。台帳に発走前オッズが無いため測れない。
