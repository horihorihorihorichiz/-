## 到達できなかったこと ＋ その理由（すべて実測）

### ROI 100% には、どの経路からも届かなかった

| 経路 | 最良 CONFIRM | なぜ止まったか |
|---|---|---|
| 例外除外の精密化（クラスタリング12構成） | 91.3% | 3閾値と同値、レース数は半分 |
| 除外後の買い方変更（54通り探索） | 84.0% | MINE 106% を作れるが CONFIRM で崩れる |
| コース類型化（G1/G2/G3、7系列） | 95.1% | 類型は3指標の代理変数 |
| 市場条件付きモデル → 三連複1点 | 71.4% | 買い目が5.8%しか変わらない |

### 決定的な3つの数字

**(1) 複勝2点は構造的に100%不能**
82クラスタ横断で `ROI = 0.726 × 的中率 + 22.5`。
**的中率100%を外挿しても ROI = 95.1%。**
的中1回あたり払戻が196〜199円で、投下200円を常に下回るため。
払戻の大きいクラスタ（216円）は例外なく的中率が低い（71%）。トレードオフが完全。

**(2) 新しい軸は存在しない**
- クラスタリングのシルエット 0.026〜0.122 ＝ レースは明瞭な群を成さない
- 出てきた軸はクラス/市場の割れ/頭数/芝ダ距離/馬場/脚質/休み明け ＝ **既に人が使っている括り**
- コース類型が分離できる的中率幅は **5.0pt**（82.9→87.9%）。
  市場1指標 fav_p は **23.2pt**（71.3→94.5%）分離する。**1/5以下。**
- 類型の的中率は fav_p と +0.50、ent と −0.53、sgap と +0.59 の相関 → 代理変数
- ヌル検査（ラベル1,000回シャッフル）で G1 は偽類型でも 48.8% の確率で再現 ＝ ノイズ

**(3) 勝ったモデルのエッジは市場の 0.16%**
MKTCOND の上積みは +0.0094 nats/レース。市場自身の LL/R は −6.043。
λ を 0→1 と4桁動かしても held-out LL/R は6桁目でしか動かない。
実務上の帰結: VAL+CONF 312R のうちモデル上位3頭が市場と違ったのは **18R（5.8%）** だけ。
残り294Rは買い目が完全に同一 → ROI が動きようがない。
三連複で必要だった的中率上積み +3.5pt に対し、実測は +0.0〜+0.8pt（必要量の1/4以下）。

## 潰れた言い訳

- 「分けるとデータが足りないから負けた」
  → コース類型 G1 で学習1,000〜2,000R（前回の最大コース330Rの3〜6倍）に達しても Δα=−0.0040（SE 0.037）。
    データ量と Δα に単調な傾向なし。**この規模では反証された。**
- 「特化が足りなかったから負けた」
  → 今回の1位一致率は 54.3〜75.0%（前回方式3は79.7〜90.1%）。**本当に特化した上で負けた。**
- 「V3 が弱いから乗せた特徴が死んだ」
  → 正しかった。V3 を外したら α が 1/6 → 6/6 に反転した。
    ただし反転しても勝てる量には足りない（上記(3)）。

## 残っている道は1本だけ

**市場の価格ズレを突く。** レースの「当たりやすさ」で切る方向は市場が織り込み済みで、
上の4経路すべてがそこで止まった。MODEL_V4_RESULT.md の結論
（オッズ抜きで控除率を超えるのは不可能）と完全に一致する。

具体的には、自前で作るオッズ時系列（odds_timeline.py、8/22の開催から収集開始）で
「発走前オッズ → 確定オッズ」の動きを測り、確定オッズが読める部分があるかを見る。
実測済みの予備データ（n=20-34）では 単勝 0.73x / 複勝 0.69x / ワイド 0.96x / 三連複 1.91x。
※パリミュチュエルなので払戻は常に確定オッズ。この倍率は
「判定時に見えているオッズが確定オッズの偏った推定値である」ことを意味する。
＝ 三連複のEVを約半分に過小評価し、単勝のEVを約3割過大評価している。

これが外れたら、控除率を越える手は現時点で無い、と結論する。
