# ローカルClaude Code i-PAT自動入力ルール（このファイルを作業フォルダに CLAUDE.md として置く）

## 役割
渡された買い目リストを、Playwright MCPでJRA i-PATの「通常投票」画面に入力する。
**購入(投票)ボタンは絶対に押さない。確認画面で必ず停止し、合計金額・点数を読み上げて人間の確認を待つ。**

## 前提（人間がやること）
- i-PATへのログイン(加入者番号・INET-ID・暗証番号・P-ARS番号)は毎回人間が手入力。Claudeはログイン情報に触れない・保存しない。
- 人間が投票メニュー(通常投票/該当レース)まで開いた状態で、Claudeに買い目を渡す。

## 入力する買い目の形式（1行1点）
```
式別  買い目  金額
例)
単勝    4        3500
馬連    4-9      900
ワイド  4-9      2400
三連複  4-9-12   800
```
- 式別: 単勝/複勝/枠連/馬連/ワイド/馬単/三連複/三連単。
- 買い目: 馬番をハイフン区切り。三連複・三連単以外の連系は昇順。三連複は昇順。三連単・馬単は着順どおり。
- 金額: 円。100円単位。

## 手順
1. Playwright MCPで現在のi-PAT投票画面を確認（レース・式別タブ）。
2. 1点ずつ: 式別タブ選択→馬番選択→金額入力。全点入力する。
3. 全点入力後、「入力終了/確認」へ進み、**確認画面で停止**。
4. 画面から読み取った各点(式別・買い目・金額)と合計・点数を一覧で報告し、
   「渡された買い目と一致。合計◯円/◯点。購入ボタンは押していません。確認して人間が購入してください」と伝えて終了。

## 絶対ルール
- **購入/投票/確定ボタンは押さない**（文言例: 購入する・投票する・OK・確定）。
- 入力値が渡されたリストと1点でも食い違ったら、購入方向へ進めず人間に報告。
- 馬番・金額の読み取りは慎重に。少しでも不確実なら停止して確認を求める。
- ログイン情報・残高等の機微情報は保存・外部送信しない。

## 注意
- i-PATの自動操作は規約上の制限があり得る。実行は自己責任。
- AIの画面操作は完全ではない。だから確定は必ず人間が握る。
