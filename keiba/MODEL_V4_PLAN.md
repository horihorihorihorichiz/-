# V4 モデル作り替え計画（2026-07-26・7/26の-43,000円を受けて）

## なぜ作り替えるか
V3は「強い馬を選ぶ」能力で市場に負けている（モデル診断 7/25）:
- モデル1位の勝率 25.0% vs 市場implied 27.9% ＝ **−2.9pt**
- 市場1番人気は32.8%勝つ。モデル1位は25.0%しか勝たない
- 唯一勝てるのは「市場が見捨てた馬(7倍+)」だけ ＝ **オッズ無しでは成立しない**

ユーザー要求: 「オッズで判断はやめよう。それならシステム変えよう」
→ **モデル単体で市場を上回れるようにする**のが V4 の目標。

## 診断で判明した欠落（7/26）
| 項目 | V3の状態 | 影響 |
|---|---|---|
| **枠番** | 特徴に**存在しない** | 「外枠のモデル2位が1位を逆転(186%/n200)」の直接原因。内枠の同条件は83.2%で死亡＝枠で系統的にズレている |
| **今日の馬場** | 特徴に**存在しない**（`wet_apt`は過去の道悪実績のみ） | 7/26新潟が良→不良に変わったら得点1位が⑬→③に入替。今日の馬場を知らずに予想していた |
| **コース特性VG** | 学習データ**全6,701件でvg=2固定**（収集時のバグ） | 内回り/外回り・瞬発/消耗の区別を一切学習していない |

## V4 の変更点
### 1. 特徴を追加（27 → 32前後）
- `waku` : 枠番(1-8) ※`course.jra_waku(馬番, 頭数)`
- `waku_rel` : 枠番のレース内相対位置 (waku-1)/7
- `umaban_rel` : 馬番の相対位置 (num-1)/(field-1)
- `baba_today` : 今日の馬場 (良0 / 稍1 / 重2 / 不3)
- `baba_x_wetapt` : 今日の馬場 × その馬の道悪実績（交互作用）
- `today_vg` : コース特性1-5 ※**hist を再生成して正しい値を入れる**
- `waku_x_surface` : 枠 × 芝ダ（芝は内有利・ダは外有利のFSI知見）

### 2. hist の VG を修正
`course.course_vg(venue, surface, dist)` で 6,701件を再計算して上書き（再収穫不要・
race側のフィールドを書き換えるだけ）。

### 3. 学習設定
- LambdaRank は維持（ラベル 1着3/2着2/3着1/圏外0）
- **1位インフレ対策**: 上位2頭の得点差にペナルティ or `lambdarank_truncation_level` 調整
- ウォークフォワード（月次）で評価。**単一のtest期間だけで判断しない**

### 4. 合格判定（これを満たさなければ V3 のまま）
| 指標 | V3現状 | V4目標 |
|---|---|---|
| モデル1位の勝率 − 市場implied | **−2.9pt** | **≥ 0pt** |
| モデル1位の単勝ROI(全レース) | 74.5% | ≥ 85% |
| 乖離帯(10倍+×上級)のROI | 412.2% | **壊さない**（≥300%） |
| 外枠モデル2位の逆転 | +9.3pt(バグ) | **消える**（枠を学習すれば1位に統合されるはず） |

※ 4つ目が重要: V4が正しく枠を学習していれば、「外枠の2位」は「1位」に繰り上がるので
　 あのパターン自体が消滅する。消えなければ枠以外に原因がある。

## 手順
1. `hist_fix_vg.py` : 6,701件の today_vg を course.py で再計算・上書き
2. `fit_v2.py` の FEATS に7特徴を追加（特徴生成もそこに追記）
3. `hist_feat` キャッシュを再生成
4. `fit_v3.py --write` で学習 → `walkforward_v3.py` で月次WF評価
5. `verify_all.py` で既存パターンが壊れていないか監査
6. 合格したら model_v3.txt を差し替え、不合格なら V3 を維持して原因を記録
