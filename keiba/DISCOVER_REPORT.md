## 0. 結論（先頭）

**一次基準は合格。二次基準（買い目）は不合格。**

| 段 | 基準 | 結果 |

**中身の要約（数字は §3〜§8 に全部出す）:**

1. **データ自身に探させたら、共通点は確かに出た。しかもその正体は「馬の強さ」ではなく
   「市場の値付けのクセ」だった。** 生き残った特徴の**係数は大半が負**
   （市場係数を自由推定した厳しい版では 102本中 **68本が負**）。
   負の係数＝**「その特徴が良い馬ほど、単勝オッズが示す確率より当たらない」**。
2. **一番強い共通点は「最近勝っている馬・上のクラスにいた馬は買われすぎ」**。
   直近3走の勝率・3着内率・在籍クラスのレース内順位が上位の馬は、
   実測勝率が市場implied勝率を **MINEで −0.77pt / OOS(VAL+CONF)で −1.62pt** 下回る（§8の表）。
   逆に下位〜中位の馬は +0.1〜+0.7pt 上回る。
3. **通過順から出た共通点は「外を回した馬・道中で動いた馬は買われなさすぎ」**。
   最終角で位置を下げる（＝外を回す）経験がある馬、道中の通過順のブレが大きい馬、
   4角で最後方付近まで下げた経験がある馬が、いずれも市場より走る。
   `move_last|min9`(z=−5.14) / `c_sd_rate|rank_mean3`(z=+5.64) / `cL_rate|max3`(z=+4.56)。
4. **「市場のオッズ目盛りの歪み（控除率・人気-穴バイアス）を直しているだけ」ではない。**
   市場log-oddsの係数を自由推定すると通過は 346→**102本**に落ちるが、
   束のOOS ΔLL は **VAL +9.26 / CONF +12.33 nats** と両方で正のまま。
   2次項まで統制しても **VAL +8.77 / CONF +11.94**。信号は残る。
5. **それでも「買える」ところまでは届かない。** B-sd16 に加点した形で複勝的中率は
   MINE +4.65pt / VAL +5.03pt / CONF +4.74pt（複勝1点）と3期とも素直に上がるのに、
   **CONFIRMのROIは下がった**（複勝1点 86.79%→85.98%）。的中率が上がってROIが下がる＝
   **上がった分が人気馬の的中で、配当が付いていない**。`CONCLUSION_20260818.md` の
   「複勝2点は ROI = 0.726×的中率 + 22.5」という構造式のとおりの結果である。
6. 効果量は小さい。市場条件付きの増分は **1レースあたり +0.016〜+0.059 nats**
   （市場log-odds 1本が持つ情報量の数%オーダー）。**実弾に載る話ではない。**

## 4. ヌル検査（事前登録版が壊れていたので、壊れている事実ごと報告する）

### 4.1 事前登録どおりの「レース内一様シャッフル」は、この設計では検定にならない

結果は **ヌル通過 723 / 744 / 744本（868本中）**、実データ 346本より多い。
事前登録の判定式に当てはめれば「棄却」だが、**これはヌルが壊れている**。理由は実測で確定している:

| | mean(z) | sd(z) | \|z\|の最大 |
|---|---|---|---|
| 実データ | +1.67 | 5.64 | 17.5 |
| 一様シャッフル null0 | **+16.57** | **41.30** | **130.1** |
| 同 null1 | +16.78 | 42.14 | 133.6 |
| 同 null2 | +16.51 | 41.69 | 130.5 |

着順を一様にシャッフルすると、**固定したオフセット（市場log-odds）が偽データに対して誤特定**になる。
βは「情報を足す」のではなく「間違ったオフセットを打ち消す」方向に動き、|z|が100超になる。
帰無仮説のもとで z が N(0,1) にならない以上、この偽データは検定として使えない。
**事前登録の設計ミスであり、結果を見てから基準を緩めたのではない**（実データの通過数を見る前に
ヌルのz分布が異常であることが確定している。生データは `discover_mine_result.json` の `z_null*`）。

### 4.2 補正版: 市場implied確率から着順を生成するヌル（`discover_null.py`）

「市場が知っていること**以上**の情報は無い」という帰無仮説を、
**市場implied確率から1〜3着を生成した偽データ**（Gumbel-top3 = PLサンプリング）で作る。

| seed | mean(z) | sd(z) | \|z\|≥2 | **\|z\|≥4.022** |
|---|---|---|---|---|
| 20260821 | +0.117 | 0.940 | 22本 | **0本** |
| 20260822 | −0.049 | 0.890 | 25本 | **0本** |
| 20260823 | −0.225 | 0.930 | 29本 | **0本** |

zは概ね N(0,1) に較正されている（sdがやや1未満＝わずかに保守的）。
**偽データ通過 0本 に対し実データ 346本 → ヌル検査 通過。** 発掘結果は偽陽性の山ではない。

## 5. 頑健性: 「市場の目盛りを直しているだけ」ではないことの確認（一次基準の**後**に実施）

一次基準はオフセット係数を1に固定している。単勝オッズ逆数の正規化確率には控除率と
人気-穴バイアスによる既知の歪みがあるため、「オッズ水準の言い換え」でも有意になりうる。
そこで**市場log-oddsの係数aを自由推定**して同じ検定をやり直した（`discover_ctrl.py`）。

- 市場log-odds単独の最尤係数 **a = 0.8498 (SE 0.0071)**。LL/R は −6.0713（a=1固定）→ **−6.0383**。
  つまり **市場の確率はレース内で少し過大に振れており、0.85倍に縮めた方が当たる**（既知のFLBと整合）。
- 各候補を a 自由で再検定 → **MINE通過 102本 / 868本**（固定aの346本から減る）。
  **符号は 負 68本 / 正 34本**。
- §6の束（140本）を a 自由で組み直した真のOOS: **VAL +9.26 nats (+0.0106/R) / CONF +12.33 nats (+0.0182/R)**。
- さらに **市場log-oddsの2次項まで統制**（レース内中心化）しても:
  a1=0.868, a2=−0.0124 に対し、束のOOSは **VAL +8.77 / CONF +11.94 nats**。

→ **信号は市場の目盛り補正では説明しきれない。** ただし規模は小さい（1レースあたり0.01〜0.02 nats）。

**「実績が見えやすい馬」ほど市場が数%買いすぎ、その分が見えにくい馬に落ちている。**

### 8.2 二番目の共通点: **外を回した馬・道中で動いた馬は買われなさすぎ**

`move_last|mean5`（最終角で上げた幅＝正は内で拾う/負は外を回して下げる）の5分位:

| z5分位 | MINE 差(実測−implied) | OOS 差 |
|---|---|---|
| 1（最も外を回して下げる） | **+0.36pt** | **+0.42pt** |
| 2 | +0.08 | +0.69 |
| 3 | −0.01 | −0.21 |
| 4 | −0.18 | −0.68 |
| 5（最も内で位置を上げる） | −0.25 | −0.23 |

同族の生き残り: `c_sd_rate`（道中の通過順のブレ＝動く馬。**+側で12本**通過）、
`cL_rate|max3`（一度でも4角最後方付近）、`unlucky|min9`（一度でも位置より着順が良い＝差した経験）、
`cL1_rate|max9` / `cL2_rate|median5`（3角・2角が後ろ寄り）。
**要するに「前で立ち回って着順を作った馬」に市場は高く払い、
「外を回した・後方から動いた・道中で動いた」馬に安く払う。実測は後者にわずかに寄る。**
これは B-sd16 が既に持っている `wide4c`(最終角で外へ) / `pos_gain`(道中で位置を上げる) と同じ鉱脈で、
**今回はそれが「人が思いついた1本」ではなく機械生成868本の中から独立に浮上した**という意味を持つ。

### 8.3 三番目: 間隔とペース経験

- `days|trend3_9`（直近3走の間隔 − 9走平均の間隔、z=−5.93）:
  **自分の平常より間隔が延びてきた馬は買われすぎ / 詰まってきた馬は買われなさすぎ。**
- `pace_diff|slope5`（前傾ラップ経験の増加トレンド、z=+4.06）:
  **前半の速い流れを最近経験するようになった馬は市場より走る。**

### 8.4 出てこなかったもの（＝共通点ではなかった）

上がり3F単体（`agari`）は固定a版では17本通ったが**市場係数を自由にすると1本も残らない**
＝「上がりが速い馬が来る」はほぼ完全にオッズに織り込み済み。
馬番率（`uma_rate`＝枠の内外）は868本中の通過1本のみ、距離・コース格も1本ずつで、
**枠順・コース格に市場の取りこぼしは無い**。

## 10. 限界（ここは数字で認める）

1. **効果量が小さい**。市場条件付きの増分は 1レース +0.016〜+0.059 nats。
   市場log-odds単独の LL/R が −6.04 であることに対し 0.3〜1%の改善に過ぎない。
2. **二次基準（買い目）は未達**。CONFIRMでROIが下がった以上、**実弾にもW12のような前向き検証にも載せない**。
3. 事前登録したヌルは設計ミスで成立しなかった（§4.1）。補正版で通過したが、
   **「事前登録どおりに1回で通した」とは言えない**。次回は「オフセット固定モデルのヌルは
   オフセットと整合的に生成する」を最初から書く。
4. 相関0.8での間引きは貪欲法で、残った140本には依然として強い相関が残る
   （事実、`w_bsd16_add` の係数は互いに打ち消し合う符号を含む）。束の解釈は個別zで行い、係数では行っていない。
5. 記述表の5分位は離散値の特徴（`win|mean3` 等）でビンが潰れる（n=0のビンが出る）。
   その場合は分位の代わりに実質3ビンで読むこと。
