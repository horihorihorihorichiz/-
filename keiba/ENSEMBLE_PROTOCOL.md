# 特徴部分集合アンサンブル（5専門家合議）実験 事前登録書

作成: 2026-08-18（**実行前に保存。以後この文書は変更しない**）
実装: `ensemble.py`（新規・既存経路は一切変更しない）

## 0. 仮説と背景

- 失敗済み: ①セグメント別モデル（データ分割）＝データ減の害が勝ち（SPECIALIST_REPORT_20260817.md）
  ②単一の全特徴モデル＝市場に4連敗（α<0）。
- 未検証: **同じ全データを使い、特徴の部分集合だけを変えた複数モデルを作り、その合議で買う**。
  データ量は減らないまま、誤り方の異なるモデルを作れる可能性がある。
- 先行実測（WATCHLIST W10）: 「モデル1位 ∧ 前走tsi最高」が一致したレースは3期間すべてで勝率+8〜13pt
  （検証+確認485RでROI85.1%）。ただし単体flatでは控除率を超えていない。本実験はその一般化。

## 1. データ・学習手順（V3と完全同一。差は「使う特徴」だけ）

- データセット: `wf_ds_cache_v8.pkl`（`fit_v2.load_dataset("hist","hist_feat",v8="all")`）
  = 台帳7,699R。評価対象は月次WFのfold 202409〜202608（24フォールド・5,990R。汎用V3台帳と同一集合）。
- 各fold `m`: 学習 = `date[:6] < m` の全レース（**セグメント分割はしない＝全レース・全データ**）、
  評価 = `date[:6] == m`。
- 学習器: LightGBM `lambdarank`。ハイパラは `wf_compare.train_fold` の非binary枝と**完全同一**:
  `learning_rate=0.02, num_leaves=31, min_data_in_leaf=30, feature_fraction=0.8,
  bagging_fraction=0.8, bagging_freq=1, lambda_l2=5.0, metric=ndcg, ndcg_eval_at=[5],
  label_gain=[0,1,3,7], num_boost_round=800, early_stopping(60)`、
  検証分割 `n_val = max(50, len(train)//10)`（学習集合の末尾）。既定seed。
- **目的変数の2系統**（ハイパラは同一のまま label だけ変える）:
  - `top3`（3着内モデル）: 1着=3 / 2着=2 / 3着=1 / その他=0 ← V3と同一ラベル
  - `win`（1着モデル）: 1着=3 / その他=0
- 合計 5専門家 × 2目的 × 24fold = 240回の学習。

## 2. 5専門家の特徴割当（実在する特徴名のみ・重複は明記）

特徴プールは `fit_v2.py` の `FEATS + RAW_FEATS + CTX_FEATS + EXTRA_FEATS + TENKAI_FEATS`
＋ `course_bias.py` のV8特徴（F1/F2/F4）。

- **E1 スピード型（8本）**: `idx_mean3, idx_last, idx_best, idx_trend, agari_best,
  agari_mean3_rel, agari_dist_match, agari_close_q`
- **E2 実績型（11本）**: `fin_frac, fin_w, fin_best2, class_fin, bigfield_fin,
  classup_lastgood, layoff_lastfin, n_runs, days_log, kinryo, wchg`
- **E3 展開型（26本）**: `corner_frac, corner_gain, ep, ep_rel, press, front_n, pace_adv,
  waku, waku_rel, umaban_rel, waku_x_dirt, field, field_chg,
  f2_wide_mean3, f2_wide_max, f2_kick_mean3, f2_kick_max, f2_last,
  tb_n, tb_waku, tb_waku_surf, tb_front, tb_front_surf, tb_upset, tb_x_waku, tb_x_ep`
- **E4 人的型（2本）**: `j_top3, t_top3`
- **E5 適性型（21本）**: `csi, cond_perf, db_best, exact_dist_place, surf_switch, wet_apt,
  dist_chg, wet_fin, wet_x_baba, baba_today, today_vg, is_dirt,
  cp_n, cp_waku, cp_front, cp_fav, cp_x_waku, cp_x_ep, cs_runs, cs_top3, cs_fin`

割当の注記（事前に宣言する制約）:
1. **重複はゼロ**（各特徴はちょうど1つの専門家に属する）。5群に割り切れたため重複を使わなかった。
2. **`wavg` は全専門家から除外**。手作り総合得点＝全群の混合であり、入れると全専門家が相関する。
3. **血統（父）特徴は本データセットに存在しない**（`exp_sire.py` は本体未統合）。
   よってE5は「距離適性・馬場適性・コース実績」のみで構成する。**賞金・連対率の特徴も存在しない**ため
   E2は着順割合系で代用する。E4は騎手・調教師の3着内率2本しか存在しない（極端に薄い）。
4. `f2_*`（前走不利推定）は「展開不利で脚を余した量」なのでE3に置く。
   `tb_*`（当日トラックバイアス）はE3、`cp_*/cs_*`（コースプロファイル・同コース実績）はE5に置く。
5. レース内で全頭共通の文脈特徴（`field, baba_today, today_vg, is_dirt, press, front_n,
   tb_*, cp_*`）は、その群の馬単位特徴との交互作用としてのみ効く。

## 3. 合議の定義

- 各レース・各目的変数について、5専門家それぞれの**1位馬**を取る。
- `k` = 最頻の1位馬に投票した専門家の数（2〜5。全員バラバラなら k=1 で「合議なし」）。
  最頻が同数で並んだ場合は**そのレースを合議なし(k=1)扱い**とする（恣意的タイブレークを避ける）。
- 合議馬 = その最頻の1位馬。

## 4. 測る指標（3分割は既存と同一: MINE=〜202602 / VALIDATE=202603-202605 / CONFIRM=202606-202608）

1. `k`=2,3,4,5 別に、合議馬の **単勝flat ROI・複勝flat ROI・勝率・3着内率・R数** を3分割別に。
   （単勝は台帳の確定単勝オッズ、複勝は実払戻 `payout["複勝"]` を使用。1点100円。）
2. ベンチマーク: **汎用V3の1位**（`wf_preds_v3ext2.jsonl`・同一fold同一レース）と**市場1番人気**。
3. **α（市場条件付き増分情報）**: 1頭1行のロジスティック回帰を fold（月）ごとに当該foldのレースで推定。
   `logit P(1着_i) = c + β·logit q_market_i + Σ_{k∈{2,3,4,5}} α_k · 1[i が k人合議の馬]`
   （`q_market` = 単勝オッズの控除率補正済み勝率）。SEはレースクラスタロバスト。
   同形で3着内版（`q_market`=Harville近似の3着内確率、被説明変数=3着内）も測る。
   比較用に汎用V3 1位のダミーだけを入れた `α_v3` も同一手続きで測る。
4. 「意見が割れたレース（k≤2）は見送る」ルールの価値: k≤2 と k≥3 での
   V3 1位単勝ROI・勝率を対比する（見送りが実際に損失を避けるか）。
5. 5専門家の予測相関: 各レース内でスコアをz化し、専門家ペアごとの Spearman 順位相関を
   全レースで平均した 5×5 行列（目的変数別）。

## 5. 合否判定基準（事前登録・変更禁止）

- **一次**: `k≥4` の合議馬について **α>0 が VALIDATE の3フォールド（202603/202604/202605）連続**。
- **二次**: `k≥4` の単勝flat が **VALIDATE n≥30 かつ ROI≥110%** ∧ **CONFIRM n≥20 かつ ROI≥105%**。
- **三次（参考）**: k別の複勝ROI、および `hist_odds/` の実オッズを用いたワイド/三連複のEV。
- **多重比較**: k=2,3,4,5 × 単勝/複勝 × 1着/3着内モデル = **16通り**の試行を全て記録し、
  「ROI≥110%が偶然で出る本数の期待」と比較する。16通り中の1〜2本の通過は偶然と区別できないと判定する。
- **診断**: 専門家間の平均相関が >0.9 の対があれば「独立した見方になっていない」と報告書に明記する。
  ただし**基準は変えず、今回の結果はそのまま報告する**（特徴割当の見直しは次の事前登録で行う）。

## 6. 既知の限界（実行前に宣言）

1. E4は特徴2本しかなく「専門家」として極端に弱い。合議のk分布はE4の弱さに引きずられる。
2. 血統・賞金・連対率の特徴が存在しないため、ユーザー構想の5群を完全には再現できていない。
3. スピード指数の較正定数は全期間フィット（軽微リーク）。全モデル共通なので比較の公平性は保たれるが、
   絶対ROIはライブ比で楽観側。
4. VALIDATE 874R / CONFIRM 676R。k≥4のサブセットはさらに小さくなり、単勝ROIは1〜2発で±20pt動く。
5. 本実験は**オッズを特徴に使わない**。RULES.md の確定事項「オッズ抜きで市場を上回るのは不可能」が
   合議でも成り立つなら、αは負のままになるはずで、それも結論として報告する。
6. n<30 の窓は「参考」と明記し、判定には使わない。ゼロ件ならゼロと書く。
