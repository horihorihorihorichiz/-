## 5. 何が分かったか（数字で言えることだけ）

1. **「当日の前半レースから読むトラックバイアス」は、確定オッズにほぼ織り込まれている。**
   本検定の市場価格は当日前半の結果を見た後の価格であり、その上に乗る残差情報は
   OOS で −0.0014〜+0.0043 nats/R（市場自身の万分の2〜7）しか無かった。
2. **MINE の z=3.3〜4.7 は見かけほど強くない。** 同じ開催日の全レース（最大12R）・同じレースの全頭が
   1つの指数を共有するため、馬単位ロジスティックの z は**日内クラスタ相関で過大評価**される
   （実効標本はレース行 94,605 ではなく日×surface ≈ 1,200 クラスタに近い）。
   MINE 4/4 → VAL 0/4 の崩落はこれと整合する。**この構造は次回から事前登録の限界欄に必ず書く。**
3. 唯一プラス側に残った断片は「前半4R以上経過後の後半レースで OOS ΔLL が VAL/CONF とも正
   （+0.42 / +0.98 nats）」だが、これは記述統計であり、効果量は MKTCOND（一次合格でも三次全滅）
   より小さい。**この断片を根拠に部分集合の再検定はしない**（選択バイアスの入口になるため）。
4. ユーザーの「レースごとにあるやろ」の最有力具体化として測ったが、
   **「レースごとに変わる情報」も市場（当日中に動くオッズ）が先に消化している**というのが測定結果である。
   オッズ抜きで市場を上回れないという V4 の結論（RULES 冒頭）と同じ壁が、当日内スケールでも確認された。
