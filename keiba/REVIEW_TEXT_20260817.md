## 結論（先頭）

**調教レビュー原文は、市場オッズを条件にすると増分情報がほぼゼロ。実弾ルールには載せない。**

| 判定 | 内容 |
|---|---|
| 増分予測力 | **なし**（3着内: 2ΔlogL=0.065, p=0.80 / 1着: 2ΔlogL=0.836, p=0.36） |
| null検定 | 偽陽性と区別できない（p_perm = 0.26〜0.82、下記1件の例外も方向が逆） |
| 「ネガ語を消す」ルール | **効果なし〜逆効果**。ネガ語27頭の実績は市場期待を**上回った**（1着 実績2 vs 市場期待0.55） |
| 実務判定 | **採用しない。** 既存の予想フロー（calc.py / エッジ購入）に特徴量として足さない |

**これは2026-07以降の「調教SABC評価」の教訓と完全に同じ構図である。**
レビュースコアは無条件では弱く正の相関を持つが（score vs 人気順 r=-0.341、高スコアほど既に人気）、
市場を条件に入れた瞬間に消える。すなわちレビュー文は**能力・人気の代理指標**であって、
市場が知らない情報ではない。

### スコア化ルール（凍結）

1. `score = ヒットしたポジ語の種類数 − ヒットしたネガ語の種類数`
2. 同じ語が1頭のレビュー内で複数回出ても1回だけ数える（水増し防止）
3. **ネガ語の打ち消し**: 直後10文字以内に否定表現
   （ない / なし / なく / なさそう / なさげ / 解消 / 苦にしない / 感じさせない / 感じられない）
   があればネガに数えない。例:「太め感もない」「重苦しさはなし」「反動はなく」「調子落ちはなさそう」
4. 「いい意味で平行線」のみ例外的に打ち消す（用法が逆の1件のため事前に規定）
5. 逆接（〜だが / 〜ものの）の減衰は**実装しない**（恣意性を避けるため）。
   したがって「最後は遅れたが、余力もあった」は 遅れ=ネガ として数える
6. レース内で平均0・標準偏差1に正規化した `rev_z` を回帰の説明変数に使う

### 辞書の取り扱いについての申告

- 辞書の語彙は**着順・オッズを一切見る前に確定し、以後1語も変更していない**。
- 実装バグを1点だけ修正した: 否定マーカー「なさ」が名詞化（「物足り**なさ**が残る」「重苦し**さ**」）を
  誤って打ち消していたため、「なさそう／なさげ」に限定した。**これは語彙の変更ではなく、
  結果を一切参照する前の修正**である。語彙自体を成績に合わせて調整した事実はない。
- 既知の取りこぼし（辞書化していないが本文に存在する表現）: 「出来がいい」「出来は良好」
  「馬体減りもなく」「硬さが解消」など。凍結ルールにより今回は追加していない。
- 「強調材料に欠ける」は 強調材料 と 欠 の2語に当たり −2 になる（意図した重み付け。事前規定）。

## 4. null検定（レース内シャッフル 1000回・seed 20260817）

帰無仮説の作り方: **レース内でレビュー由来の全列（score, rev_z, has_neg, pos_z, neg_z 等）を
まとめて別の馬に付け替える。** レース構造・オッズ・着順・レビュー文の分布はすべて保存され、
「レビューと馬の対応だけがランダム」な世界を1000個作って同じ推定を回す。

| 検定 | 観測 b | 観測 2ΔlogL | p_perm(LR) | p_perm(&#124;b&#124;) |
|---|---:|---:|---:|---:|
| 全頭 3着内 + rev_z | +0.0577 | 0.065 | **0.8212** | 0.8052 |
| 全頭 3着内 + has_neg | +0.7528 | 1.313 | **0.2647** | 0.1948 |
| TSIあり 3着内 + rev_z | +0.3053 | 1.163 | **0.3137** | 0.2787 |
| 全頭 1着 + rev_z | +0.3448 | 0.836 | **0.3796** | 0.2977 |
| 全頭 1着 + has_neg | +2.8960 | 5.381 | **0.0470** | 0.0739 |
| TSIあり 1着 + rev_z | +0.5367 | 1.092 | **0.3437** | 0.2637 |

### 「1着 + has_neg」p_perm=0.047 をどう扱うか → **偽陽性として棄却**

1. **方向が逆。** 「ネガ語の付いた馬は消す」という実務仮説と反対に「ネガ語が付いた馬ほど勝つ」
   という推定になっている。事前の仮説を支持する証拠ではない。
2. **多重比較。** 4仕様 × 2目的変数 = 8本の検定を回している。帰無の下で p<0.05 が
   少なくとも1本出る確率は約34%。8本のうち1本の p=0.047 は何も意味しない。
   両側の p_perm(|b|)=0.074 では 0.05 を超える。
3. **2イベントに依存。** ネガ語27頭のうち勝ったのはエンヤラヴフェイス（11.9倍）と
   パシアンジェンヌ（16.5倍）の2頭だけ。1レースずつ除く leave-one-race-out:

   | 除外レース | b |
   |---|---:|
   | なし（全13R） | +2.896 |
   | −202604020707（エンヤラヴフェイス） | +2.020 |
   | −202607020802（パシアンジェンヌ） | +2.218 |
   | −202601010805 | +3.559 |
   | −202607020806 | +3.346 |

   2レース抜くだけで係数が3割落ちる。**単一の万馬券級の結果に支配された数字**であり、
   実力の推定値ではない。

**結論: null検定を通過したレビュー特徴は1つもない。**

13本検定して1本も0.05を切らないのは、帰無仮説（どの語も無関係）と完全に整合する。

ネガ語は単独で8頭以上出現するものが**1つもない**ため個別分析ができない（出現頻度）:

| ネガ語 | n | ネガ語 | n |
|---|---:|---|---:|
| 遅れ | 6 | 強調材料 | 2 |
| 地味 | 5 | 物足り | 2 |
| 平凡 | 4 | 良化待ち / 良化途上 | 各1 |
| 使いつつ | 4 | 太め / 不満 / 今イチ | 各1 |
| 欠（欠ける・欠く） | 4 | 切れず / 平行線 | 各1 |
| ひと息・一息 | 4 | ズブ / モタれ | 各1 |
| 劣勢 | 4 | | |

「ネガ語を消す」ルールの実体は、事実上「遅れ・地味・平凡・使いつつ・劣勢・ひと息」の6語しかない。

## 7. 限界

1. **サンプルが小さい。** 13レース158頭、1着イベント13件・3着内イベント39件。
   条件付きロジットの実効サンプルは「13レース」でしかない。
   仮に真の効果が中程度（オッズ比1.5/1SD）あっても、この規模では検出できない可能性が高い。
   → **「効果がない」ことを証明したのではなく、「効果があるという証拠が得られなかった」。**
2. **偏った期間。** 2日間（8/15・8/16）のみ。全13レースが馬場「良」。
   道悪でのレビューの価値は一切測れていない。RULES.md の「同一ルールで良148%/道悪51%」の
   教訓から見て、馬場条件を跨いだ検証が別途必要。
3. **レース種別が偏っている。** 2歳新馬3レース、重賞2レース（札幌記念・中京記念）を含み、
   条件が揃っていない。新馬戦はそもそも過去走がなく、調教レビューの相対的な重みが違うはずだが、
   層別に分けるだけのサンプルがない。
4. **TSIが8レース107頭にしかない。** モデルB/Cの比較はこの部分集合でしか成立しない。
   しかもTSI自体が今回のサンプルでは有意でない（3着内 p=0.864 / 1着 p=0.161）。
5. **辞書は単純な語彙カウント。** 逆接（「最後は遅れたが、余力もあった」）を減衰させていないため、
   ノイズが乗っている。ただしこれは検出力を下げる方向のバイアスであり、
   「効果あり」を偽造する方向ではない。
6. **ROIは推定できていない。** 全頭買いの単勝ROIが45.4%（理論値は約80%）という時点で、
   このサンプルサイズでは回収率の議論は成立しない。表中のROIは記述統計にすぎない。

## 8. 実務判定

### 採用しない

- `calc.py` / エッジ購入エンジンに、レビュースコアを特徴量として**追加しない**。
- 「ネガ語が付いた馬を消す」ルールを**採用しない**。上位人気にはそもそも発動せず（39頭中0頭）、
  発動した27頭は市場期待を上回った。
- レビュー原文の取得を、予想フローの必須ステップに**しない**（プレミアム取得コストに見合わない）。

### 唯一の残る用途（限定的・検証済みではない）

- score ≤ 0 の層（37頭、3着内 4頭 = 10.8%、1着 0頭）は実績が薄い。ただしモデルA期待 5.73 に対して
  実績4で差はわずか −1.73 であり、**これは市場が既に織り込んでいる**（この層は平均人気10.1・
  オッズ中央値75.3倍）。独自の情報ではない。
- したがって、**買い目を最終確認するときの人間側の目視材料**としてのみ位置付ける。
  スコアを数式に入れることはしない。

### 再検証の条件

以下が揃った時点で再実行する（`review_eval.py` はそのまま使える）:

- **最低500頭・50レース以上**（1着イベント50件以上）。今回の4倍規模。
- **道悪を含む**こと。良馬場だけでは RULES.md の教訓に照らして判断できない。
- 再実行時も**辞書は今回の凍結版のまま**使う（`review_score.py` VERSION 1.0-frozen-20260817）。
  語彙を成績に合わせて足したら全段やり直し。
