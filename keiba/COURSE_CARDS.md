# 全コース運用カード — 配点と買い目

**使い方**: レース前にこのコースの行を見る → ①その群の配点で並べる（v99w_rank.py が自動）
→ ②選別3条件を判定（exclusion.py が自動）→ ③下の買い目ルールに従う。

**重要**: 配点はコース単位ではなく**芝ダ×距離帯の6群**で決まる。
コース単位で配点を分けるのは7回測って7回とも未来で悪化した（同じ場より同じ距離帯の方が似ている: 4.72 vs 4.48）。
**このカードは「全コースにその群の配点を割り当てた表」であり、それがデータの出した答え。**

# Ⅱ. 買い目ルール（全コース共通・凍結）

```
STEP1  選別3条件を判定（判定時オッズで計算・発走3分前に凍結）
         A: fav_p >= 0.341     市場1番人気の実質確率
         B: ent   <= 1.904     市場の割れ具合
         C: sgap  >= 0.066     モデル1位2位の得点差
STEP2  A∧B∧C が揃わない → ★見送り★（全体の約79%はここで降りる。これが正常）
STEP3  揃った → 複勝・市場上位2頭を各100円（2点）
         実測 的中率 MINE 94.4 / VAL 95.9 / CONF 92.4%（3期とも90%超）
         ROI  MINE 92.6 / VAL 95.6 / CONF 85.3%（★100%未満＝現状は実弾に載せない★）
STEP4  ダート1400m以下 かつ A∧B なら W12 を併記録（掛け金ゼロ）
         B-sd16上位2頭のワイド1点 ＋ 同2頭軸-3〜6位の三連複4点
         n>=80 到達までROIがいくつでも判断しない（w12_watch.py が強制）
```
**買ってはいけないもの**（実測に基づく）:
- 馬連・馬単・三連単＝**勝ち順系は買わない**（三連単はMINE119-146%が未知データで全滅）
- モデル順位そのもので買う（696案全滅。買い目が市場とほぼ同じになるため）
- 期待値が高く見える点だけ買う（EVの高い裾ほどROIが下がる＝信号が逆向き）
- 開催初日（誰も馬場を読めない）
