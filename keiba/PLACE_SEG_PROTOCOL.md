# セグメント別 3着内モデル 事前登録書（PLACE_SEG_PROTOCOL）

作成 2026-08-18 / **実行前に確定・以後変更禁止**（RULES §後知恵禁止）

## 背景と仮説

- SPECIALIST実験（SPECIALIST_REPORT_20260817.md）は**1着を目的変数**にしたセグメント別学習で
  11セグメント中10が汎用に劣り不成立だった。
- PLACE実験（PLACE_SYSTEM_20260817.md）は**3着内を目的変数**にすると市場への付加情報 α_place が
  史上初めて正（+0.0424・27fold中26で正・最長連続24）になることを示した。
- **仮説**: セグメント別学習が失敗したのは「1着当て」という土俵が悪かったからであり、
  **3着内 × セグメント別**なら汎用を上回るセグメントが存在する。この組合せは未検証。

## ウォークフォワードと分割（PLACE_SYSTEM と完全同一・変更禁止）

- fold = 月次。fold月 m の学習は **m より前の全レース**（かつ当該セグメントのみ）。
- start-fold = **202403**（既存 place_preds_*.jsonl と同一。ベースライン流用のため）。
- **MINE = 〜202602 / VALIDATE = 202603-202605 / CONFIRM = 202606-202608**。
- 学習データ薄いセグメント: fold時点の当該セグメント学習データが **800頭未満**なら
  「専用なし=汎用（v8place）予測を流用」と記録し、その件数を報告する
  （SPECIALIST と同一の閾値）。安全ガード: 800頭以上でも train/val 分割が成立しない場合も同様に流用扱い。

## α_place の測り方（PLACE_SYSTEM の主指標と同一形）

```
p_win    = (1/単勝オッズ) をレース内で和1に正規化
q_market = Harville近似で p_win から作った P(3着内)（和=3）
q_model  = モデル生出力をロジット平行移動でレース内和3に正規化
P(3着内_i) = σ( α·logit q_model_i + β·logit q_market_i + c )      ← α_place
```

- 係数は月次WF: **fold月 m の α は「当該セグメントの m より前の月」だけで最尤推定**。SEはレース単位クラスタ頑健。
- **α推定の最低データ量: 当該セグメントの学習側レース数 ≥ 200R**（`place_eval.py` の既存閾値と同一）。
  満たさない fold は「α推定不能」と記録し、**判定上は不通過**として扱う。
- **Δα = α_spec − α_gen**。両者は**同一のレース集合・同一の市場側・同一の推定手順**で、
  `q_model` の列だけ（専用予測 / 汎用予測）が異なる。

## 判定基準（事前登録・実行後の変更禁止）

- **一次**: あるセグメントの **Δα > 0 が VALIDATE の3フォールド（202603/202604/202605）連続**。
  3フォールドのいずれかで α 推定不能なら不通過。
- **二次**: そのセグメントの**複勝flat**（専用モデルの3着内確率1位に100円）が
  **VALIDATE ROI ≥ 95% かつ CONFIRM ROI ≥ 95%**。
  （複勝は控除率20%＝理論上限80%付近。95%超なら市場超えの候補。）
- **三次（参考のみ・合否に使わない）**: ワイド・三連複の EV（Harville近似）。
  組合せの事前オッズが台帳に無いため推定オッズを使う。PLACE_SYSTEM §2 で
  「勝者の呪いで壊れる」ことが実証済みなので**参考表記に限定**する。
- **多重比較**: セグメント数 **36**。「Δα>0 が3フォールド連続」は偶然でも 0.5³ = 1/8 で起きるため、
  偶然期待の通過数は **36 × 0.125 = 4.5 セグメント**。
  **一次通過数がこの 4.5 を大きく超えない限り「発見」とは呼ばない**（超えた場合も二次で確認）。
  さらに PLACE_SYSTEM §1-4 で「α>0 の連続は実力ゼロのヌルでも通る」ことが実証済みなので、
  **一次だけの通過は『不成立』と報告する**。二次まで通ったセグメントのみ候補と呼ぶ。
- **n<30 のセルは全て「参考」表記**（ROI・的中率とも）。

## 既知の限界（事前に明記）

1. セグメントに切ると VALIDATE/CONFIRM の n が激減する（S-C は VALIDATE 平均 44R 見込み）。
   ROI の標準誤差は数十pt になり、**二次基準の 95% は n が小さいセグメントではほぼ運**。
2. 市場側は単勝オッズの Harville 近似であり、事前複勝オッズではない（PLACE_SYSTEM と同じ限界）。
3. Δα は α-fit の in-sample 量（=セグメントの過去月）で測る。セグメントが薄いほど推定が不安定。
   補助指標として **fold月に対する out-of-sample 対数損失（1頭あたり）**も併記する（参考）。
4. 多重比較を 36 で数えるが、S-A/S-B/S-C は互いに入れ子（相関あり）なので独立試行 36 ではない。
   よって偶然期待 4.5 は**上限寄りの見積り**であり、通過数がこれを下回るなら明確に不成立。
