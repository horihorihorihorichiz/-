## 0. 結論

1. **学習と本番の事前情報のズレを3つ発見し、全部直した。これが最大の利得だった**:
   同じV3アーキテクチャのまま **1位勝率 24.8% → 26.1%（+1.3pt）**、市場implied比 −3.0 → −1.9pt。
2. **V5（統一データ＋強さ特徴6本＋二値目的関数）が現時点の最強**:
   1位勝率 26.7% / 市場比 −1.3pt / 単勝ROI 80.3%。ただし種分散が±0.45ptあり、上振れ込みで読む。
3. **統一の代償**: 得点分布が変わり、旧V3の癖を突いていたパターンの約半分が死んだ。
   全パターンを統一データ版で再採掘し、台帳を刷新した（§4）。
4. 既定エンジンは**V3（統一データ）のまま**。V5は `KEIBA_ENGINE=v5`。

## 3. なぜ既定をV5にしないか

パターン台帳（買い判定＝金の流れ）はV3得点の分布で採掘されている。V5に替えると
g12系パターンは1/5しか再確立できない（V5は市場との差が小さく、「モデルの癖と市場のズレ」
という原資そのものが減るため）。**エンジンと台帳はセットで替える**のが統一原則なので、
台帳が再採掘で成熟するまでV5は `KEIBA_ENGINE=v5` の選択制。
