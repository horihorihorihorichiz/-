# 予想に必要な情報 まとめ（何を渡せば予想できるか）

このシステム(calc.py Ver.99.27 + predict.py)が予想を出すのに要る情報の一覧。
**2つの渡し方**があり、どちらでもOK。

---

## 渡し方A：race_id だけ（地方=NAR は基本これで完結）
```
python fetch_race.py <race_id> --run
```
netkeiba公開ページから **出馬表＋各馬の馬柱9走＋馬場＋馬体重＋オッズ** を全部自動取得して予想まで出す。
- **貼るものゼロ**。race_id（12桁）さえあればいい。
- ただし**タイム指数だけは会員限定**なので自動では入らない（軸はほぼ不変・相手/穴の精度がやや落ちる）。
  → 精度を上げたいレースだけ、下の「タイム指数」を新聞から貼って `--tsi` で足す。
- **JRAは現状 自動非対応**（→ 渡し方Bで新聞を貼る）。

## 渡し方B：新聞を貼る（JRA / race_id不明 / タイム指数を入れたい時）
netkeibaの「**タイム指数(近5走)タブ**」＋「**馬柱(競走成績)**」をそのまま貼ればOK。
（今夜の川崎/園田はこれで本気精度が出た。）下の「必須項目」が入っていれば形式は問わない。

---

## 必須項目（これが無いと予想できない）

### ① レース条件（1行でいい）
| 項目 | 例 | 用途 |
|---|---|---|
| 場・R・レース名(格/クラス) | 園田11R 兵庫サマークイーン賞(重賞) | tier(格)判定 |
| 芝/ダ・距離 | ダ1700 | コース補正 |
| 頭数 | 12頭 | 展開・枠 |
| **馬場** | 良/稍/重/不 | ★道悪補正(TAS)。**必ず** |

### ② 各馬の基本（馬番順に全頭）
| 項目 | 例 | 用途 |
|---|---|---|
| 馬番・馬名 | ② タマモアルタイル | — |
| 脚質 | 逃/先/差/追 | 展開・DSI |
| 斤量 | 56.0 | — |
| **馬体重(増減)** | 492kg(-5) | ★HCS(馬体) |
| 単勝オッズ・人気 | 12.4倍(6人気) | ★EV裁定・買い目（※ランキングだけなら無くても可） |

### ③ 各馬の過去走（近5〜9走・新しい順）
各走について：
- **距離・着順・頭数・馬番**
- **4角通過順**（「3-4-4-1」の最後の数字）
- **上がり3F**（「後 40.4」）
- **馬場**（その走の 良/稍/重/不）
- **クラス(格)**（C1・重賞 等）
- **日付**（間隔=NRJA用。新聞の日付でOK）

### ④ タイム指数（近5走）★精度の肝＝LTS
各馬の「前走・2走前…5走前」の指数。netkeibaのタイム指数タブそのまま。
- これがあると「大井の高指数を園田替わりで割り引く」等の芸当が効く。
- 無くても軸は出る（相手/穴の判別が甘くなるだけ）。

---

## あると精度UP（任意）
- **ペース**（H/M/S）・馬場指数
- 新聞の**展開予想**（脚質分類：逃げ/先行/差し/追込）
- 休養明け/使い詰め・ブラインド情報（NRJA/ブースト指定）

## 出力に要るか要らないか早見
| 出したい物 | 最低限要る情報 |
|---|---|
| **全頭ランキング（得点・PWin・ランク）** | ①②③（＋④tsiで精度UP）。**オッズ不要** |
| **EV裁定・買い目・i-PAT** | 上記＋**単勝/馬連/ワイド/三連複オッズ**（地方は自動、JRAは自動取得） |
| **事前スクリーン（軸が立つ形か）** | ①②③のみ（オッズ前でOK） |

---

## いちばんラクな運用（結論）
- **地方**：race_id を送るだけ（`fetch_race.py <race_id> --run`）。タイム指数を足したい時だけ新聞のその列を貼る。
- **JRA**：netkeibaの**タイム指数タブ＋馬柱をコピペ**＋**馬場**を一言。→ 今夜と同じ精度で出す。
- どちらも **購入・GOは人間**。買い目提示まで。
