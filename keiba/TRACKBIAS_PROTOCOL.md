## 0. 背景と仮説

同じ開催日（＝同じ馬場）の前半レースの結果から「今日の馬場の内外バイアス・前後バイアス」を
指数化すれば、後半レースで市場が織り込み切れていない情報になる可能性がある。
「レースごとに変わる情報」の最有力具体化として、本プロジェクトで**初測定**する。

- 過去の教訓: 人が丸めた集計は全滅、生データ（通過順）だけが CONFIRM を通過した（CORNER_REPORT.md）。
  よって前後バイアスの指数は **paper_style 版（丸め）と、当日レースの実通過順版（生）を両方**用意して比較する。
- 市場（確定オッズ）は当日の前半レースを見た後の価格である。つまり本検定は
  「市場がバイアスを織り込んだ後になお残る情報があるか」という**意図的に厳しい**設定である。

### 事前の構造チェック（測定前に実施・結果と無関係な配管確認のみ）
- `hist/` 8,805R = 759開催日グループ、1グループ中央値12R（12R完備が543グループ）。全場JRA（場コード01-10）。
- surface は 芝/ダ の2値のみ（障害なし）。paper_style は 逃/先/差/追 の4値。
- `horse_cache/` の同日レコード被覆: 無作為25R・344頭中 343頭に `_pdate`=当日 のレコードがあり、
  343頭すべて `corner4` あり（→当日前半レースの実4角位置が取れる）。
- `horses[].horse_id` は全レースで保存済み（CORNER 再収穫の成果物）。

## 2. 当日バイアス指数（as-of・実装前に確定）

対象レース R（レース番号 n_R、surface s）に対し、**同一開催日グループ・同一 surface・
レース番号 < n_R** で hist に存在し、かつ `result.top3` の3頭が特定できるレース集合を E とする。
（前半レースの結果は発走の数十分前に確定しているので as-of 適合。hist に無い当日レースは単に数えない。）

各 e ∈ E について3つの寄与を計算する。`ndraw(j) = (num_j − 1)/(field_e − 1)`（0=最内、1=大外）。

| 記号 | 定義 | 意味 |
|---|---|---|
| dB(e) | mean_top3(ndraw) − mean_出走全頭(ndraw) | 正=外枠有利だったレース |
| sB(e) | mean_top3(st) − mean_出走全頭(st)。st: 逃=1, 先=2/3, 差=1/3, 追=0 | 正=前有利（脚質・丸めデータ版） |
| cB(e) | mean_top3(fr) − mean_corner4既知全頭(fr)。fr = 1 − (corner4−1)/(field_e−1) | 正=前有利（当日実通過順・生データ版） |

- cB の corner4 は `horse_cache/{horse_id}.json` の `_pdate` = 当日 のレコードから取る
  （馬は1日1走なので一意）。top3 の3頭全部に corner4 が無ければその e は cB から除外。
- sB は top3 のうち paper_style を持つ馬が2頭未満ならその e を sB から除外。

**指数（縮約 k=2 は先に固定・チューニングしない）:**

```
I_x(R) = Σ_{e∈E_x} x(e) / (|E_x| + 2)      x ∈ {dB, sB, cB}
```

**当日前半が0〜2Rしか無い標本の扱い（事前登録）**: |E_x|=0 なら I_x=0（特徴が全て0になり
尤度に寄与しない＝自動的に中立）。|E_x| が小さい日は k=2 の縮約で 0 に寄る。
標本は**除外しない**（除外すると後半レースだけの偏った母集団になる）。
報告書に |E_dB| の分布と、|E_dB|≥4 / <4 に分けた OOS ΔLL の内訳を**記述統計として**載せる
（判定には使わない）。

## 3. 馬側属性と候補特徴（4本・以後追加禁止）

馬 i（対象レース R 内）の属性。centered はレース内平均を引くこと（欠損馬は 0 ＝平均扱い）。

| 属性 | 定義 |
|---|---|
| draw_c(i) | ndraw(i) のレース内 centered |
| style_c(i) | st(i)（逃=1,先=2/3,差=1/3,追=0）のレース内 centered |
| own4_c(i) | 直近5走（`horses[].races`、as-of既収録）の fr = 1−(corner4−1)/(F−1) の平均をレース内 centered。1走も無ければ 0 |

**候補特徴 = 指数×属性の交互作用4本（生の積。レース内zは掛けない※）:**

| # | 特徴 | 定義 | 仮説の向き |
|---|---|---|---|
| 1 | `tb_draw` | I_dB × draw_c | 正（外有利の日に外枠が走る） |
| 2 | `tb_style` | I_sB × style_c | 正（前有利の日に前の馬が走る）— 丸めデータ版 |
| 3 | `tb_c4style` | I_cB × style_c | 正 — 指数=生データ、属性=丸め |
| 4 | `tb_c4own` | I_cB × own4_c | 正 — 指数も属性も生データ |

※レース内zを掛けると z(I×attr) = sign(I)×z(attr) となり**指数の大きさが消える**ため、生の積のまま使う
（レース内の定数シフトは条件付きロジットで消えるので centering だけで十分）。この判断も先に固定する。

バイアスの主効果（I_x 単体）はレース内定数なので条件付きロジットでは恒等的に消える。
よって検定対象は交互作用のみで正しい。

## 4. 検定手順

### 4-1. 単独スクリーニング（CORNER_PROTOCOL §3 と同一の推定器）
- 馬単位ロジスティック回帰（Newton-Raphson）。目的は `y_top3` **のみ**（勝ち目的はやらない。
  一次基準が top3 条件付きロジットであるため）。
- ベースライン共変量 `[1, log pm, log(3/field)]` ＋ 候補特徴1本（生値）。
- 記録: 各分割の coef / z / ΔLL。
- 判定: MINE通過 `|z|≥2.5` → VALIDATE で再推定・同符号かつ `|z|≥2.0` → CONFIRM も同じ。

**多重比較**: 試行数 = 4特徴 × 1目的 = **4**。
MINE の偶然期待 = 4 × 0.012419 = **0.0497**。
VAL の偶然期待 = (MINE通過数) × 0.02275。バッチ判定 = VAL通過数 ≥ 3×偶然期待 かつ >0。

### 4-2. 一次判定（本プロトコルの主判定・親指定の物差し）
MKTCOND_PROTOCOL と同一のモデル:

```
u_i = log(pm_i) + x_i·θ        市場log-oddsはオフセット・係数1固定
q_i = softmax(u) over race     条件付きロジット
目的 = 3着内の並び（Plackett-Luce 3段展開。特定できない段は尤度から外す）
```

- 特徴 = **4本全部**（選択ステップを置かない。選択バイアスの混入を避ける）。
- λ は MINE 内部5分割CV（レース単位・rid ハッシュ mod 5）で
  グリッド {0, 1e-4, 3e-4, 1e-3, 3e-3, 0.01, 0.03, 0.1, 0.3, 1.0} から決定。
- **θ_MINE を凍結し、VALIDATE と CONFIRM の 真のOOS ΔLL = LL(θ_MINE) − LL(0) を各1回だけ測る。**
- **一次合格 = VALIDATE と CONFIRM の両方で ΔLL > 0。**

### 4-3. ROI translation（最小限・2ルール固定・探索なし＝試行数2）
- バイアス強度 S(R) = max(|I_dB|, |I_cB|)。閾値 T = **MINE の対象レース（|E_dB|≥3）における S の80パーセンタイル**
  （MINEのみで決定・以後固定）。
- 対象レース: |E_dB| ≥ 3 かつ S ≥ T（＝バイアスがはっきり出ている日の後半レース）。
- **ルールR1（複勝1点）**: a_i = x_i·θ_MINE が最大の馬に複勝100円。
- **ルールR2（ワイド1点）**: オフセットモデルの q 上位2頭のワイド1点100円。
- VALIDATE / CONFIRM で各1回だけ集計。**ROIを主張する条件 = VAL/CONF両方100%超 かつ 各n≥80**
  （RULES.md の基準）。満たさなければ「未達」と数字で書く。

### 試行数の総括（申告）
単独検定 4 ＋ 一次判定 1 ＋ ROIルール 2 = **7試行**。これ以外の検定・買い方探索はしない。

## 6. 事前に分かっている限界（先に書く）

1. **確定オッズは当日前半の結果を見た後の価格**である。バイアスが市場に完全に織り込まれていれば
   ΔLL は 0 に潰れる。これは仕様（「織り込み後になお残るか」を測る）。
2. hist に無い当日レース（中央値12Rなのでわずか）は指数から漏れる。as-of は壊れないが指数の分散が増える。
3. 枠バイアスはコース・距離で向きが変わる（例: 内回り芝1200と外回りは別物）。本検定は
   surface 別のみで距離・コース別には分けない（コース別分割7回全滅の教訓により細分化しない）。
   向きが混ざる分は**帰無方向へのバイアス**（検出力低下）であり、偽陽性方向ではない。
4. 縮約 k=2・脚質スコア(1, 2/3, 1/3, 0)・直近5走窓は**恣意的な固定値**（チューニングはしていない）。
5. 1日の前半レース数は surface 別で最大6R程度。指数自体の標本誤差が大きく、
   検出できるのは相当強いバイアスだけの可能性がある。
6. ROI 検定の対象レース数は VAL/CONF が短いため n≥80 に届かない可能性が高い。
   その場合は ROI について**主張しない**（参考数字として報告のみ）。
