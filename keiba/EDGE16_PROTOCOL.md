# EDGE16_PROTOCOL — B-sd16確率コア×EVベース購入の事前登録（測定前に凍結）

作成: 2026-08-20（測定実行前に本文を確定。以後の変更は追記欄に理由付きで記録する）

## 0. 最重要の正直さ（先読みバイアス）

- 本測定のオッズ（hist_odds/ の複勝下限・ワイド下限・三連複、および払戻）は**すべて確定（最終）オッズ**。
  実運用では判定時オッズしか見えない。実測（PLACE_REAL_ODDS_REPORT.md §8、n=20〜34の小標本）では
  判定時（発走15-30分前）→確定 の変化率は **複勝0.69倍 / ワイド0.96倍 / 三連複1.91倍**。
  - 複勝: 確定は判定時より**低い**（モデルが好む馬は締切までに売れてオッズが縮む）
  - 三連複: 確定は判定時の約**2倍に伸びる**（判定時に見えるオッズは確定の約半分）
- したがって確定オッズでEVを計算して選定する素のEVには**選定の先読みバイアス**が乗る。
  感度分析として下記 §5 の保守補正版を主判定に使う。
- さらに「確定オッズは締切までの全情報を含む」という一般的な楽観（判定時に見えない情報で選んでいる）は
  保守補正でも完全には消えない。この限界は報告書冒頭に再掲する。

## 2. 確率コア（Plackett-Luce）

- モデル強さ: u_i = score_i / τ。P(1着=i) = softmax(u)_i。
  逐次除去（Harville/PL）で P(上位3頭の順列) → そこから
  P(3着内=i)、P(ペア{i,j}が両方3着内)、P(3着内集合={i,j,k}) を厳密に計算（n≤18なのでテンソルで全列挙）。
- 温度 τ: MINEの**上位3着の部分PL対数尤度** Σ[log P(1着) + log P(2着|1着除去) + log P(3着|1,2着除去)]
  を最大化して**1回だけ**決定（グリッド+黄金分割）。【決定1】
- 市場確率: q_i ∝ 1/単勝オッズ_i（レース内正規化＝控除率除去）。市場の3着内系も同じPL逐次除去で計算。
  （複勝オッズから市場複勝確率を作る代替案は採らない。市場コアは単勝オッズ由来の1本に固定。）
- 頭数7以下のレース（192R）は複勝が2着内払い → 複勝のみ P(2着内) を使用（同じPLで厳密計算）。
  頭数7以下でも複勝3頭払いの例外が18Rあるが（0.2%）、ルールは頭数基準で固定し例外は誤差として受容。

## 3. 市場ブレンド

- チケット確率レベルでブレンド: p_final = (1-β)·p_market + β·p_model。
- βは種類別にMINEの対数尤度最大化で**各1回**決定（グリッド β ∈ {0, 0.05, …, 1.00}）:
  - β_win: 勝ち馬のカテゴリカル尤度（購入対象外だが仕様通り報告）【決定2】
  - β_place: 馬ごとの3着内ベルヌーイ尤度【決定3】
  - β_pair: ペアごとの「両方3着内」ベルヌーイ尤度【決定4】
  - β_trio: 3着内集合のカテゴリカル尤度（C(n,3)通り）【決定5】
- 較正の質: MINEで p_final（および p_model 単独）の reliability（予測確率10分位ごとの平均予測 vs 実測頻度）
  を勝ち・3着内について数表で報告。

## 4. EV計算と候補チケット

- 候補: 複勝（各出走馬）、ワイド（全ペア）、三連複（全トリオ）。勝ち順系（単勝含む）は買わない。
- EV_素 = p_final × 払戻オッズ（複勝=hist複勝下限、ワイド=histワイド下限、三連複=hist三連複）。
- 的中判定・払戻は bsd16_races.jsonl の payout 辞書（実際の確定払戻）。キー存在=的中。

## 5. 購入規則とθ（事前登録）

- 購入: 1点100円均等。上限・資金配分の工夫なし。「大半のレースが見送り」は正常。
- **θの決定（券種ごとに1回、MINEのみ）**【決定6-8】:
  グリッド θ ∈ {0.90, 0.95, 1.00, …, 3.00}（0.05刻み）。
  券種ごとに「MINE購入点数 ≥ 500」を満たすθの中で **素のEV版のMINE ROI最大**のθを採用（同率なら小さいθ）。
  最大ROIが100%未満の券種は**購入対象から外す**（曲線は報告する）。
- **素のEV版**: EV_素 ≥ θ* を購入。
- **保守補正版（主判定）**: 判定時オッズ = 確定オッズ/変化率 なので、判定時EV = EV_素/m
  （m = 複勝0.69 / ワイド0.96 / 三連複1.91）。実運用で「判定時EV ≥ θ*」で買う行動は
  **確定EVで書くと EV_素 ≥ m·θ*** に等価。この選定で買い、**実払戻**で精算する。
  - 複勝(m=0.69): 判定時にはオッズが膨らんで見える → θ*を実質0.69倍に緩めた分の球まで買ってしまう
    （選定が緩む＝保守側）。
  - 三連複(m=1.91): 判定時に見えるオッズは確定の約半分 → 確定EVが1.91θ*以上の球しか判定時に拾えない
    （購入が激減する＝保守側）。
  - 係数は n=20〜34 の小標本による近似であることを報告に明記。
  - 参考として「文字通りEV×mをθ*と比較する版」（タスク文の字義通り、方向は上と逆）も数表で併記するが、
    主判定は上記の実運用方向とする。理由: PLACE_REAL_ODDS_REPORT §8 に変化の向きが実測記録されており、
    字義通り版は複勝で選定が締まり（=甘い側）、実運用の再現にならないため。
- θ*は両版で共通（θは「判定時EVに対して設定する運用パラメータ」であり、ドリフトは選定バーの実効値を変える）。

## 6. 判定（VAL/CONFは最後に1回だけ）

- 指標: 券種別・全体の ROI（素版・保守版）、購入点数、購入レース率、的中率。
- **合格ライン: 保守補正版で VAL・CONF の両方 ROI ≥ 100%、かつ保守版購入点数（VAL+CONF合計）≥ 200点。**
- 素のEV版のみ100%超の場合は「先読みバイアス込みでのみ成立」と明記する。
- 未達は未達と数字で書く。

## 7. 対照（健全性チェック）

- 同一パイプラインで β=0（市場のみ）: EVは理論上ほぼ一定（≈1−控除率）で θ*超えはほぼ出ないはず。
  もし対照が有意な点数で ROI>100% になれば測定系のバグとして停止し原因を書く。
  （注: 市場3着内系はHarville近似なので厳密には一定でない。逸脱が出た場合はHarville起因かバグかを切り分ける。）
