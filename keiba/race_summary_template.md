# 競馬レースまとめテンプレート Ver.97.4

## 出力ルール（厳守）
- 過去走情報をメインに出力（10走分）
- 調教評価のみ抽出（無ければ「B」）
- LTS関連データはnetkeibaタイム指数ランキングタブ（8列形式）から読み取る
- 各馬データはコードブロックで出力（最大10走分）
- データが切れている場合は [記録なし] と記載

## LTS_Final算出（自動計算）

### LTS_D が数値の場合:
```
LTS_D_eff = min(LTS_D, LTS_max)  ← キャップ: LTS_DがLTS_maxを超える場合は抑制
LTS_Final = LTS_D_eff × 0.7 + LTS_max × 0.3
```

### LTS_D = "未" の場合:
```
LTS_Final = LTS_max × 0.85（距離未知ペナルティ -15%）
★ 距離未知フラグ = ON → セクション2に記載
```

### LTS_max = "-" の場合（補完LTS）【Ver.97.4新設】
```
指数なし馬 = 「能力がない」ではなく「データ不足」

■ 補完LTS算出:
  補完LTS = クラス基準値 × 0.85 + 騎手補正(±3) + 調教評価補正(±2)
  信頼度係数: 0.6（通常馬の60%の重み付け）
  表示: [補XX] のように括弧付きで区別（例: [補58]）

■ クラス基準値:
  新馬・未勝利: 50
  1勝クラス:    65
  2勝クラス:    75
  3勝クラス:    83
  OP・リステッド: 88
  重賞:          93

■ 騎手補正:
  リーディング上位10位以内: +3
  リーディング11-30位:      +1
  それ以外:                  0
  見習い騎手:               -2

■ 調教評価補正:
  A評価: +2
  B評価:  0
  C評価: -1
  D評価: -2

■ LTS_Final算出:
  LTS_Final = 補完LTS × 0.6（信頼度係数）
  ★ 指数なしフラグ = ON → ランキング表で [補XX] と表示
  ★ UPS計算: 補完LTS馬は母数から除外（GF馬と同様）

■ 旧ルール（参考）:
  LTS_Final ≈ R1 × 0.7 → 廃止（R1自体が存在しない場合に対応不可のため）
```

## TRD算出【Ver.97.0: △1/△2方式に刷新・下降側減感化】

```
△1 = R1（前走） - R2（2走前）
△2 = R2（2走前） - R3（3走前）
```

| 条件                     | TRD | 解釈 |
|--------------------------|-----|------|
| △1 > 5  かつ △2 > 0     | +5  | 2走連続上昇（急上昇・絶好調） |
| △1 > 5  かつ △2 ≤ 0     | +3  | 直近急上昇（前走のみ） |
| 0 ≤ △1 ≤ 5              | +1  | 安定維持・微上昇 |
| -5 ≤ △1 < 0             |  0  | 横ばい・微減（許容範囲） |
| △1 < -5 かつ △2 > 0     | -1  | 直近急落（一時的の可能性）【97.0: -2→-1 緩和】|
| △1 < -5 かつ △2 < 0     | -3  | 2走連続下降（要注意）【97.0: -5→-3 緩和】 |
| 近走データ2走以下        |  0  | 判定不能（ニュートラル） |

R2またはR3が"-"の場合 → TRD = 0（判定不能）

## フラグ自動判定（Ver.97.0）

### GrowthFlag（GF）判定
- 条件A: R1 ≥ LTS_max（前走で過去最高更新）
- 条件B: TRD ≥ +3（急上昇 ※新TRDでは+3または+5が該当）
- 条件C: 3〜5歳 AND LTS_Final_Rank ≥ 出走頭数 × 0.55（中下位）
- 2条件以上該当 → GF=ON → 🌱マーク + UPS計算除外 + 相手強制追加

### LDF（直近信頼度低下フラグ）判定
- 条件1: TRD ≤ -2（Ver.97.0新TRDでは TRD=-3 のみ該当）
- 条件2: R1 ≤ LTS_max × 0.85（前走が過去最高の85%以下）
- 両方該当 → LDF=ON → ⚠️直近信頼度低下 + 副軸提示

### SCF（単発崩れ型候補フラグ）判定
- 条件1: R1 ≤ LTS_max × 0.80（前走が過去最高の80%以下・大幅下落）
- 条件2: R2 ≥ LTS_max × 0.90（2走前は過去最高の90%以上・安定）
- 除外: GF=ON馬 または R2="-"
- 両方該当 → SCF=ON → ⚡相手7頭目として検討推奨
