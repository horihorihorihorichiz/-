# 競馬レースまとめテンプレート Ver.98.3

## 出力ルール（厳守）
- 過去走情報をメインに出力（10走分）
- 調教評価のみ抽出（無ければ「B」）
- LTS関連データはnetkeibaタイム指数ランキングタブ（8列形式）から読み取る
- 各馬データはコードブロックで出力（最大10走分）
- データが切れている場合は [記録なし] と記載

## LTS_Final算出（自動計算）

### LTS_D が数値の場合:【Ver.98.1: 重み改定+適性比連動floor】
```
LTS_D_eff = min(LTS_D, LTS_max)  ← キャップ: LTS_DがLTS_maxを超える場合は抑制
LTS_Final_raw = LTS_D_eff × 0.6 + LTS_max × 0.4
適性比 = LTS_D / LTS_max
floor_rate = 0.82（適性比 ≥ 0.65）/ 0.75（適性比 < 0.65）
LTS_floor = LTS_max × floor_rate
LTS_Final = max(LTS_Final_raw, LTS_floor)
```

### LTS_D = "未" の場合:
```
LTS_Final = LTS_max × 0.85（距離未知ペナルティ -15%）
★ 距離未知フラグ = ON → セクション2に記載
```

### LTS_max = "-" の場合（補完LTS）【Ver.97.4新設】
```
指数なし馬 = 「能力がない」ではなく「データ不足」

■ 補完LTS算出:
  補完LTS = クラス基準値 × 0.85 + 騎手補正(±3) + 調教評価補正(±2)
  信頼度係数: 0.6（通常馬の60%の重み付け）
  表示: [補XX] のように括弧付きで区別（例: [補58]）

■ クラス基準値:
  新馬・未勝利: 50
  1勝クラス:    65
  2勝クラス:    75
  3勝クラス:    83
  OP・リステッド: 88
  重賞:          93

■ 騎手補正:
  リーディング上位10位以内: +3
  リーディング11-30位:      +1
  それ以外:                  0
  見習い騎手:               -2

■ 調教評価補正:
  A評価: +2
  B評価:  0
  C評価: -1
  D評価: -2

■ LTS_Final算出:
  LTS_Final = 補完LTS × 0.6（信頼度係数）
  ★ 指数なしフラグ = ON → ランキング表で [補XX] と表示
  ★ UPS計算: 補完LTS馬は母数から除外（GF馬と同様）

■ 旧ルール（参考）:
  LTS_Final ≈ R1 × 0.7 → 廃止（R1自体が存在しない場合に対応不可のため）
```

## TRD算出【Ver.98.2: 加点のみ方式に移行】

```
△1 = R1（前走） - R2（2走前）
△2 = R2（2走前） - R3（3走前）
```

| 条件                     | TRD | 解釈 |
|--------------------------|-----|------|
| △1 > 5  かつ △2 > 0     | +5  | 2走連続上昇（急上昇・絶好調） |
| △1 > 5  かつ △2 ≤ 0     | +4  | 直近急上昇（前走のみ）【98.2: +3→+4】|
| 0 ≤ △1 ≤ 5              | +3  | 安定維持・微上昇【98.2: +1→+3】|
| -5 ≤ △1 < 0             | +2  | 横ばい・微減（許容範囲）【98.2: 0→+2】|
| △1 < -5 かつ △2 > 0     | +1  | 直近急落（一時的の可能性）【98.2: -1→+1】|
| △1 < -5 かつ △2 < 0     |  0  | 2走連続下降（要注意）【98.2: -3→0】|
| 近走データ2走以下        | +2  | 判定不能（ニュートラル）【98.2: 0→+2】|

R2またはR3が"-"の場合 → TRD = +2（判定不能）【98.2: 0→+2】

## フラグ自動判定（Ver.98.2）

### GrowthFlag（GF）判定
- 条件A: R1 ≥ LTS_max（前走で過去最高更新）
- 条件B: TRD ≥ +4（急上昇 ※旧+3相当）【98.2改定】
- 条件C: 3〜5歳 AND LTS_Final_Rank ≥ 出走頭数 × 0.55（中下位）
- 2条件以上該当 → GF=ON → 🌱マーク + UPS計算除外 + 相手強制追加

### LDF（直近信頼度低下フラグ）判定
- 条件1: TRD = 0（旧-3相当。判定不能+2とは区別される）【98.2改定】
- 条件2: R1 ≤ LTS_max × 0.85（前走が過去最高の85%以下）
- 両方該当 → LDF=ON → ⚠️直近信頼度低下 + 副軸提示

### SCF（単発崩れ型候補フラグ）判定
- 条件1: R1 ≤ LTS_max × 0.80（前走が過去最高の80%以下・大幅下落）
- 条件2: R2 ≥ LTS_max × 0.90（2走前は過去最高の90%以上・安定）
- 除外: GF=ON馬 または R2="-"
- 両方該当 → SCF=ON → ⚡相手7頭目として検討推奨

### 逃げ馬序列の判定基準【Ver.98.0新設】

逃げラベルの馬が2頭以上いる場合、以下の手順で序列を判定する。
逃げラベルが1頭のみの場合は自動的に「主逃げ」とする。

```
■ Step 1: テン3F（前半3ハロン）の比較
  過去5走のテン3F平均タイムを各逃げ馬で算出。
  最速の馬を「主逃げ候補」とする。

■ Step 2: テン3F差の判定
  主逃げ候補と2番手以降のテン3F差を算出。
  - 差 ≥ 0.3秒 → 2番手以降は「番手転換」（追いつけない）
  - 差 < 0.3秒 → 2番手以降は「競り逃げ」（競り合いリスク）

■ Step 3: 枠順による補正
  テン3F差が 0.2〜0.4秒（ボーダーライン）の場合:
  - 主逃げ候補が内枠（1-4枠）→ 差0.2秒でも「番手転換」に格下げ
    （内枠が楽にハナを切り、外枠は無理に競らない）
  - 主逃げ候補が外枠（7-8枠）→ 差0.4秒でも「競り逃げ」に格上げ
    （外枠はハナを主張するのにロスがかかり、競り合いになりやすい）

■ Step 4: 前走位置取りによる補正
  逃げラベルだが前走で3番手以下だった馬 → 「番手転換」に1段階格下げ
  （前走で控えた実績あり = 今回も控える可能性が高い）

■ 判定フローまとめ:
  逃げ馬リスト → テン3Fでソート → 最速=主逃げ
  → 2番手以降: 差≥0.3秒 → 番手転換 / 差<0.3秒 → 競り逃げ
  → 枠順・前走で微調整
```
