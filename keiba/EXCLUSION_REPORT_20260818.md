実測日: 2026-08-18

## 何を測ったか

「レースを条件で分けて専用モデルを作る」は5回失敗した。今回は方針を変え、
**モデルは汎用のまま据え置き、レースそのものを"予想可能"と"例外"に分けて、例外は買わない**
という設計を測った。

除外に使う指標は、すべて発走前に入手できるものだけ:
- `fav_p` : 市場1番人気の implied 確率（オッズの逆数を正規化）
- `ent` : implied 確率分布のエントロピー（市場の割れ具合）
- `sgap` : モデル1位と2位の得点差

閾値は **MINE のみ**で決定（fav_p は上位40%、ent は下位40%、sgap は上位60%）:
```
A: fav_p >= 0.341
B: ent   <= 1.904
C: sgap  >= 0.066
```

## 結論（2つに分けて書く）

### 達成した: 的中率
**複勝・市場上位2頭の2点買いで、的中率 MINE 94.4% / VALIDATE 95.9% / CONFIRM 92.4%。
3期すべてで90%超。** 閾値はMINEだけで決めたので、VALIDATE と CONFIRM は完全に未知データ。
「例外を除けば、残りはほぼ全部当たる」は成立する。過去に失敗した5件と違い、
これは条件別モデルではなく汎用モデルのままレースを選んだだけなので、
分割によるデータ不足の問題が起きない。

### 未達: 回収率
最良で 95.6%（VALIDATE）、CONFIRM では 85.3%。**100%には届かない。**
複勝の控除率は実測20.4%なので、無選別の期待ROIは79.6%。95.6%はそこから+16pt で、
市場を出し抜いてはいる。しかし控除率の壁を越えてはいない。

三連複はVALIDATEで98.9%が出ているが、CONFIRMで57.4%に崩れる（n=132、1点買いなので分散が大きい）。
この数字は採用しない。

### なぜROIが動かないか（今回の数字で確認できたこと）
的中率が 46.8%→83.2% と1.78倍になったとき、ROIは 78.6%→91.5% と1.16倍にしかならない。
差の分は配当が落ちている。市場は「当たりやすいレース」を知っていて、その分オッズを下げている。
これは今セッションで別途測った「配点を変えても 的中率×平均配当 の積は動かない」
（的中率27%→7%、平均配当280→1,307円、ROIは77.9%のまま）と同じ現象。

### 残っている道
控除率20.4%を越えるには、あと+5〜15pt が要る。方法は原理的に2つしかない。
1. **除外の精度を上げる** — 今回使ったのは市場と得点差の3指標だけ。
   データ駆動のクラスタリング（実行中）が、これより良い例外判定を見つけられるかどうか。
   合格ラインは VALIDATE と CONFIRM の両方で複勝ROI 100%超・的中率85%以上・n>=80R。
2. **市場の価格ズレを突く** — 予想の当たりやすさではなく、市場が間違っている度合いで選ぶ。
   MODEL_V4_RESULT.md の結論（オッズ抜きで控除率を超えるのは不可能）と同じ方向。
