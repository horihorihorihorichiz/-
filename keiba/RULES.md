# 競馬予想 運用ルール（毎回必ず守る・チェックリスト）

このファイルは、ユーザーから受けた「標準指示」の固定版。予想を出すたびに毎回ここを見て全項目を満たす。

## 出力（毎レース必須）
1. **全頭ランキングを必ず出す**（馬番・脚質・得点(総合=WAvg)・PWin・ランク・単勝オッズ の全列）。省略禁止。
2. **買い目は netkeiba「軸流し」形式**で書く（1頭軸→軸流し / 2頭軸→2頭軸流し / S3頭→BOX）。
   - **S2頭でも既定は1頭軸流し**（1位を単軸・2位を相手筆頭）。2頭軸は片方が飛ぶと全滅（7/5北九州で④凡走→8点全滅）なので明示指定時のみ。
   - **★1.7倍級の“1本かぶり”が市場にいる時、それを完全に軸から外して人気を落とす穴1頭に全額依存する構成は禁止**（7/8スパーキングで軸⑨47倍が5着→全滅、1.7倍⑧が勝ち）。モデルが強い単勝EVを示しても、sub-2.0の本命がいる時は「本命を1頭軸に据え、穴は相手の1枚に混ぜる」。EVが幻の場合に全滅を避ける。
3. **点数を必ず明記**（券種ごとの点数＋合計点数＋券種ごとの投資額）。
4. **全6券種から最高の組み合わせを選ぶ**：単勝・馬連・馬単・ワイド・三連複・三連単（EVプラスのみ）。
   - **核(的中率)＝順序に強い券種のみ**（単勝/馬連/ワイド/三連複）。三連単・馬単をfloor担保に使わない（順序が外れると落ちる＝7/8検証）。
   - **馬単・三連単＝上積み(高配当)**。軸が「勝つ」と読める時(Sランク かつ 単勝≤5.0倍 or PWin≥25%)だけ、軸1着固定で薄く。各点floor厳守。exactが読み通りなら大きく返る（JCの170万馬券型）。

## 予算・配分ルール（デフォルト、変更指定時のみ上書き）
- 予算 **10,000円** / **250%floor** / **100円単位**。
- **【二層構造：核＋上積み】(7/8スパーキング大反省で確立)**
  1. **軸＝モデル最上位のSランク馬**。**SランクをEV妙味で軸から外すの禁止**（⑧S=1着を捨て⑨B=47倍を軸にして全滅した反省）。
  2. **核＝軸×「モデルも市場も評価する馬」**（ランクS/A/Bかつ単勝オッズが低い＝人気の上位2頭）。単勝＋馬連＋ワイド＋三連複を重ねる＝**的中率重視**。期待値馬(モデルだけ高評価の高オッズ穴)を核に入れない。
  3. **期待値馬（市場に売られてる妙味の穴）は「上積み」**に回す＝三連複中心に薄く＝**配当重視**。
- **floorは「買い目(複合)単位」で考える**：同じ買い目に重ねた馬連＋ワイド＋単勝＋三連複は**一緒に当たる**（馬連的中⟹同一買い目のワイドも必ず的中）ので、**想定決着(軸→核①→核②)での複合合算払戻が対予算250%前後**を担保すればよい（短オッズ本命でも買い目単位でクリア）。**上積み(穴)の各点は単体で250%floor厳守**。
- **【方針A(7/8)確定・維持】核の短オッズ買い目(単勝・短ワイド等)は“安全網”として残す**。個別買い目で250%割れは許容（想定決着の複合合算で250%超を担保していればOK）。＝取りこぼしを減らす側に倒す。（★短オッズ買い目を“切る”のは誤り。250%は複合合算で担保する）
- **システム上位を厚く、穴は薄く**（純EV最大化で穴を過信しない＝7/1・7/8の反省）。
- predict.py の build_buylist が上記を自動化。最後に人的判断を1枚。

## データ反映（毎回確認）
- **馬場（良/稍/重/不）** を必ず確認・反映（道悪TAS）。稍重＝ミドルハイ「上限(min3)」で固定でない。重/不＝ミドル上限(min2)。
- **馬体重・最終オッズ**を反映。ブースト①②指定を反映。
- **枠順**（馬番→枠は自動変換）と内回り/外回りを反映。

## オッズ取得
- 大井/名古屋(NAR): race_id=YYYY+場コード+MM+DD+RR（例 大井=44, 名古屋=48）。odds_get_form.html。
- JRA: race_id=YYYY+場コード(2)+開催回(2)+日目(2)+R(2)。api_get_jra_odds.html type=**1単/4馬連/5ワイド/7三連複**（★type=8は三連単。取り違え厳禁）。場コード: 札幌01函館02福島03新潟04東京05中山06中京07京都08阪神09小倉10。

## 検証

## 安全
- 最終の投票確定ボタンは必ずユーザーが押す。自動では押さない。パスワード・Cookieは使わない/保存しない。
