## 1. 出力（毎レース必須・省略禁止）
1. ★**全頭ランキングを必ず出す**。列＝**馬番・馬名・脚質・得点(WAvg)・PWin・ランク・単勝オッズ(人気)**。
   - ★「得点(WAvg)」列を忘れない（3回忘れた）。
2. **買い目は netkeiba で買いやすい形**：軸流し形式（1頭軸→軸流し / 2頭軸→2頭軸流し / S3頭→BOX）。
   - ★**並び順は「券種ごとにまとめて、馬番の若い順」**（入力しやすいように）。
3. ★**点数を必ず明記**：券種ごとの点数＋金額＋合計点数＋合計金額。
4. **i-PAT入力フォーマット**を毎回付ける（下記テンプレ）。
5. 結果が出たら **results.jsonl に記録**し、**的中率・回収率（stats.py）**を更新。

## 2. 予算・floor（デフォルト。指定があればそのレースだけ上書き）
- 予算 **10,000円**／★**最低ライン200%（2倍）**／★**100円単位**。(7/9ユーザー決定: 250%→200%に変更)
- **【シナリオ保証システム(7/9確立)】どの的中シナリオでも回収が最低2倍**になるよう組む:
  1. **保証層**: 各相手を「当たれば単独で2倍」の券で担保。
     - **ワイド単独2倍**=『軸と相手が両方馬券内』の全パターンを2倍保証（馬連的中⇒ワイドも的中、が根拠の最安カバー）。
     - ワイドが高すぎる人気相手は**馬連単独2倍**に格下げ（ワンツーのみカバー・安い）。
     - ★**2倍に届かないトークン買いは全廃**（「ワイドのみ的中で回収が合わない」買い方をしない）。
  2. **核(人気本命S/A/B or ≤3.5倍)は必須カバー**。残る相手は**的中確率/円の効率順**でカバー=システム×期待値の自動バランス。
  3. **EVブースト層**: 残予算で三連複・三連単・馬単をEV降順・各点2倍floor。
- 出力に**シナリオ保証表**（⑪-①ワンツー→X円(Y%) 等）を必ず付ける。

## 3. 買い目の組み方【二層構造】（7/8スパーキング大反省で確立）
- **軸＝モデル最上位のSランク馬**。★**SランクをEV妙味で軸から外すの禁止**
  （7/8: S=⑧1着を捨てB=⑨47倍を軸→全滅。「Sランクしっかり活用して」）。
- **【ハシゴ一貫性(7/9確定)】相手に採用した馬は必ず「馬連＋ワイド＋三連複」のセットで買う**。三連複に入る馬が馬連/ワイドに居ない“歯抜け”禁止。相手＝人気本命(S/A/B or ≤3.5倍)＋モデルpwin順で最大5頭（S/A/Bは全員）。
- **核（的中率）**＝軸×「モデルも市場も評価する馬」（ランクS/A/B、または**単勝3.5倍以下の人気馬は評価Cでも核に入れる**＝1.9倍本命を切らない）。
  単勝＋馬連＋ワイド＋三連複を重ねる。**核は順序に強い券種のみ**（馬単・三連単をfloor担保に使わない＝順序が外れると落ちる）。
- **上積み（配当）**＝期待値馬（市場に売られてる妙味の穴）。三連複中心に薄く。
- **全6券種から最高の組合せを選ぶ**：単勝・馬連・馬単・ワイド・三連複・三連単。
  - ★**馬単・三連単は「Sランクの頭（1着固定）」だけ**。軸が勝つ読み（S かつ 単勝≤5.0 or PWin≥25%）の時に上積みで薄く（JCの170万馬券型）。
- **システム上位を厚く、穴は薄く**（EV最大化で穴を過信しない）。
- **S2頭でも既定は1頭軸流し**（2頭軸は片飛び全滅＝7/5北九州の反省。明示指定時のみ）。
- **sub-2.0の1本かぶりを完全に切って高オッズ穴1頭に全額依存は禁止**（7/8の反省）。

## 4. データ反映（毎回確認）
- ★**馬場（良/稍/重/不）**を必ず確認（道悪TAS: 稍→S10/A5、重不→S15/A8）。
  展開: 稍重＝ミドルハイ**上限(min3・固定でない)**／重・不＝ミドル上限(min2)。
- ★**馬体重（増減）・最終オッズ**を反映（発走前に更新されたら取り直して組み直す）。
- **枠順**：芝=内有利FSI_MATRIX／ダート=**外枠プラス（砂被りロジック）FSI_MATRIX_DIRT**。
- 9走分の馬柱・タイム指数・CSI・休養(NRJA)・ブースト指定を反映。

## 5. オッズ取得（predict.py が自動化）
- **NAR**: race_id=YYYY+場コード+MM+DD+RR（大井44/川崎45/笠松47/名古屋48…）。
  odds_get_form.html を **cart-item属性**でパース。b1単/b4馬連/b5ワイド/b6馬単/b7三連複/b8三連単（b7,b8は&jiku=軸指定）。
- **JRA**: race_id=YYYY+場(2)+回(2)+日(2)+R(2)。api_get_jra_odds.html
  type=**1単/4馬連/5ワイド/6馬単/7三連複/8三連単**（★7三連複と8三連単の取り違え厳禁）。
  場コード: 札幌01函館02福島03新潟04東京05中山06中京07京都08阪神09小倉10。

## 6. 実行
```bash
# ★完全自動（race_idだけ／既定）: 出馬表+過去9走をnetkeiba公開ページから取得→予想まで一気通貫
python fetch_race.py <race_id> --run --budget 10000
#   タイム指数はプレミアム限定→既定None（軸はほぼ不変・相手判別のみやや低下）。
#   精度UP時のみ数字を貼って --tsi tsi.txt（"馬番 t1 t2 …"新しい順）。

# 手動（馬柱を貼られた／race_id不明時）
python predict.py race_xxx.json --race-id <id> [--budget N]   # ランキング〜買い目〜i-PATまで自動
python stats.py                                               # 通算 的中率・回収率
```
