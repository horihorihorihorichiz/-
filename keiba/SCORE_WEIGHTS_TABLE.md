# 条件別の得点配分表（B-sd16・実データ）

学習: Ver.99.27の11成分+展開乗数 に、通過順から作った4特徴を足した16成分。
芝ダ×距離帯の6条件それぞれに配点を学習（MINEのみ・未知2期で検証済み=V99W2_REPORT）。
表の値は **TSI(タイム指数)を1.00としたときの相対倍率**。
**TSI=30点と読み替えれば、そのまま点数になる**（例: 芝L の DSI 4.32 → 約130点相当）。

実体は `v99w2_result.pkl` の `arm2_w`。`v99w_rank.py` が毎回ここから読む。
selfcheck が指紋を検査するので、値が1つでも変われば起動時に落ちる。

## 条件ごとの読み方（数字が語っていること）

### 芝S(〜1400)
- 効く順（TSI以外の上位3）: **mgn_abs** -2.30 / **DSI** +1.87 / **spd_res** +1.68

### 芝M(1401-1700)
- 効く順（TSI以外の上位3）: **mgn_abs** -2.88 / **DSI** +2.29 / **spd_res** +1.62

### 芝L(1701〜)
- 効く順（TSI以外の上位3）: **mgn_abs** -7.00 / **DSI** +4.32 / **NSI** +3.31

### ダS(〜1400)
- 効く順（TSI以外の上位3）: **spd_res** +1.59 / **mgn_abs** -1.13 / **DSI** +1.10

### ダM(1401-1700)
- 効く順（TSI以外の上位3）: **DSI** +1.85 / **mgn_abs** -1.74 / **spd_res** +1.72

### ダL(1701〜)
- 効く順（TSI以外の上位3）: **mgn_abs** -1.85 / **DSI** +1.40 / **spd_res** +1.35

**全条件に共通すること**
- **mgn_abs（着差）は全群でマイナス**。前走で大きく離された馬を市場が過小に嫌う＝そこを買う側に振れという意味ではなく、
  「着差が小さいことを市場が過大評価している」補正。芝Lで −7.00 と極端に強い。
- **spd_res（スピード余力）は全群でプラス1.35〜3.21**。通過順の再収穫で初めて手に入った成分で、今回の伸びしろの主役。
- **WAS（斤量差）は6群中5群でマイナス**。軽量馬への加点は予想を悪くする＝現行15点は撤廃が正しい。
- **HCS（馬体重）0.20〜0.37 / 展開乗数 −0.07〜0.50** ＝ ほぼ効かない。

**条件によって大きく違うこと**
- **DSI（距離適性）**: ダS 1.10（33点相当）〜 **芝L 4.32（130点相当）**。長距離ほど距離適性がすべて。
- **LTS（上がり）**: ダS 0.51 〜 **芝L 2.04**。ダート短距離で上がりを見るのは無駄に近い。
- **FSI（枠×脚質）**: **芝M 0.27 が最弱**。芝の中距離は枠で買わない。
- **NSI（クラス実績）**: **芝L 3.31** が突出。長距離は格がそのまま出る。
- **CSI（コース適性）**: 芝S 0.02 ＝ ほぼ無意味。芝L 1.48 / ダL 0.63 では効く。
- **wide4c・pos_gain**: ダMで符号が反転（−0.12 / −0.08）。位置取り系はダ中距離だけ逆に働く。

## 注意（この表の使い方）

1. これは**並べる力**の配点。**買い目の期待値ではない**。ROI 100%超はこの配点では出ていない（EDGE16_REPORT）。
2. 値はレース内で標準化したスコアに掛ける係数。生の点数をそのまま足す Ver.99.27 とは尺度が違う。
   「TSI=30点なら」の換算は**成分間の重みの比較**のために付けた読み替えで、手計算用の表ではない。
3. 本番エンジン（calc.py / params.json）はこの配点を**使っていない**。凍結ルールブックの実測を汚さないため、
   `v99w_rank.py` の並走レーンで記録だけしている。採用は前向き実測を見てから。
4. 再現: `python3 v99w2_fit.py --stage final`（指紋: 202610020612 の B-sd16 上位3頭 = [5,8,15]）
