## 結論（先頭に明記）

**第2次キャンペーンも事前登録基準により不合格。採用セルはゼロ。**

- 多重比較の3倍ルール（プロトコル第4条）に**(a)合算・(b)単独の両方で抵触**:
  - **(b) 単独: VALIDATE通過 103 < 3 × 偶然期待 44.40 = 133.20 → 不合格**（実測は期待の2.32倍）
  - **(a) 合算: VALIDATE通過 115（第1次12+今回103） < 3 × 偶然期待 53.15 = 159.45 → 不合格**（同2.16倍）
  - プロトコル第4条「どちらか一方でも不合格ならキャンペーンは不合格として公表する」に従い**不合格**。
- 3段関門（MINE→VALIDATE→CONFIRM）を全て通ったセルは**9個**あった。うち**8個がV8軸を含む**。
  しかし上記のとおりキャンペーンが不合格である以上、**これらは採用しない**（後述の全数字は記録のためだけに載せる）。
- 補足診断（判定基準は変更せず・報告のみ）: null検定通過888セルのVALIDATE窓で同じシャッフルnullを
  1000回ずつ回した**経験的な偶然通過期待は75.49セル**（VALIDATE窓 n≥15 の499セル・平均15.1%/セル）。
  実測103はその**1.36倍**でしかない。名目5%基準（44.40）より甘い現実的基準で見ると、
  今回の「発見」は偶然の量とほとんど区別できない。
- **V8軸の判定**: V8軸を含むセルは各段で非V8よりやや高い生存率を示した
  （VALIDATE通過率 V8 12.4% vs 非V8 9.3%／CONFIRM通過 8 vs 1）。
  だがこれは事前登録された合否基準ではなく、キャンペーン不合格の結論を動かさない。
  **「V8軸を条件として切れば勝てる」とは主張しない。**
- V8_RESULT_20260817.md の結論（V8特徴をモデルに入れる使い方は α<0 で不成立）は今回も覆っていない。

- 条件付き通過率で見ると: null→VALIDATE は **V8 82/661=12.4% vs 非V8 21/227=9.3%**（名目の偶然率は5%）。
  VALIDATE→CONFIRM は V8 8/82=9.8% vs 非V8 1/21=4.8%。
- **V8軸を含むセルはゼロではなく、各段で非V8よりやや高い生存率を示した**。3段通過9個中8個がV8軸入りで、
  特に `cp_front高`（コース先行度が高いコース）が6セル、`tb_front_surf`（当日の先行有利度）が3セル、
  `tb_upset`（当日の荒れ度）が2セルに現れた。
- **ただしこれは事前登録された合否基準ではない**。キャンペーン全体は3倍ルールで不合格であり、
  V8軸入りセル群だけを取り出して「V8は効いた」と主張するのは、まさに事前登録が禁じている
  部分集合の後出し評価にあたる。V8軸入りセルだけで3倍ルールを当てはめても
  82 < 3×(661×0.05)=99.15 で**やはり不合格**（この当てはめ自体、事前登録にない後付け指標なので参考）。
- 結論: **V8軸が「条件として切る」使い方で有効だという主張はできない。** 記録として残るのは

  観察のみで、これは今後の**新規データでの前向き観察**の対象にしかならない。

## データ・手法の既知の限界（第1次から持ち越し＋今回固有）

1. **スピード指数の較正定数が全期間フィット（軽微なリーク）**: モデルscores由来のシグナル
   （g12/sp15/p1・モデル序列）はライブ運用時より僅かに「良く見える」方向のバイアスを持つ。
   MINEだけでなくVALIDATE/CONFIRMのROIもライブ比で楽観側に寄る。
2. **確定オッズ使用**: 実運用は直前オッズ。o1/o2/市場1位オッズ帯を条件に使うセルは実運用と数%ズレうる。
3. **検証窓が小さい**: VALIDATE 874R / CONFIRM 676R。n=12〜40のセルROIは1発の配当で大きく動く
   （実際、通過9セルのうち5セルはCONFIRM n≤17）。
4. **セル間の非独立**: 上記のとおり9セルは5〜6族。名目の通過数は実効発見数より多い。
5. **今回固有: 軸を21本に増やした分、試行が3.82倍になった**。事前登録の注記どおり
   「発見数が増えても偶然期待も同じ比率で増える」が実際にそのまま起きた
   （試行3.82倍 → VALIDATE通過 12→103、偶然期待 8.75→44.40。比率はどちらも約8.6倍・5.1倍で同オーダー）。

   当該レース日付より前の日のみ）。この保証が崩れていれば V8軸入りセルの数字は上振れする。
