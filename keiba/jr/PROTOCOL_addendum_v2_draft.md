# JOCKEY_RAW_PROTOCOL — 騎手・斤量の「生の変化」シグナル 事前登録

作成: 2026-08-20（測定前に確定。以降この文書は結果を見て書き換えない）
担当: 実験アーム `jockey_raw`

## 0. 動機と事前予想（正直に）

人が丸めた騎手集計（リーディング、複勝率、jockey_db.py の j_top3 等）は過去に全滅している。
未測定なのは「前走からの生の変化」そのもの:

- (a) 乗り替わり（前走騎手ID → 今走騎手ID の変化）
- (b) 斤量の前走差（kinryo の増減）
- (c) 馬体重変化 × レース間隔 の交互作用

**事前予想は「ほぼゼロ」**。理由: (a)(b)(c) はいずれも出馬表に印字され、締切前に市場が見ている情報である。
市場log-odds をオフセット固定した増分 ΔLL が正になる余地は、市場が「重みづけを誤っている」場合のみ。
したがって本測定は「効かないことを数字で確定させる」ためのものであり、正が出たら疑ってかかる。

## 1. データと結合

### 1.1 素材
- `hist/*.json` 8805R（race + result + date）。全期間で kinryo / weight_change / last_race_days は 100% 充足。
- `hist_enrich/*.json` 7058R（202407–202608）。全出走馬に `jockey_id` と着順。hist の部分集合（race_id 完全一致）。
- hist 本体の `jockey_id` は 202509–202606 が欠損（0%）、202507/08・202607 が部分欠損。
  → **今走 jockey_id は hist_enrich を優先し、無い場合のみ hist を使う**。

### 1.2 前走リンク（乗り替わり・斤量差に必須）
過去走レコード（hist の `races[]`、`horse_cache/`）には jockey_id も kinryo も入っていない。
よって前走の騎手・斤量は「その馬が前走で出走したレース自体」を hist ∪ hist_enrich から引くしかない。

リンク規則（確定）:
1. `horse_id` をキーに、hist ∪ hist_enrich の全出走記録を (日付 → {jockey_id, kinryo}) として索引化。
2. 対象行（レース日 D、`last_race_days` = L）に対し、日付が `D - L` ± 1 日 かつ D 未満 の記録を検索。
3. 該当があればそれを前走とみなし、jockey_id / kinryo を取る。複数該当時は最新日。
4. 該当が無い行は **除外しない**。`linked=0` のダミーで区別して全行をモデルに残す
   （新馬・長期休養・非JRA前走が系統的に落ちるのを防ぐため。選択バイアス回避）。

### 1.3 リンク被覆率（測定済み・事前確定の事実）
| 期 | 行数 | 今走騎手 | 前走リンク | 前走騎手あり | 前走騎手×今走騎手 両方 | 前走斤量あり |
|---|---|---|---|---|---|---|
| MINE (≤202602) | 99,150 | 99.9% | 67.4% | 67.3% | **67.2%** | 67.4% |
| VAL (202603–05) | 12,358 | 99.8% | 92.5% | 92.2% | **92.0%** | 92.5% |
| CONF (202606–08) | 10,091 | 99.9% | 85.6% | 85.4% | **85.3%** | 85.6% |

いずれも 50% 超。よって「測定不能」ではなく **測定可能** と判定する。
（(c) 馬体重変化×間隔は hist 本体だけで 100% 充足。リンク不要。）

## 2. 分割（固定・変更禁止）

hist の `date` の年月で分割する。
- **MINE**: month ≤ 202602 （99,150 行 / 6,929 R）— 閾値・特徴・仕様の決定は全部ここだけ。
- **VAL**: 202603–202605 （12,358 行 / 874 R）— 最後に1回だけ。
- **CONF**: 202606–202608 （10,091 行 / 763 R）— 最後に1回だけ。

VAL/CONF を見た後に仕様を変えることは禁止。変えたら別実験として試行数に加算する。

## 3. 判定モデル（一次基準）

レース内条件付きロジット（softmax over runners in a race）、**市場 log-odds をオフセット固定**。

```
u_i = log(p_mkt_i) + β · x_i          （log(p_mkt) の係数は 1.0 に固定、推定しない）
P(win = i) = exp(u_i) / Σ_j exp(u_j)
p_mkt_i = (1/odds_i) / Σ_j (1/odds_j)   （単勝オッズ、レース内正規化）
```

- 目的変数 = 単勝的中（result.order の rank == "1"）。
- **ベースLL** = β=0（市場そのまま）のときの平均対数尤度。
- **増分 ΔLL** = 当該期の 1行あたり平均 LL(β̂) − LL(0)。単位は nats/race。
- β̂ は **MINE で推定**し、VAL / CONF にはその係数を**そのまま適用**（再推定しない）＝真のOOS。
- 合格条件（一次）: **ΔLL > 0 が VAL と CONF の両方**。片方でも ≤0 なら不合格。
- 有意性: レース単位のブートストラップ（B=2000、レース再抽出）で ΔLL>0 の片側 p を出す。

### 3.1 ROI を主張する場合の追加条件
ROI を持ち出すのは ΔLL が VAL/CONF 両方で正だった仮説のみ。その場合でも
**VAL・CONF 両方で回収率 100% 超 かつ n ≥ 80** を満たさなければ「勝てる」とは書かない。
本アームは ΔLL が主で、ROI は事後の参考値に留める。

## 4. 仮説と特徴量（MINE で仕様を確定し、以下の5本だけを VAL/CONF に持ち込む）

すべての特徴は、リンク不可行では 0 に置き、`linked` ダミー（1=前走リンク成功）を同時に投入して
「リンクできたこと自体の効果」を吸収する。連続量はレース内で中心化しない（条件付きロジットが
レース内定数を自動的に消すため、レース内平均のシフトは推定に影響しない）。

- **H1 乗り替わり（有無）**: `chg = 1[前走騎手 ≠ 今走騎手]`, + `linked`
- **H2 当該馬騎乗経験**: `newpair = 1[今走騎手が、この馬にキャリア内で一度も乗ったことがない]`,
  `n_prev_rides = log1p(その騎手がこの馬に乗った過去回数)`, + `linked`
  （経験はレース日 D より**厳密に前**の記録のみ。hist ∪ hist_enrich の全期間索引を使う。）
- **H3 斤量前走差**: `dk = 今走kinryo − 前走kinryo`（kg）。MINE で線形 / クリップ / 符号分割を比較して1本に確定, + `linked`
- **H4 馬体重変化 × 間隔**: `wc = weight_change`（kg, 100%充足）、`ivl = last_race_days`。
  `wc`, `wc^2`, `wc × 1[ivl>90]`, `1[ivl>90]` を基本形とし MINE で確定。リンク不要。
- **H5 全部乗せ**: H1〜H4 の確定特徴を同時投入した1本。

## 5. 試行数の申告と多重比較

- **VAL/CONF に持ち込む主仮説は 5 本（H1〜H5）**。
- 各仮説について VAL と CONF の 2 期。判定は「両方で ΔLL>0」の連言なので、期については追加補正しない。
- 有意水準: **Bonferroni α = 0.05 / 5 = 0.01**（片側）。VAL・CONF 両方で p < 0.01 を要求する。
- MINE 内での仕様探索（H3 の関数形、H4 の閾値など）は探索とみなし試行数に数えないが、
  **VAL/CONF を一度も見ずに終える**ことで担保する。MINE 内で試した本数はレポートに実数で記載する。

## 6. 偽陽性チェック（null control）

H1〜H5 のうち VAL/CONF 両方で ΔLL>0 になったものがあれば、以下を必ず実施し、通らなければ棄却:
- **ラベルシャッフル null**: レース内で勝ち馬をランダムに再割当（市場オフセットはそのまま）した
  合成データで同じ手順を 200 反復し、実データの ΔLL が null 分布の上位 1% 外にあることを要求。
- **騎手ID置換 null**: 前走騎手IDを同一期内でランダムな別騎手IDに置換して H1/H2 を再測定し、
  ΔLL が実データより有意に小さいことを要求（＝「変化そのもの」が効いている確認）。

## 7. 事前に決めた失格条件

- リンク被覆率が当該期で 50% 未満 → その仮説は「測定不能」と書く（現時点の実測では全期 50% 超）。
- VAL または CONF で ΔLL ≤ 0 → **不合格**。差の大きさを nats/行 で正直に記載する。
- 「一部のレース種別だけで勝った」は主張しない。全レース比較のみを報告する。
