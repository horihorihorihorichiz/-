### 【依頼A】コース別の傾向データ（最優先）

**背景**: ユーザーの構想「東京芝2000m専用システムを作れば期待値プラスになる」を実装中です。
ただしコース単位に分けるとデータが1/23に減る問題があり、**コースの癖を直接教えてくれる情報**が
あればそれを補えます。netkeibaの「コースデータ」ページに、私が持っていない集計があるはずです。

**欲しいもの**（取れる範囲でOK・1コースずつでも歓迎）:
```
対象コース: まず主要18コース（レース数が多い順）
  中山ダ1800 / 中山ダ1200 / 京都ダ1800 / 東京ダ1600 / 阪神ダ1800
  東京ダ1400 / 中京ダ1800 / 京都ダ1400 / 新潟ダ1800 / 中山芝1600
  福島ダ1700 / 東京芝1600 / 中京ダ1400 / 京都ダ1200 / 小倉ダ1700
  （＋東京芝2000m など、ユーザーが例に挙げたコース）

欲しい列:
  1. 枠番別成績（1〜8枠の勝率・複勝率・単勝回収率・複勝回収率）
  2. 脚質別成績（逃げ・先行・差し・追込の勝率・複勝率・回収率）
  3. 人気別成績（1〜10番人気の勝率・複勝率・単勝回収率）
  4. 種牡馬別成績（そのコースで好成績の父・上位10頭でOK）
  5. 騎手別成績（そのコースの上位10人）
  ※集計期間も明記してください（過去◯年 等）
```

**なぜこれが効くか**: 私が自分で計算すると2年分のデータ（コースあたり100-260R）しか使えませんが、
netkeibaの集計は10年分などの長期データを持っているはずです。長期の安定した傾向は、
短期データのノイズに埋もれない本物のコース特性である可能性が高いです。
