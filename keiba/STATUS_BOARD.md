**方針変更**: 「東京芝2000m」は例として挙がったものでした。
コース別データは1つずつ手集めするより、こちらで全120コースを一斉検証して
「どのコースが有望か」を統計に選ばせる方が正しい順序です（現在検証中）。
**有望コースが判明したら、そのコースだけ深掘りをお願いします。**

そこで先に、**何が取れるのかの棚卸し**をお願いします。
プレミアム画面を実際に開いて、あるものを列挙してください。

```
知りたいカテゴリ:
 1. ラップタイム/ペース関連
    各ハロンのラップ・前後半3F・ペース指数・上がり順位・位置取り推移
 2. 馬体/馬具関連
    馬体重の推移・ブリンカー等の着用変更・去勢歴・休養理由
 3. 厩舎/ローテーション関連
    厩舎の休み明け成績・間隔別成績・帰厩日・放牧先
 4. 血統関連
    父/母父別のコース適性・距離適性・馬場適性の集計
 5. 馬場関連
    クッション値・含水率・芝丈・A/Bコース使用状況
 6. netkeiba独自の指数・スコア類（タイム指数以外）
 7. ★オッズの時系列★（前日オッズ・変動履歴・人気の推移）
```

**★7が最重要です。** こちらの実測で「三連複は発走直前にオッズが1.91倍に伸びる」
という市場の非合理な動きを発見しました。オッズの時系列データがあれば、
この歪みを直接突けます。モデルの精度に依存しない、いま最も有望な攻め口です。

```
判断基準（検証済みの経験則）:
 ✗ 印・評価・◎○▲・SABC など人が丸めたもの → 全滅済み。市場が織り込み済み
 ○ 生の数値・計測値・長期集計・時系列       → 効く可能性あり
```
