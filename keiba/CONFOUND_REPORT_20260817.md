## 結論（先に）

### 1. 調教評価(SABC) — **市場を条件にすると、残る情報は検出されない**

| 検定 | 統計量 | p |
|---|---|---|
| C vs B（1着・条件付きロジット LR） | ΔlogL **+0.930** / χ²=1.86 df=2 | **0.395** |
| C vs B（3着内・プールドロジット LR） | ΔlogL **+0.140** / χ²=0.28 df=3 | **0.964** |
| 調教ダミー3本の同時検定（3着内・**raceクラスタ頑健Wald**） | χ²=**0.28** df=3 | **0.963** |
| `grade_C` 係数（3着内） | **+0.0491** (SE 0.2157) | **0.820** |

`grade_C` の係数は **符号すら逆**（Cのほうがわずかに良い）。AIC も悪化する（3着内 803.27→808.99、1着 274.02→276.16）。
leave-one-day-out でも改善しない（3着内 oos logL **C−B = −1.40**、Brier **+0.00034 悪化**）。
null検定でも観測LR統計量は null分布の**平均を下回る**（3着内 経験的 p=0.95〜0.96）。

→ **「調教B vs C で複勝率27% vs 14%」の 11.5pt 差は、ほぼ全量が市場オッズとの交絡である。**
　 調教評価は市場が既に織り込んだものと同じものを見ており、**上乗せ情報はこの標本では検出できない**。

### 2. タイム指数 — **3着内に対してのみ、弱い増分がある。ただし実用的な大きさではない**

| 検定 | 統計量 | p |
|---|---|---|
| B vs A（3着内・LR） | ΔlogL **+5.993** / χ²=11.99 df=3 | **0.0074** ** |
| 指数3変数の同時検定（3着内・**クラスタ頑健Wald**） | χ²=**8.15** df=3 | **0.043** * |
| B vs A（1着・条件付きロジット LR） | ΔlogL +0.964 / χ²=1.93 df=3 | 0.588 |
| `tsi_hi_z` 係数（3着内） | +0.3025 (SE 0.1808) | 0.094 . |

市場ベースラインを厚くしても（logpm²・市場ランクzを追加）**p=0.0074 のまま**残る＝「市場の残差を拾っているだけ」ではない。
**しかし** leave-one-day-out の増分は 930頭で **oos logL +0.46 / Brier −0.00092** ＝ 実質ゼロ。
1着（＝勝ち順）にはまったく効かない（p=0.59）。

→ **統計的には境界域（p≈0.04〜0.007）、実務的な予測改善は無視できる大きさ。**
　 「オッズ抜きで市場を上回るのは不可能」（RULES.md §V4）を覆すものではない。

### 3. 実務ルール「調教Cの馬をモデル1位・2位から外す」— **採用しない**

| | 点数 | 単的中 | 複的中 | 単回収 | 複回収 |
|---|---|---|---|---|---|
| ベースライン（全点買い） | 154 | 24.0% | 50.6% | 87.4% | 82.0% |
| **C除外後** | **133** | 26.3% | 50.4% | **97.6%** | **82.7%** |
| 差 | −21 | +2.3pt | **−0.3pt** | **+10.2pt** | **+0.7pt** |

見送り: 2点とも残る **59R** / 1点だけ残る **15R** / 全部見送り **3R**（全77R）。
※ C+D除外はまったく同じ結果（モデル1位・2位に D評価の馬は1頭も入らなかった）。

**単回収 +10.2pt は採用根拠にならない。理由:**
- 除外される C の点は **n=21（<30 の参考値）**。単勝的中は **2本のみ**。
- 市場が織り込んだ期待1着数 **4.4** に対し観測 **2**。Poisson二項の厳密片側 **p=0.142** ＝ **有意でない**。
- 3着内は逆に期待 **9.7** に対し観測 **11**（p=0.351）＝ **Cは市場予想を上回って複勝圏に来ている**。
- **Ver.100 が実際に買う複勝／ワイド／三連複の側では効果がほぼゼロ（+0.7pt、複的中は −0.3pt で悪化）。**
- 仮説（Cを外す）と検証がまったく同じ標本＝独立検証ではない。

## 検証設計

### レース内相対化と頭数の吸収

すべての特徴量をレース内で正規化した。

- **市場**: `1/オッズ` をレース内で正規化した implied win prob（控除率を除去）。回帰には `log(implied)` を投入。
- **タイム指数**: 「最高」「5走平均」をそれぞれ**レース内 z-score**。欠測は 0（＝レース平均）＋欠測ダミー。
- **1着モデル**: **条件付きロジット**（race を層とする McFadden choice model）。レース内 softmax なので**頭数は構造的に吸収**され、切片も race 固定効果も不要。
- **3着内モデル**: プールドロジット ＋ `log(頭数)` ＋ **race クラスタ頑健SE**。3着内のベースレートが `3/n` である点を `log(n)` が吸収する。

### 識別上の処理（ここを誤ると偽の有意が出る）

| 問題 | 処理 |
|---|---|
| 調教評価が**全頭欠測のレース 6R (78頭)** | レース内で定数＝条件付きロジットでは層に完全吸収され調教の情報を1bitも持たない。A/B/C を同一標本で比較するため回帰から除外 |
| 一部の馬だけ欠測 **4R (6頭)** | 欠測馬は 1着0/3着内0 で完全分離し、欠測ダミー係数が識別されない（実質その馬を落とすのと同じ）。→ 回帰は「全頭の調教評価が観測されたレース」に限定 |
| 調教D: **n=19 / 1着0** | 完全分離。1着モデルでは D を C に統合（`grade_CD`） |
| CSV の**完全重複行 45 行** | (race_id, 馬番) で重複除去（値の衝突 0 件） |

**回帰の共通標本: 67レース / 930頭（1着68・3着内201）**
**記述統計と実務判定: 77レース / 1071頭（1着78・3着内231）**

**`grade_C` の95%CI は log-odds で −0.37〜+0.47。複勝確率にすると概ね ±7pt。**
「C の複勝率が 7pt 以上下がる」ような効果は棄却されるが、それより小さい効果は否定も肯定もできない（第6章）。

### 2-5. 頑健性 — 市場ベースラインを厚くしても結論不変

`logpm` に加えて `logpm²` と市場ランクz を投入した「リッチな市場」A' を基準にしても:

| 目的変数 | B vs A' | C vs B' |
|---|---|---|
| 1着 | ΔlogL=+0.908 χ²=1.82 **p=0.612** | ΔlogL=+1.085 χ²=2.17 **p=0.338** |
| 3着内 | ΔlogL=+5.999 χ²=12.00 **p=0.0074** | ΔlogL=+0.136 χ²=0.27 **p=0.965** |

指数の3着内への増分は市場の定式化を厚くしても残る（＝市場の残差の拾い直しではない）。
**調教は何をしても p≈0.96。**

## 5. null検定 — 調教評価をレース内でシャッフル ×1000

2種類の null を回した。

- **null-1**: レース内で自由にシャッフル（評価と市場の相関を**壊す**）
- **null-2**: レース内の implied確率**3分位ブロック内**でのみシャッフル（評価と市場の相関を**保存**＝交絡を残したまま「評価の中身」だけ消す。**こちらが本命**）

| 統計量 | 観測 | null-1 平均±sd | null-1 p | null-2 平均±sd | null-2 p |
|---|---|---|---|---|---|
| LRχ² C vs B（1着） | 1.860 | 1.970 ± 1.827 | 0.436 | 2.032 ± 2.044 | 0.395 |
| LRχ² C vs B（3着内） | 0.280 | 3.042 ± 2.528 | **0.964** | 2.409 ± 1.862 | **0.952** |
| C除外による複勝回収率の改善(pt) | +0.694 | −4.027 ± 4.585 | 0.137 | −2.236 ± 2.727 | 0.143 |
| 除外されるCの点の**複勝**回収率（低いほど良） | 77.62 | 90.29 ± 9.38 | 0.091 | 93.19 ± 13.81 | 0.136 |
| 除外されるCの点の**単勝**回収率（低いほど良） | 22.86 | 90.44 ± 19.54 | **0.0010** | 94.02 ± 29.66 | **0.0030** |

### 偽陽性率（名目5%の χ² 臨界値に対する null分布の超過率）

| | 1着 (df=2, 臨界値 5.99) | 3着内 (df=3, 臨界値 7.81) |
|---|---|---|
| null-1 | 3.6% | 5.6% |
| null-2 | 5.4% | 1.6% |

**名目5%と大きく乖離していない＝この標本サイズでも漸近χ²近似は許容範囲。**
つまり第2章の p値は、偽陽性を過小評価しているわけではない。

### 単勝回収率の p=0.003 をどう読むか

これは**本検証で唯一「有意」に見えた統計量**である。honest に扱う。

1. **着度数ベースの検定と結論が食い違う。** 同じ C の点について、1着数は期待4.4に対し観測2で **p=0.142（[4-b]）＝有意でない**。
   着度数は回収率より統計的に効率的（分散が小さい）。回収率だけが極端に見えるのは、**当たった2本がたまたま短オッズ**だったため。
2. **交絡を無視した null-1 の p値（0.0010）は有意性を過大評価**している。交絡を保存する null-2 では分散が広がり（sd 19.5→29.7）
   p は 0.0030 に後退する。
3. **多重比較**: 本検証では10個の permutation 統計量を見ている。うち1つが p<0.01 になるのは驚くべきことではない。
4. **仮説と検証が同一標本**。「C を外す」という仮説はこの77レースの観察から生まれており、独立検証ではない。
5. **決定的に、Ver.100 が実際に買う券種（複勝・ワイド・三連複＝3着内の並び）では効果がゼロ。**
   複勝回収の改善は +0.7pt（p=0.137〜0.143）、複勝的中はむしろ **−0.3pt で悪化**。

→ **単勝の回収率だけを根拠にルールを実装するのは、まさに RULES.md が禁じている「部分集合のROIで勝てると言う」パターン。採用しない。**

## 6. サンプルサイズと検出力の限界 — 「無い」と言えるのはどこまでか

**標本: 77レース / 1071頭 / 開催日 6日（回帰は 67レース / 930頭）。クラスタ単位で見れば実効的には n=6。**

| 項目 | 値 |
|---|---|
| 素の B(n=604) vs C(n=351) 複勝率差の標準誤差 | 2.59pt |
| 検出力80%(両側5%)で検出できる最小差（交絡なしの単純比較でも） | **7.3pt** |
| 実際の素の差（市場交絡込み） | 11.5pt |
| 市場を条件にした `grade_C` 係数 | +0.0491 (SE 0.2157) |
| 検出力80%で検出できる最小 log-odds | **0.604**（オッズ比 1.83） |
| 複勝確率で言うと | 21.6% → **13.1%（−8.5pt）以上**の効果でなければ検出できない |

### したがって本レポートが言えること／言えないこと

**言えること**
- 「調教C は複勝確率を **8.5pt 以上**押し下げる」という主張は、この標本で**棄却される**。
- 粗い分析が見た **11.5pt の差は、市場オッズとの交絡でほぼ全量説明できる**。
- 市場を条件にした調教評価の点推定は **ゼロ近傍（+0.05 log-odds、複勝で +0.6pt）**、95%CI は概ね **±7pt**。

**言えないこと**
- 「調教評価に情報が**まったく**無い」とは言えない。**±7pt 未満の効果**は否定も肯定もできない。
- 検出するには標本を数倍にする必要がある（クラスタ n=6 では開催日レベルの変動も吸収できていない）。
- タイム指数の 3着内効果（Wald p=0.043）が本物かどうかも、この標本では確定できない。
  out-of-sample で消える以上、**現時点で運用に載せる根拠にはならない**。

## 7. 運用への反映（提案）

1. **調教評価(SABC) を予想スコアやフィルタに入れない。** 市場を条件にした増分がゼロで、
   入れると AIC・oos logL・oos Brier がいずれも悪化する。
   `params.json` の較正やパターン条件に SABC を追加しない。
2. **「調教C を買い目から外す」ルールは実装しない。** 複勝側で効果ゼロ、単勝側の効果は着度数検定で否定される。
3. **タイム指数は現行どおり「取れたら使う補助情報」に留める。**（`fetch_race.py --tsi` の扱いを変えない。）
   3着内への弱い増分はあるが oos ではほぼ消えるため、α を上げる根拠にならない。
4. **データ収集の注意**: 8月の6開催日のうち **6レースは全頭の調教評価が欠測**、4レースは一部欠測。
   欠測はレース単位でまとまって発生しており、ランダムではない。今後この列を使うなら欠測パターンの記録が必要。
5. **RULES.md §V4「オッズ抜きで市場を上回るのは現時点で不可能」を、本検証は追加のデータで裏付けた。**
   プレミアム調教評価はその例外にならない。
