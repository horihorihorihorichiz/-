### 読み方 — Ver.99.27 の配点が外していた3か所

1. **NSI（クラス実績）が最大の過小評価。20点 → 43〜121点。**
   特に芝L（≥1800m）で121点。長い距離ほど「どのクラスで通用したか」が効く。
   Ver.99.27 は NSI を Tier別 25/20/15 で頭打ちにしているが、実データはその2〜6倍を要求している。

2. **TAS（道悪適性）は大幅な過大評価。15点 → 1〜6点。**
   道悪実績は、市場が既に織り込んでいる分を差し引くとほぼ残らない。
   ※ 馬場そのものは依然として必須（同一ルールで良148%/道悪51%）。
     効かないのは「その馬の道悪実績で加点すること」であって、馬場を見ることではない。

3. **WAS（斤量差）は符号が逆。15点 → −0〜−9点。**
   軽い馬に加点するルールは、Ver.99.27 の形では**害になっている**。
   実運用では 0点（＝使わない）に落とすのが安全。

4. LTS（上がり）と FSI（枠×脚質）はほぼ妥当。ただし LTS の条件差が大きい
   （芝L 58点 ⇔ ダS 16点）。Ver.99.27 は VG別に 30/25/20/15/15 としているが、
   実データが要求するのは **VGよりも距離と芝ダ**の差。

## ⚙️ 加点方式について（測定して**不採用**）

「加点方式を入れたらいける」を3通り試して、**3通りとも棄却**した。記録として残す。

| 方式 | 結果 |
|---|---|
| ① 条件（VG×距離帯）ごとに加点を実測 | MINEで決めた点数の符号が未知2期間でも一致するのは **62/215 = 28.8%**（まぐれ25%） |
| ② 加点の点数をCEMでROI最大化探索 | MINE ROI 67.7→**172.3%**（在サンプル）だが VALIDATE 55.9% / CONFIRM 84.1%。<br>MINEの上昇は 実+104.6pt に対し**偽データ+116.2pt**。偽物の方が高い |
| ③ 加点を全体1本で実測して入れる | 加点を強くするほど3着内率が単調に低下（53.4→52.4%）。**偽の加点の方が成績が良い** |

**効かない理由（これが重要）**:
加点ルールは「複勝ROIの残差」＝**市場が安く売っている型**から作った。
つまり持ち上げているのは「速い馬」ではなく「安い馬」。だから的中率が落ちる。
払戻の増加が的中率の低下を上回れば勝てるが、それは控除率の壁そのもので越えられない
（→ `WALL_20260821.md`）。

**運用上の結論: 加点は入れない。配点の付け直しだけを採る。**

## ⚙️ STEP0〜STEP10（Ver.99.27 から変更なし）

以下は Ver.99.27 のまま。この文書では再掲しない。
- STEP0 CSI/DSI 母数判定（有効過去走 ÷ 頭数×9）
- STEP1 脚質判定 5段階手順（新聞表記 → 先差🔄 → 差先🔄 → 隠れ逃げ → 逃げ序列）
- STEP2 展開判定（0スロー〜4ハイ・単騎逃げ・枠順系補正・展開マトリクス5.10版）
- STEP3 LTS算出（P/B/C/D補正）
- STEP4 TSI算出（距離係数）
- STEP5 FSI（枠順×脚質マトリクス＋同枠帯繰上）
- STEP6 Bonus（TFB/SSC）
- STEP7 他コンポーネント（DSI/CSI/NSI/WAS/TAS/HCS/NRJA）
- STEP8 S2_Raw → WAvg（展開乗数）
- STEP9 Power → Final_PWin（30%キャップ）
- STEP10 ランク分け + Case判定

**変わるのは STEP8 の合算だけ**:

```
Ver.99.27:  S2_Raw = TSI + LTS + FSI + Bonus + DSI + CSI + NSI + WAS + TAS + HCS + NRJA
Ver.100  :  S2_Raw = Σ ( 各成分のレース内zスコア × 上表の配点 )
            ※ 各成分を「そのレースの出走馬の中で」平均0・SD1に直してから配点を掛ける。
              上表の生スケール点数は、この計算を Ver.99.27 の点数感覚に翻訳したもの。
WAvg = S2_Raw × 展開乗数[判定展開][脚質]   ← ここは変更なし
```
