## 0. 結論（先頭）

**保有データ（過去9走レコード）に「市場が織り込んでいない使い残し」は、実弾に載る形では見つからなかった。全体判定=不合格。**

| 段 | 基準 | 結果 |
|---|---|---|
| 総試行 | 27特徴 × 2目的 | **54** |
| MINE 通過 | `\|z\| ≥ 2.5` | **9**（偶然期待 **0.67**） |
| VALIDATE 通過 | 同符号 かつ `\|z\| ≥ 2.0` | **3**（偶然期待 **0.20**） |
| CONFIRM 通過 | 同符号 かつ `\|z\| ≥ 2.0` | **0** |
| バッチ判定（VAL ≥ 3×偶然期待） | 3 ≥ 0.61 | **形式上OK**（ただし下記のとおり中身は無い） |
| **V9 の α（3フォールド連続 >0）** | 3連続 | **連続正の最大 = 1 → 不合格** |

**中身（数字は §3〜§5 で全部出す）:**

1. **信号は実在する。ただし極小で、しかも「市場が過大評価している側」に出る。**
   MINE で有意だった9件のうち **7件が負の係数**＝「その特徴が良い馬ほど、市場が付けた確率より当たらない」。
   最大の増分対数尤度は `iv_match_fin|top3` の **ΔLL=+9.24 nats / 92,799行 = 1行あたり0.0001 nats**。
   実務的にはゼロと同義（市場のlog-odds1本が持つ情報量の1万分の1オーダー）。
2. **独立2期間を両方通った特徴はゼロ。** VALIDATE を通った3本（`rebound_flag|top3` / `fin_sd|top3` /
   `baba_match_fin|win`）のうち、CONFIRM で符号が保たれたのは `baba_match_fin|win` の1本だけで、
   それも `z=-1.51` と基準未満。他2本は **符号が反転**した。
3. **V9（V3 + 通過3特徴）は市場に何も足さない。** 6フォールド中 **5フォールドで α<0**。
   V3単体の α も同じく5フォールドで負であり、**α(V9) − α(V3) の平均は −0.0046**（3フォールドで負・3フォールドで正）。
   新特徴の寄与は符号すら定まらない。
4. **「使い残し」の正体は、大半が既存特徴の言い換えだった。** MINE通過9件の内訳は
   間隔適性2・距離適性2・馬場適性1・頭数適性1・クラス経験1・復調1・着順ムラ1。
   いずれも既存の `days_log` / `dist_chg` / `wet_apt` / `field_chg` / `class_fin` / `fin_best2` と
   同じ情報源を別の切り口で見たものであり、独立期間へ持ち越された量はゼロだった。

## 4. 多重比較の判定

| 段 | 通過数 | 偶然期待 | 判定 |
|---|---|---|---|
| MINE | **9** | 54 × P(\|z\|≥2.5) = 54 × 0.01242 = **0.67** | 偶然を大きく超える |
| VALIDATE | **3** | 9 × P(同符号 & \|z\|≥2.0) = 9 × 0.02275 = **0.20** | 3 ≥ 3×0.20=0.61 → 形式上OK |
| CONFIRM | **0** | 3 × 0.02275 = **0.07** | ゼロ |

事前登録のバッチ判定式では VALIDATE 段が「OK」になるが、**これを勝ちと呼ばない**。理由:

1. **CONFIRM がゼロ**。VAL を通った3本のうち2本（`rebound_flag`, `fin_sd`）は CONFIRM で
   **符号が反転**し、アウトオブサンプルΔLLも **負**（−3.12 / −1.61）になった。
   一期間だけの再現は「MINEで拾った癖が3か月だけ続いた」で説明がつく。
2. 効果量が小さすぎる（§3-1）。仮に本物でも、控除率20〜25%を埋める向きに使える大きさではない。
3. **符号が「市場の過大評価」側に出ている**（MINE通過9件中7件が負）。これは
   「モデルに足せば強くなる情報」ではなく「市場が少し買い被る癖」であり、単勝1点で取るには小さすぎ、
   買い控えにしか使えない。

## 5. V9（V3 + 通過特徴）の α

事前登録の作成条件「MINE と VALIDATE の両方を通過した特徴が1本以上」を満たしたため作成した。
搭載した特徴 = **`baba_match_fin` / `fin_sd` / `rebound_flag`（3本）**。

- 一段目 = 条件付きロジット（レース内softmax・1着尤度・L2=1e-3）。
  入力は `fit_v2.build_row(..., v4=False)` の V3行（27特徴 + field = 28列）＋ 上記3本のレース内z。
- 学習は月次ウォークフォワード（評価月より前のレースのみ）。評価対象 7,524R。
- 二段目 `u = α·log p_model + β·log p_market` を評価月ごとに推定。**α>0 = 市場への付加情報あり**。

| フォールド | 学習R | 評価R | α(V3) | α(V9) | 差 | β(V9) | NLL 市場 → 混合 |
|---|---|---|---|---|---|---|---|
| 202603 | 6,049 | 277 | +0.0316 | **+0.0078** | −0.0239 | +0.963 | 1.9481 → 1.9476 |
| 202604 | 6,326 | 250 | −0.2863 | **−0.3024** | −0.0161 | +1.198 | 2.0088 → 1.9953 |
| 202605 | 6,576 | 307 | −0.0846 | **−0.0825** | +0.0022 | +1.129 | 1.9123 → 1.9096 |
| 202606 | 6,883 | 221 | −0.2698 | **−0.2876** | −0.0179 | +1.194 | 1.9553 → 1.9442 |
| 202607 | 7,104 | 246 | −0.2096 | **−0.1857** | +0.0239 | +1.240 | 1.8710 → 1.8637 |
| 202608 | 7,350 | 174 | −0.2775 | **−0.2732** | +0.0043 | +1.248 | 1.9153 → 1.9041 |

- **α(V9) > 0 は 6フォールド中1つだけ**（202603 の +0.0078）。**連続正の最大 = 1 → 一次不合格**。
- α(V3) も同じく5フォールドで負。**差の平均 = −0.0046**（負3・正3）で、
  **新特徴の寄与は符号すら定まらない**。
- 混合のNLLが市場単独よりわずかに小さいのは **α<0（モデルを逆向きに使う）+ β≈1.2（市場のlog-oddsを
  少し強める）** の効果であり、モデルが情報を足しているのではない。各フォールド n=174〜307Rの
  2パラメータ当てはめで、しかも改善幅は 0.001〜0.013 nats。**買いに使える量ではない**。

## 7. 「保有データに使い残しはあったか」への回答

**あるにはあったが、市場より先に知っている量ではなかった。**

- 現行28列（27特徴+field）が過去走から取っていない量は確かに存在した（§2の27本すべて実装可能で、
  被覆41.5〜89.6%）。うち9件は MINE 6,713R で統計的に有意だった。
- しかしその信号は **(a) 極小**（最大でも1行あたり 0.0001 nats）、**(b) 独立2期間を越えない**（CONFIRM 0/3）、
  **(c) 符号が市場の過大評価側**、という3点で「買える情報」ではない。
- V4/V5/V7/V8・条件採掘・アンサンブル・プール間裁定・3着内特化・タイム指数・調教・レビュー文・南関市場に続き、

  控除率を超える道は市場の価格ズレを突くしかない」という結論は、今回の測定でも覆らなかった。

## 8. 限界（正直に）

1. **単独検定である。** 27本を同時に入れた場合の交互作用や、既存28列との条件付き寄与は測っていない
   （V9 が実質その役割だが、載せたのは通過3本のみ）。組合せ探索は多重比較を爆発させるため
   事前登録の範囲外とした。
2. **市場オッズは確定オッズ**（発走直前の最終値）。実運用の締切前オッズとは僅かにずれる。
   これは既存の全検証と同じ条件。
3. **斤量・馬体重の履歴は台帳の横断結合**（被覆81.2% / 66.6%）。各馬の初出走・地方戦は None。
4. **上がりの「同レース内相対順位」は作れなかった**（§2の注記）。標準上がり残差での代替は
   レース固有の展開差を吸収しきれない。
5. **CONFIRM の n**（727R / 9,605頭）は3か月分しかない。ここでの非通過は「効果が無い」ことの
   証明ではなく「あっても検出できる大きさではない」ことの証明である。n<30 の段は無い（全段で十分）。
6. **`vg` は使っていない**（実測91%が2固定で信用できないため）。ペース記号 `pace` は
   紙面表記そのままで、レースの実ラップではない。
7. 検証中に別プロセスの収穫が走り台帳が増えていた（§1-1）。通過集合は4回の再構築で同一だった。
