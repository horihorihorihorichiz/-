## 結論（先に要点）

1. **腕2（CORNER合格4特徴の追加）が今回の主役で、明確に合格**。B-sd16（芝ダ×距離帯6群 + corner4）は
   第1弾までの最良 B-sd を **VALIDATE ΔLL/R +0.150 / CONFIRM +0.105** 上回り、CONFIRMで
   複勝1点 54.7%（現行比 **+5.0pt**）・単勝22.8%まで的中率を押し上げた。効いているのは
   **spd_res（条件補正時計、z重み+0.22）と mgn_abs（着差の絶対値、z重み−0.30）**の2本で、
   wide4c・pos_gainはほぼゼロ。CORNER_REPORTで「V3経由では届かない」とした4特徴は、
   **Ver.99.27成分空間に直接載せれば並べる力になる**ことが確定した。
2. **腕1（B-sd+B-tier加法結合）も合格ライン通過**（B-sd単独比 ΔLL/R VAL +0.0030 / CONF +0.0192）。
   ただし改善幅は腕2の1/10以下で、B-sd16が使えるなら出番はない。
3. **腕3（月次ローリング再学習）は効果ほぼゼロ＝運用に組み込む価値なし**。
   rollB-sdでΔLL/R VAL +0.0007 / CONF +0.0011、rollAはCONFIRMでむしろ−0.0005。
   **第1弾で見えたCONFIRM減衰（+0.14→+0.045）はデータ鮮度の問題ではない**（毎月学び直しても消えない）。
4. **腕4（例外除外×学習配点）は未達**。除外後もモデル買いは市場複勝2点ベースラインをROIで上回れない
   （レース単位的中も モデル2点88〜90% vs 市場2点94〜95%）。
   **ROI 100%超が1セルだけ出た: 学習sgap版・CONFIRM・三連複1点 100.7%（17的中/148R）**。
   ただしVALIDATEは76.5%で2期一致せず、事前登録の趣旨どおり**採用しない**。
5. 総合: **現時点の最良配点 = B-sd16**（全期・LL/的中率とも最良）。それでも控除率の壁は
   越えない（腕4含め、両期一致でROI100%超の買い方は今回も存在しない）。

## 3. 腕別の判定

### 腕1: B-sd × B-tier 加法結合 — **合格（ただし腕2に吸収される）**
- 変種はMINE内部でsimple-sum選択（backfitとの差は va20 で 0.0003 と無視できる規模）。
- 判定基準「B-sd単独を両期ΔLL/Rで上回る」: **VAL +0.0030 ✓ / CONF +0.0192 ✓**。
- 券種は混在: CONFで単勝 22.2%/80.8%（B-sd比 +0.5pt/+0.2pt）だが、三連複ROIは 50.7%（−13.5pt）に低下。
  LLの改善幅が小さく、B-sd16がある以上こちらを採る理由はない。

### 腕2: CORNER4特徴の追加成分化 — **合格（今回の最大の成果）**
- 判定基準「追加なし版を両期ΔLL/Rで上回る」:
  armA16 vs armA = **VAL +0.1405 ✓ / CONF +0.0986 ✓**、B-sd16 vs B-sd = **VAL +0.1501 ✓ / CONF +0.1047 ✓**。
  この改善幅は第1弾の全成果（現行→B-sd）と同等以上が上乗せされた形。
- 学習重み（zスケール・全体1本wg16）: spd_res **+0.2232** / mgn_abs **−0.3032** / wide4c +0.0297 /
  pos_gain +0.0080。既存成分は総じて縮む（tsi 0.221→0.132、dsi 0.334→0.238 等）＝
  **新2特徴が既存成分の情報の一部を代替しつつ、独自情報を足している**。
- mgn_absの符号について: CORNER単独検定（市場条件付き・win）では正だったが、成分と同時に入れると
  **負（着差が大きい馬ほど減点）**。「大差で勝ち負けしてきた馬」の情報はTSI/NSIが既に持っており、
  残る成分は「着差が荒れる＝不安定」のマイナス面、という解釈で矛盾はない。
- B-sd16群別のcorner重みも安定（spd_res 0.18〜0.30で全群正、mgn_abs −0.21〜−0.40で全群負。
  ダ短距離ほどspd_res大、芝長距離ほどmgn_abs大）。
- 注意: 単勝・複勝1点の**ROI**はVALIDATEで悪化する（単勝69.2%、複1 79.0%）。並べる力（的中率・LL）が
  上がるほど人気サイドに寄るという第1弾と同じ現象で、合格ラインには的中率側（複2 VAL+2.9pt、
  複1 CONF+3.5pt 対B-sd）で達している。

### 腕3: 月次ローリング再学習 — **効果なし（未達）。定期再学習は組み込まない**
- rollA: VAL +0.0002 / **CONF −0.0005**（固定armA比）。rollB-sd: VAL +0.0007 / CONF +0.0011。
- 的中率も複勝1点でVAL −0.2pt〜CONF +0.4ptの範囲で、判定基準「固定版より改善」を実質満たさない。
- 月別LL/R（rollB）: 202603 −6.660 / 04 −6.810 / 05 −6.723 / 06 −6.871 / 07 −6.676 / 08 −6.706。
  月ごとの上下（202604・202606が悪い）は学習データが増えても消えない。
- **含意: CONFIRM期の改善幅縮小は「配点が古くなった」せいではなく、その月のレース構成・展開の
  当たりにくさ自体**。毎週・毎月の再学習を運用に足すコストに見合う利得はない（年1回程度の
  再学習で十分、という第1弾の「定期再学習が前提」をより弱い頻度に修正する）。

## 4. 何が確定したか / 次に効きうること

1. **採用候補はB-sd16**（芝ダ×距離帯6群 + spd_res/mgn_abs。wide4c/pos_gainは実質不要）。
   本番に載せるには (a) 予想時にcorner系特徴（過去5走の通過順・タイム・着差）を fetch_race 経路で
   作る実装、(b) calc.py側のレース内標準化＋群別重みの機構、が必要。本件は測定のみで未改修。
2. 並べる力の限界も再確認: 的中率がどれだけ上がっても（複1 CONF 54.7%）、両期一致の
   ROI100%超は出ない。**「買う点を選ぶのはエッジ（市場の価格ズレ）」という既定エンジンの
   役割分担は不変**。B-sd16の使い道は α_place 側の順位付け精度向上。
3. 月次再学習は不要（腕3）。再学習は特徴・構造を変えた時だけでよい。
4. 例外除外との合成は「市場並びの複勝2点」を超えられず打ち止め（腕4）。この路線の残る手は
   EXCLUSION_REPORTの結論と同じく「除外の後にエッジで買う点を選ぶ」形のみ。
