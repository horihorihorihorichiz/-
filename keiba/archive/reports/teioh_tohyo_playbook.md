# 帝王賞 投票プレイブック（ローカル /chrome 用ハンドオフ）

このファイルは「ローカルのClaude Codeアプリ + /chrome（あなたのログイン済みChrome）」で
netkeiba経由投票を半自動入力するための手順書。**リモート環境では/chromeが使えないため、ここで指示だけ用意した。**

## 実行ルール（厳守）
1. **ログインの自動化はしない。** netkeibaが未ログイン／認証（2段階・画像）を出したら、**そこで停止してユーザーに操作を渡す**。
2. **入力（式別・馬番・金額）まで**を /chrome で行う。
3. **最終の「購入・投票確定」ボタンは押さない。** 入力完了後に一旦停止し、ユーザーに確認させる。金が動く最後の操作はユーザーが押す。
4. 入力後、**式別・点数・各金額・合計を画面から読み上げ**、下の表と一致するか照合して報告する。

## netkeiba 経由投票の操作手順（/chrome）
1. オッズページを開く: `https://nar.netkeiba.com/odds/index.html?race_id=202644070111`
   - 未ログインなら停止 → ユーザーにログインしてもらう。
2. 式別タブを切り替えながら買い目を選択（同じ式別はまとめて）:
   - 単勝: `?type=b1&race_id=...` → `[cart-item$='_b1_c0_1']`, `[cart-item$='_b1_c0_11']` をクリック
   - 馬連: `?type=b4&race_id=...` → `_b4_c0_1_5`, `_b4_c0_10_13`, `_b4_c0_1_2`, `_b4_c0_5_11`
   - ワイド: `?type=b5&race_id=...` → `_b5_c0_1_10`, `_b5_c0_1_2`, `_b5_c0_1_6`, `_b5_c0_10_11`, `_b5_c0_11_13`, `_b5_c0_1_11`
   - ※馬番は昇順（小さい方が先）で末尾が決まる。
3. 「投票する／選択した買い目を登録」ボタンで投票（カート）画面へ進む。
   - ここで連携先（SPAT4等）のログイン/認証が出たら**停止してユーザーに渡す**。
4. 各買い目の金額欄に上表の金額を入力。
5. **合計が20,000円**になっているか、式別・馬番・点数・各金額を画面から読み上げて上表と照合。
6. 一致を報告し、**購入ボタンは押さずに停止**。ユーザーが最終確認して購入。

## 不一致・不明時
- 選択がズレる／金額欄が見つからない場合は、その画面のスクショかDOMを確認してセレクタを特定してから入力を続行。
- オッズは時々刻々変わるため、想定オッズ列は参考値。**買い目（式別・馬番）と金額**が正であることを最優先で照合する。
