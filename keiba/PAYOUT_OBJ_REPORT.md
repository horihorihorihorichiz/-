## 0. 結論（先頭）

**不合格。目的関数を「勝つ馬」から「払戻」に変えても市場は超えられない。**

| 事前登録の判定 | 基準 | 実測 | 判定 |
|---|---|---|---|
| ① 全レース買い 単勝flat ROI | VAL ≥95% **かつ** CONF ≥95% | **10モデル中 0本**。最良は M3-l2 の VAL 98.4%／CONF 85.6% | **不合格** |
| ② EV≥1.2 買い（実オッズ） | VAL n≥40 ROI≥110% ∧ CONF n≥25 ROI≥105% | 単勝 最良 74.5%（VAL）／複勝 最良 64.4%（CONF）。**110%を超えたセルは1つも無い** | **不合格** |
| ④ 見送り基準（追加軸） | 同① | 164セル中 **8セル通過（4.9%）**。ヌルスイープの偶然通過率 **4.45%**、偶然期待 7.3セル | **偶然と区別できない** |

### 核心（本報告の一番大事な数字）

**平均人気を 1.88 → 8.19（4.4倍）まで動かしても、単勝回収率は 70〜93% の帯から出ない。**

| | 人気寄りモデル（平均人気≤3・7本） | 穴寄りモデル（平均人気5.6〜8.2・3本） |
|---|---|---|
| 単勝的中率 | 22〜27% | 7.1〜12.7% |
| 平均配当（的中時） | 280〜335円 | 552〜1,307円 |
| **単勝ROI（VAL+CONF）** | **74.9〜80.4%（平均76.9%・sd 1.8pt）** | **70.2〜92.8%（平均80.3%・sd 11.5pt）** |

10モデル全体で ROI 平均 **77.9%**・sd **5.9pt**。JRA単勝の払戻率（控除率20%）= **80%**。
**「的中率 × 平均配当」の積は控除率の壁に貼り付いたまま動かない。**
穴寄りモデルの ROI が散らばって見えるのは実力差ではなく**分散**で、
最良の M3-l2（92.8%）のブートストラップ95%CIは **[49.9, 153.1]** — 80%と区別できない。

**→ 「重み配分（人気寄り/穴寄り）の最適化は無効」の直接証拠。配分側の道は閉じた。**

さらに **M5（28特徴の線形結合の重みを、MINE期の単勝flat ROI で直接・全力で過学習させたもの）が
MINE期で到達できた上限は 101.1%** だった。**探索し放題の in-sample ですら辛うじて100%**であり、
その重みを VALIDATE に持って行くと **57.7%** に崩れる。配分探索の天井そのものが低い。

### 1-1. 実行前に確定した仕様（PROTOCOL §2-1・成績は見ずに `best_iteration` だけで判断）

スモークテストで **M2（重み付き binary）は1回で停止**、**M3-l2/M4-l2（L2回帰）は2回で停止**した。
どちらも「重み／外れ値がごく少数の高配当行に支配され、早期停止の指標が壊れる」ためで、
そのままでは定数モデルになり実験にならない。そこで**実行前に**次を確定した:

- binary（M2/M2c）: 学習は重み付き、**早期停止の判定だけ重み無し** logloss
- regression（M3/M4 全変種）: **早期停止の指標は常に `l1`**（絶対誤差）

学習の目的関数（重み・損失）自体は事前登録のまま。変えたのは「いつ止めるか」だけ。
これで全モデルが学習した（初fold の `best_iteration`: M2 799 / M2c 142 / M3-l2 95 / M3-huber 328 /
M3-log 246 / M4-l2 143 / M4-huber 367 / M4-log 541 — いずれも20超）。

### 1-2. M1 の実体

M1（現行V3）は既存WF台帳 `wf_preds_v3ext2.jsonl`（汎用V3 LambdaRank 28特徴）をそのまま使用。
本実験のfold集合と **rid が5,990件で完全一致**することを確認済み（再学習していない）。

### 1-3. 使った損失（明記事項）

M3/M4 は目的変数の分散が極端（ほとんど −100、たまに +数千）。事前登録どおり **3つ全部**を走らせた。

| 変種 | 中身 | 挙動 |
|---|---|---|
| `-l2` | 目的変数そのまま・L2損失 | **完全に穴馬側へ振り切れる**（1位の平均人気 8.0〜8.7・的中率 6〜9%） |
| `-huber` | huber(alpha=100) | **ほぼ人気馬側に戻る**（平均人気 1.9〜2.0・的中率 26〜28%）。M1とほぼ同じ挙動 |
| `-log` | 目的変数を sign·log1p\|v\| に変換してL2 | huber と同様に人気馬側 |

**主判定は事前登録どおり `-huber`。** ただし「回収率を目的にすると何が起きるか」を最も素直に
見せるのは `-l2`（頑健化していない生の払戻回帰）なので、以下では両方を載せる。

## 6. 核心の問い: 「配分をどう変えても積は動かないか」— 数字での回答

**VAL+CONF プール（1,550R）。同じ特徴・同じデータ・目的関数だけを変えた10モデル。**

| model | 平均人気 | 単勝的中% | 平均配当(円) | **単勝ROI%** |
|---|---|---|---|---|
| M4-log | 1.88 | 26.77 | 280 | 75.0 |
| M4-huber | 1.90 | 27.09 | 297 | 80.4 |
| M2c | 1.90 | 26.71 | 288 | 77.0 |
| M1（現行V3） | 1.92 | 26.39 | 290 | **76.5** |
| M3-log | 1.92 | 26.39 | 292 | 77.0 |
| M3-huber | 1.97 | 26.45 | 292 | 77.3 |
| M2 | 2.74 | 22.39 | 335 | 74.9 |
| M5 | 5.60 | 12.71 | 552 | 70.2 |
| M4-l2 | 7.93 | 7.22 | 1078 | 77.9 |
| M3-l2 | 8.19 | 7.10 | 1307 | 92.8 |

- **平均人気 1.88 → 8.19（4.4倍）。的中率 27% → 7%（1/4）。平均配当 280円 → 1,308円（4.7倍）。**
- **にもかかわらず ROI は 70.2〜92.8%、平均 77.9%、sd 5.9pt。JRA単勝の払戻率 80% の周りに貼り付いている。**
- 人気 vs ROI の相関 r=+0.455 だが、これは**穴側3本の分散が大きいだけ**で、
  人気寄り7本に限れば ROI 74.9〜80.4%・**sd 1.8pt** と完全に一定。
- 上振れして見える M3-l2（92.8%）のブートストラップ95%CI は **[49.9, 153.1]** で 80% を含む。
  M4-l2 は **77.9% [46.0, 121.3]**、M5 は **70.2% [51.6, 95.0]**。**80%と区別できるモデルは1本も無い。**

### 判定: **「配分最適化は無効」は数字で支持された。**

的中率と平均配当は**きれいに逆比例で入れ替わり、積は控除率の壁に固定**される。
配分を人気寄りにも穴寄りにも動かせることは示せた（M2/M3-l2 が実際に動いた）が、
**動かした先で積が改善する方向は無かった**。

さらに強い証拠が **M5** である。M5 は 28特徴の線形結合の重みを、
**MINE期の単勝flat回収率そのものを目的にランダム探索4,000本＋座標降下で全力で過学習させた**もので、
探索し放題・同じデータで評価という最も甘い条件だ。それでも到達点は **101.1%**。
「配分をいじる」という操作の**理論上の天井が、in-sample ですら控除率をやっと超える程度**しかない。
そしてその重みは out-of-sample で **57.7%（VAL）** に崩れた。

## 8. 限界（正直に）

1. **α_place の正（M4-l2）は本物かもしれない**。VAL/CONF/MINE の3分割すべてで正・有意（z=2.7〜6.8）。
   ただし「係数として市場に足せる情報がある」ことと「控除率を超える」ことは別物で、
   同じモデルの複勝flat ROI は M1 より悪い。`PLACE_REAL_ODDS_REPORT.md` §2 と同じ落とし穴なので、
   これを根拠に実弾を張らない。追試するなら**複勝オッズ側にブレンドして買う設計**が必要で、本実験の範囲外。
2. **EV買いの n が巨大すぎる**（4,000〜7,000）。softmax温度較正が裾で甘く、大穴を過大評価している。
   より厳しい閾値や裾の再較正で n を絞る余地はあるが、それは**閾値の後出し探索**になるので今回はやらない。
3. **複勝オッズは下限のみ**（`hist_odds/` の仕様）。複勝EVは保守側に出ている。ただし不合格の幅（40〜65%）に対して
   実払戻/下限の実測倍率 1.19倍では届かない。
4. **M5 の探索空間は線形結合のみ**。非線形な配分（木モデルの重み調整）は試していない。
   ただし M1〜M4 が実質それに当たり、同じ壁で止まっている。
5. **VALIDATE 874R / CONFIRM 676R** は、的中率7%の穴戦略に対しては小さい。だからこそ CI とヌルスイープで判断した。
6. **単勝・複勝のみ**。組合せ券（ワイド・三連複）は本実験の対象外（`PLACE_REAL_ODDS_REPORT.md` で全滅済み）。

## 9. 結論の一文

**「回収率そのものを目的関数にする」は、狙いどおり穴馬に寄ったが、市場は超えられなかった。**
的中率と平均配当は控除率の壁の上を滑るだけで積は動かず、
見送り基準を164通り当てても、実力ゼロの偽モデルと同じ数（8 vs 期待7.3）しか「合格」が出なかった。
**得点配分側の道は、これで閉じたと判断してよい。**
残るのは `MODEL_V4_RESULT.md` が既に指していた方向 —— **市場の価格ズレを突く（オッズを入力に使う）** —— だけである。
