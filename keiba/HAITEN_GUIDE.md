# 堀川システム設計図 — 点数の出し方と配点表

> 数値は `hori52_w.json` から直接生成（2026-08-23版・台帳13,194R）。
> 実効配点＝**平均絶対値を30に揃えたスケール**。生の重みは層ごとに絶対値が違い、そのままでは比較できない。
> 正＝加点方向 / 負＝減点方向。

## 1. 点数の出し方（5手順）

| # | 手順 | 中身 |
|---|---|---|
| 1 | 16成分を1頭ずつ計算 | 過去9走・今回条件・枠・斤量・馬場から算出（定義=`calc.py`）。脚質確定と展開（ペース5段階）を先に決めてから展開乗数が乗る |
| 2 | レース内でZ正規化 | 各成分を「そのレースの出走馬の中での偏差」に直す＝`Z16`。**点数は同一レース内でしか比較できない** |
| 3 | 配点を2層で合成 | `w = 0.5 × w52[場+芝ダ+距離帯] + 0.5 × w30[芝ダ+距離帯+クラス]`<br>w52欠落→w30のみ / w30欠落→w6[芝ダ×距離帯] / それも無ければ全体1本 |
| 4 | 内積＝得点 | `得点 = Z16 · w`。同点の並べ替えは (−得点, −WAvg, 馬番)。表示は見やすさのため100前後に平行移動 |
| 5 | PWinと形に変換 | PWin=得点のsoftmax（上限30%クリップ後に再正規化）。形= `g12=(1位−2位)/SD`, `g23`, `g34` → 1強/2強/3強/階段/混戦 |

**⚠PWinの取り扱い（2026-08-23実測）**: PWinは市場より一貫してフラットで、単勝1〜3倍帯を19.2%（実測38.0%）と大幅に過小、20〜50倍帯を+2.8pt過大に見る。条件付きロジットでは市場に対する上乗せがゼロ（β=−0.06, t=−2.42）。**PWinは順位付けの副産物として読み、確率の絶対値や期待値計算には使わない。**

## 2. 16成分の意味

| 記号 | 名前 | 中身 |
|---|---|---|
| `TSI` | タイム指数 | 今回条件に近い過去走の最良タイム。距離換算・馬場差で補正 |
| `LTS` | 近走着順 | 最良着順スコア。中央競馬は繰上、条件一致でブースト |
| `FSI` | 脚質×枠 | 芝=内枠有利／ダ=砂被りロジック(差・追は外枠クリーンを高評価) |
| `Bonus` | 実績加点 | 該当実績の数で 0 / 8 / 10 点 |
| `DSI` | 距離適性 | 近3走±200mで掲示板=A → 1年以内 → ±400m の3段階 |
| `NSI` | 格 | クラス実績のグレード(勝ち上がりの水準) |
| `CSI` | コーナー | 通過順の統計。位置取りの安定度 |
| `WAS` | 斤量 | 出走馬プール内での相対斤量。最軽量判定を含む |
| `TAS` | 道悪適性 | 1年以内の稍/重/不の着順から A〜C |
| `HCS` | 条件調整 | 斤量・条件面の微調整 |
| `NRJA` | 間隔 | 前走からの休養日数(ローテ) |
| `展開乗数` | 展開 | ペース5段階(スロー〜ハイ) × 脚質の相性 |
| `spd_res` | 脚の残り | コーナー通過からの失速/持続 |
| `mgn_abs` | 着差 | 着差の絶対量。負の重み＝大差負けを強く減点 |
| `wide4c` | 4角外回し | 4コーナーで外を回した距離ロス |
| `pos_gain` | 位置上昇 | 道中で押し上げた位置の量 |

下4つ（spd_res / mgn_abs / wide4c / pos_gain）は4コーナー通過データから作る後付けの4成分。`mgn_abs`だけ符号が負＝「大差で負けた馬を強く減点する」働き。

## 6. 読み取れること

**全セル共通の骨格**
- **DSI（距離適性）とNSI（格）が二本柱** — どのセルでも最大級の重み（60〜100）
- **mgn_abs（着差）が唯一の大きな負** — −40〜−70。大敗の記憶を強く引く
- **spd_res（脚の残り）が第3の柱** — 44〜60で全セル安定

**セルによる違い（設計上の意味）**
- **TSI（タイム指数）はダートで効き、芝Lで効かない** — ダS 39.6 に対し芝Lはほぼ0。時計勝負のダートと展開勝負の芝長距離の差
- **TAS（道悪適性）もダート寄り** — ダS 25.4 / ダM 23.9 に対し芝は一桁台のセルが多い
- **FSI（脚質×枠）はダートで倍** — ダS 36.0 / ダM 36.0 vs 芝S 21.0。砂被りの有無
- 全体として**芝は展開・CSI寄り、ダートは能力・時計寄り**
