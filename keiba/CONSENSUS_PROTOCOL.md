## 1. 合議の定義（4種・事前確定・後から追加禁止）

模型順位 = 台帳 `order`（得点降順）。tsi順位 = 前走tsi降順（tsiを持つ馬のみで順位付け、同値は馬番昇順）。

| ID | 定義（「一致」の条件） |
|---|---|
| **C1** | モデル1位 = tsi最高の馬 |
| **C2** | モデル上位3頭 ∩ tsi上位3頭 が **2頭以上** |
| **C3** | モデル1位の tsi順位が **3位以内**（緩い一致） |
| **C4** | モデル1位 ≠ tsi1位 **かつ** モデル2位 = tsi1位（1-2位の入れ替え） |

各定義について **一致 / 不一致** の2群に分け、両方を測る（不一致 = tsi有効レースのうち一致でないもの）。

| 軸 | バンド |

| surface | 芝 / ダ |

| tier | 上級(tier<=5) / 1勝(tier6-9) / 未勝利(tier>=10) |

セル = 無条件(1) + 単一条件(21) + 2条件結合(異なる軸のペア・181) = **203セル**。
**3条件以上は禁止**（前回の多重比較破産の再発防止）。

総試行数 = 203セル × 8合議群（4定義×2） × 8券種 = **12,992**（実際に n>=1 で評価できた数も併記する）。

## 4. 3段関門（事前確定・変更禁止）

| 段 | 期間 | 基準 |
|---|---|---|
| MINE | 202409-202602 | n>=40 **かつ** ROI>=120% **かつ** 並べ替え検定 p<0.05 |
| VALIDATE | 202603-202605 | n>=15 **かつ** ROI>=105%（MINE通過セルのみ・1回だけ） |
| CONFIRM | 202606-202608 | n>=10 **かつ** ROI>=100%（VALIDATE通過セルのみ・1回だけ） |

並べ替え検定: セル内MINEレースについて「オッズ/モデル序列(受け手)」と「着順+払戻(出し手)」の
対応をレース間でシャッフル（B=1000, seed=20260817）。着順は市場人気ランク空間にエンコードし、
受け手レースの同ランク馬が的中したとみなして出し手の実払戻で精算する（miner_v2.py と同一手続き）。
p = (1 + #{null ROI >= 観測ROI}) / (B+1)。

**多重比較の判定**: VALIDATE通過数が「偶然期待 = null検定通過数 × 0.05」の **3倍未満なら全体不合格**。
個別セルがどれだけ良く見えても、この判定が不合格なら「買いルールにしない」。
