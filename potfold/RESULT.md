# Pot Fold 勝ち筋の計算

KKPoker の Pot Fold（2026年9月開始）を対象に、「場札3枚を見てから続けるか降りるか」の
基準を計算で求めたもの。勉強用の確率計算であり、自動で打つ仕組みではない。

## 1. 前提にしたルール

- 全員が参加料 a を出す。通常の強制賭け金（SB/BB）はない
- 配られる前の賭けはなく、いきなり場札3枚が開く
- 行動は SB の位置から順。続けるための額は「最初のポット」と同額に固定
- 選択肢は「続ける」か「降りる」の二択、一巡のみ
- 2人以上残れば残り2枚が自動で開き、以降の賭けはない
- 手札は2枚（テキサスホールデム形式）として計算した

## 2. まず分かる、いちばん大事な性質

参加人数を n、参加料を a とすると、最初のポットは **P = n×a**。続ける額も P。
続けた人が合計 m 人になったとき、最後のポットは **P + m×P**。

自分の取り分の期待値を e とすると、続けたときの損得は（P を1単位として）

```
e × (1 + m) − 1
```

つまり **損益分岐の勝率 = 1 / (1 + m)**。自分以外に k 人続けるなら **1/(k+2)** で足りる。

| 自分以外に続ける人数 k | 必要な勝率 | 人数で等分した取り分 |
|---|---|---|
| 1人 | 33.3% | 50.0% |
| 2人 | 25.0% | 33.3% |
| 3人 | 20.0% | 25.0% |
| 4人 | 16.7% | 20.0% |
| 5人 | 14.3% | 16.7% |

**必要な勝率は、常に「等分の取り分」より低い。** これがこの形式の最大の特徴で、
直感より かなり広く続けてよい。参加料をいくらに変えてもこの比率は変わらない。

ただし実戦では2つの要素が効く。

1. **後ろに何人残っているか** — 前の席ほど「後から強い手に続かれる」危険が大きい
2. **前で何人続けたか** — 続けた人が多いほど、相手の手が強いと分かる

この2つを織り込んだのが第4節の表。

## 3. 計算方法

1. **役の判定器**（`evaluator.py`）
   7枚から最強の5枚を選ぶ処理を、13ビットの表引きで一括化。毎秒約300万件。
   5枚総当たりの素朴な判定と4000件で完全一致を確認済み（`test_evaluator.py`）。

2. **勝率の推定**（`gen_data.py`）
   1回の配札につき、ターン/リバー候補80通り × 相手手札候補12通りを全員で使い回す。
   1手あたり実質800通り以上を試しながら、評価回数を大幅に削減。
   全手の平均勝率が 0.499（理論値 0.5）になることで検算した。

3. **基準の決定**（`solve.py`）
   各席の戦略を「タイマン勝率がある値以上なら続ける」という形に絞り、
   他の席の戦略を固定して自分の最善を求める、を全席で繰り返す（繰り返し最適応答）。
   20万配札 × 8人分のデータで計算。

   検算: 2人卓で後攻・前が続けた場合の基準が **34%** と出た。理論値 1/3 = 33.3% と一致する。

## 6. 使い方

```bash
# 単発の判定
python3 check.py --hand AsKd --flop Ah7c2d --players 6 --seat 3 --continued 1

# 勝率だけ知りたいとき（相手の人数を指定）
python3 equity.py AsKd Ah7c2d 3

# データを作り直す（約3分）
python3 gen_data.py 200000 deals.npz

# 基準を計算し直す
python3 report.py && python3 make_md.py

# 判定器の検算
python3 test_evaluator.py
```

## 7. 注意と限界

- **これは勉強用の確率計算であり、自動で打つ仕組みではない。**
  KKPoker は自動プレイを規約で禁止しているのが一般的。また日本国内から
  実際のお金を賭けてオンラインで遊ぶことは賭博罪に当たるおそれがある。
- 手札は2枚（ホールデム形式）と仮定した。実際が4枚（オマハ形式）なら数値は変わる。
- 相手も同じように賢く打つ前提の数値。実際の相手が緩い／固い場合はずれる。
- 各席の戦略を「勝率の閾値ひとつ」に絞った近似解であり、厳密な均衡解ではない。
- 前で4人以上続いた場面は出現が非常に少なく、数値の精度は低い。
- この形式の手数料率（レーキ）は織り込んでいない。実際にはその分だけ基準が厳しくなる。

## 8. 対話型の判断盤（`tool.html`）

手札・場札を押して選び、「後ろに残っている人数」と「前で続けた人数」を選ぶと、
その場で続ける／降りるを判定する一枚もの。ブラウザだけで動く（外部通信なし）。

- 役の判定と勝率計算を JavaScript に移植。1回あたり22,000試行を約0.1秒で計算
- 判定器は Python 版と4000件で完全一致、勝率も誤差内で一致することを確認済み
- 基準は `grid.json`（後ろの人数 × 前で続けた人数）を埋め込んでいる

`python3 -c "..."` を使わずにその場で答えが出るので、実戦の振り返りに向く。
