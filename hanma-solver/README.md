# 韓麻ソルバー（Hanma Solver）

パラダイスシティのカジノ麻雀「**韓麻（ハンマ）**」ルールに対応した、
牌効率・打点の解析エンジンと、その上に載せる対戦アプリ。

目標イメージは **ポーカーの PokerSnowie の麻雀版** —
「この打牌は最善からどれだけ損している（EVロス）」を採点し、AIと実戦できるトレーニングツール。

## 使い方（Phase 1: 打牌アドバイザー）

ES モジュールを使うため、ローカルサーバー経由で開く（`file://` 直開きは不可）。

```bash
npx serve hanma-solver
# → http://localhost:3000 を開く
```

手牌を入力して「解析する」を押すと、切る牌ごとの **向聴・受け入れ・ドラ** を計算し、
最善打牌を提示する。

- 手牌表記: `123456789m123p1s1z`（m=萬 p=筒 s=索 z=字）
- 赤5: `0m` `0p` `0s`
- 字牌: `1z`=東 … `7z`=中
- 表ドラ表示牌を入れると、テンパイ形のドラ枚数も加味される

## テスト

```bash
node hanma-solver/test/engine.test.mjs
```

向聴・受け入れ・点数計算の 20 ケースを検証。

## 構成

```
hanma-solver/
├── index.html          # 解析画面
├── styles.css
├── src/
│   ├── tiles.js        # 牌モデル・表記変換・ドラ判定
│   ├── shanten.js      # 向聴数（通常形/七対子/国士）
│   ├── ukeire.js       # 受け入れ（有効牌）計算
│   ├── score.js        # 韓麻の点数計算（差し替え可能）
│   ├── analyze.js      # 打牌解析（14枚→最善打）
│   └── app.js          # UI グルー
├── test/engine.test.mjs
└── docs/
    ├── rules.md        # 韓麻ルール仕様（唯一の仕様源）
    └── preview.png     # 画面プレビュー
```

## ⚠️ ルールの未確定事項

韓麻はリリース直後（2026年2月）で情報が揺れている。`docs/rules.md` に「要確認」として記載。
特に **ツモ時のリーチ加点** と **赤5×表ドラの重複計上** は、実際のパラダイスシティの
挙動が分かり次第 `src/score.js` の `CONFIG` を直せば全体に反映される設計。
