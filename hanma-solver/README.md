# 韓麻ソルバー（Hanma Solver）

パラダイスシティのカジノ麻雀「**韓麻（ハンマ）**」ルールに対応した、
牌効率・打点の解析エンジンと、その上に載せる対戦アプリ。

目標イメージは **ポーカーの PokerSnowie の麻雀版** —
「この打牌は最善からどれだけ損している（EVロス）」を採点し、AIと実戦できるトレーニングツール。

## 使い方（Phase 1: 打牌アドバイザー）

ES モジュールを使うため、ローカルサーバー経由で開く（`file://` 直開きは不可）。

```bash
npx serve hanma-solver
# → http://localhost:3000 を開く
```

手牌を入力して「解析する」を押すと、切る牌ごとの **向聴・受け入れ・ドラ** を計算し、
最善打牌を提示する。

- 手牌表記: `123456789m123p1s1z`（m=萬 p=筒 s=索 z=字）
- 赤5: `0m` `0p` `0s`
- 字牌: `1z`=東 … `7z`=中
- 表ドラ表示牌を入れると、テンパイ形のドラ枚数も加味される

### EV解析（Phase 2a）

「**EV解析（モンテカルロ）**」を押すと、残り山からランダムに自摸る試行を
各打牌ごとに多数回まわし、**アガリ率・平均打点・アガリEV**（= アガリ率 × 平均打点）
を実測して EV 順に並べ替える。Web Worker で実行するので UI は固まらない。

- 「残り自摸巡数」で局の進行度を指定（既定 12）。少ないほどアガリ率は下がる。
- **アガリEV** の割り切り: まだ相手のアガリで自分の手が流れる分を割り引いていない。

### 放銃リスクと正味EV（Phase 2b）

「警戒相手（テンパイ濃厚）の人数」を入れると、各打牌の **放銃率** と
**正味EV = アガリEV − 放銃率 × 平均失点** を計算し、警戒人数が1人以上なら正味EV順に並べ替える。

> ⚠️ **韓麻はフリテンが無い＝現物でも当たる。** リーチ麻雀と違い「捨て牌による絶対安全牌」が
> 存在しないため、危険度モデルは現物=安全を使わない。相手の手を知らない前提の
> ヒューリスティック（牌種・見え枚数・壁）で、**絶対値ではなく打牌間の相対比較**に使う。

「場に見えている牌」を入れると、受け入れ計算の精度と壁（カベ）判定が向上する。

## テスト

```bash
node hanma-solver/test/engine.test.mjs
```

向聴・受け入れ・点数計算の 20 ケースを検証。

## 構成

```
hanma-solver/
├── index.html          # 解析画面
├── styles.css
├── src/
│   ├── tiles.js        # 牌モデル・表記変換・ドラ判定
│   ├── shanten.js      # 向聴数（通常形/七対子/国士）
│   ├── ukeire.js       # 受け入れ（有効牌）計算
│   ├── score.js        # 韓麻の点数計算（差し替え可能）
│   ├── analyze.js      # 打牌解析（14枚→最善打）
│   ├── mc.js           # モンテカルロEV（アガリ率・平均打点・EV）
│   ├── mc-worker.js    # EV解析を回す Web Worker
│   ├── danger.js       # 放銃リスク（フリテン無し前提のヒューリスティック）
│   ├── game.js         # 対局エンジン（配牌〜ツモ/ロン/ポン/リーチ/点数）
│   ├── play.js         # 実戦UI（対AI）
│   └── app.js          # 解析UI グルー
├── play.html           # 実戦（対AI）画面
├── test/engine.test.mjs
├── test/game.test.mjs
└── docs/
    ├── rules.md        # 韓麻ルール仕様（唯一の仕様源）
    └── preview.png     # 画面プレビュー
```

## 実戦（対AI）

`play.html` を開くと韓麻をAIと1局対戦できる。役なし・フリテンなし・チーなし（ポンあり）・
5は全部赤ドラ・ロン頭ハネ・リーチ棒供託。「お手本を表示」でソルバーの推奨打牌が出る（学習用）。
AIは向聴最小＋孤立牌の貪欲打牌、面前テンパイでリーチ、テンパイになるポンのみ副露する。
カン（暗槓/明槓）は v1 未実装。

## ⚠️ ルールの未確定事項

韓麻はリリース直後（2026年2月）で情報が揺れている。`docs/rules.md` に「要確認」として記載。
特に **ツモ時のリーチ加点** と **赤5×表ドラの重複計上** は、実際のパラダイスシティの
挙動が分かり次第 `src/score.js` の `CONFIG` を直せば全体に反映される設計。
