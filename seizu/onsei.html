二級建築士 設計製図 音声講座

耳から製図

全10話・約20分。教材と同じ内容を、ラジオ講座のように耳で復習できます。

使い方：▶を押すと、お使いのスマホ／パソコンに入っている 日本語の声で読み上げます。いちばん自然な声を自動で選びます （下の「声をもっと自然にする」で、さらに良い声を入れられます）。 ▶をもう一度押すと一時停止。「連続再生」をオンにすると第1話から最後まで通しで流れます。 文字も同時に表示されるので、目と耳の両方で覚えられます。
声をもっと自然にする（声優みたいな声にしたい人へ）

読み上げに使えるのはその端末に入っている声だけです。 一覧は自然な順にならべてあり、★★★ があれば自動で選びます。 もっと良くしたいときは、端末に良い声を入れてください。

端末やること
Windowsこのページを Microsoft Edge で開く。 「Nanami」「Keita」など Natural とつく声が出ます。 いちばん自然で無料。迷ったらこれ
iPhone・iPad設定 → アクセシビリティ → 読み上げコンテンツ → 声 → 日本語 → Kyoko / Otoya の「高品質」をダウンロード
Macシステム設定 → アクセシビリティ → 読み上げコンテンツ → システムの声 → 日本語の「拡張」「プレミアム」をダウンロード
Android設定 → ユーザー補助 → 音声出力 → Google音声サービス → 日本語の音声データをダウンロード

※ ブラウザの読み上げ機能なので、 プロの声優さんの録音のようにはなりません。 そこまで求める場合は、有料の音声合成で音声ファイルを作って差しこむ形になります。
